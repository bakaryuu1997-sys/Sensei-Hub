Giao diện Android & Tích hợp PWA

Hãy lựa chọn giải pháp thiết kế tối ưu nhất cho ứng dụng Android và PWA của bạn.

Phần 1: Kiến trúc & Giao diện ứng dụng Android (Chọn 1)

A

Hybrid Wrapper (Khuyên dùng)

Sử dụng WebView hiệu năng cao, tích hợp thêm thanh công cụ Native (tiêu đề, nút back/forward, refresh) và màn hình cấu hình Server IP để dễ dàng kết nối thử nghiệm trên thiết bị thật. Giữ nguyên 100% giao diện vũ trụ/starfield và logic dịch thuật mượt mà của Next.js.

  • Không cần viết lại 11 môn học trong Kotlin
  • Dễ cập nhật tính năng đồng thời với web
  • Hỗ trợ đổi IP Server linh hoạt
  • Vẫn phụ thuộc vào WebView
B

Compose Bottom Navigation Shell

Bọc WebView bằng thanh điều hướng dưới (Bottom Navigation) dạng Native của Jetpack Compose (Home, Cài đặt, Offline). Khi chuyển tab sẽ ẩn/hiện WebView hoặc chuyển trang tương ứng.

  • Cảm giác ứng dụng native hơn
  • Quản lý tab độc lập
  • Tạo độ trễ khi đồng bộ trạng thái tab giữa WebView và Compose
  • Thao tác back button phức tạp hơn
C

100% Native Jetpack Compose

Xây dựng lại toàn bộ giao diện học tập bằng Jetpack Compose thuần túy. Đọc bài học từ Next.js REST API và parse Markdown thành giao diện native bằng Jetpack Compose Markdown renderer.

  • Hiệu năng tối đa, mượt mà 120Hz
  • Trải nghiệm Android thuần chuẩn mực
  • Tốn cực kỳ nhiều thời gian (vượt quá phạm vi hiện tại)
  • Khó tái hiện hiệu ứng starfield động và client translations động

Phần 2: Phương án tích hợp PWA (Progressive Web App)

Để ứng dụng Web hiện nút "Tải App PWA", chúng ta cần thiết lập:

  • Web App Manifest: Định nghĩa tên app, màu sắc chủ đạo, icon và chế độ hiển thị fullscreen độc lập.
  • Service Worker: Đăng ký cache tĩnh để app có thể khởi động ngay cả khi offline.
  • Install Prompt Handler: Bắt sự kiện beforeinstallprompt để hiện nút "Tải App" đẹp mắt trên thanh Navigation của trang Web khi mở bằng trình duyệt điện thoại/máy tính.
