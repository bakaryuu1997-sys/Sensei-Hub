PWA: Tải ứng dụng trên Web

1. Luồng hoạt động của nút tải PWA:

  1. Khi người dùng truy cập web bằng Chrome/Safari, Service Worker kiểm tra độ tương thích.
  2. Bắt sự kiện beforeinstallprompt và lưu trữ để kích hoạt khi nhấn nút.
  3. Hiện nút "Tải ứng dụng" (Download App) trực quan trên Sidebar và TopBar.
  4. Nhấn nút sẽ gọi prompt cài đặt của trình duyệt và cài đặt app lên màn hình chính.

Kế hoạch triển khai kỹ thuật

Android App

  • Thêm các nút điều hướng Native vào MainScreen.kt
  • Tích hợp SharedPreferences để lưu/tải URL Server tùy chỉnh
  • Tạo Dialog Jetpack Compose cho cấu hình Server IP
  • Xử lý sự kiện back button native đồng bộ với WebView history

PWA (Next.js Dashboard)

  • Thêm tệp public/manifest.json định nghĩa cấu hình app
  • Thêm tệp public/sw.js cài đặt Service Worker cache tĩnh
  • Tạo client component PwaRegistrar.tsx đăng ký Service Worker và prompt
  • Thêm nút tải app vào sidebar.tsx và top-bar.tsx
