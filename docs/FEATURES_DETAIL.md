## モジュール1: 📖 マークダウンレッスンシステム

### 概要
Markdownベースの学習コンテンツ配信システム。11コース × 3言語で約1,560以上のレッスンファイルを管理・レンダリングします。

### ステータス: ✅ コンテンツ作成完了 / 🔧 ビューア開発中

### 機能要件

| ID | 機能 | 説明 | ステータス |
|----|------|------|-----------|
| L-1 | レッスン一覧表示 | コース別・フェーズ別のレッスン一覧 | ⏳ 予定 |
| L-2 | レッスン詳細表示 | Markdownレンダリング（コードハイライト、テーブル、Mermaid対応） | ⏳ 予定 |
| L-3 | 進捗トラッキング | レッスンの開始・完了状態を記録 | ⏳ 予定 |
| L-4 | 言語切替 | レッスンコンテンツの言語切替（EN/JA/VI） | ⏳ 予定 |
| L-5 | フロントマター解析 | title, description, day, chapter, category の解析 | ⏳ 予定 |
| L-6 | ナビゲーション | 前のレッスン/次のレッスンへの移動 | ⏳ 予定 |
| L-7 | コンテンツ検索 | レッスン内容のフルテキスト検索 | ⏳ 予定 |

### 受入基準
- [ ] 全11コースのレッスンが正しくレンダリングされること
- [ ] 3言語のコンテンツが切替可能であること
- [ ] コードブロックにシンタックスハイライトが適用されること
- [ ] Mermaid図が正しく表示されること
- [ ] レスポンシブ対応（モバイル/デスクトップ）

### ステータス: 🔧 データベース設計完了 / UI未実装
