# 🌟 機能詳細要件 (Features Detail)

Sensei Hub における主要機能の要件定義です。

---

## 1. 📖 記事学習機能 (Markdown Lessons)
Markdown で書かれた記事を読み、知識をインプットする機能。

### 必須機能
- `lessons/` ディレクトリ内の `.md` ファイルを読み込み、HTMLに変換して表示する。
- 記事のメタデータ（タイトル、カテゴリ、難易度）を一覧ページで表示する。
- コードブロックに対してシンタックスハイライト（色付け）を適用する。
- 記事の最後までスクロールしたら「完了ボタン」を押せるようにする。

### 拡張機能 (フェーズ2以降)
- 目次（Table of Contents）の自動生成。
- 記事内検索。

---

## 2. 📚 IT用語集 (Vocabulary Dictionary)
専門用語の意味を日本語・ベトナム語・英語の3言語で確認できる機能。

### 必須機能
- キーワード検索機能（日/越/英のどの言語でもヒットすること）。
- カテゴリ（Java, AWS, Network等）による絞り込み。
- 詳細画面での例文表示。
- 「お気に入り」に登録し、後から一覧で復習できる機能。

---

## 3. 🎮 インタラクティブ・クイズ (Interactive Quiz)
学習した内容をテストし、定着度を確認する機能。

### 必須機能
- 4択問題の出題（DBからランダムに取得）。
- 選択肢を選んだ瞬間に、正解・不正解を判定し、解説を表示する。
- 10問1セットなど、まとまった単位でスコアを計算する。
- クイズ結果（スコア）をユーザーの履歴として保存する。

---

## 4. 📊 学習ダッシュボード (Dashboard)
ユーザー自身の学習進捗を可視化する機能。

### 必須機能
- 完了したレッスンの数と進捗率（プログレスバー）の表示。
- 連続学習日数（ストリーク）の記録と表示。
- 直近のクイズスコアの履歴。
- お気に入り登録した単語へのクイックアクセス。

---

## 5. 🔐 認証システム (Authentication)
ユーザーごとのデータを管理するための機能。

### 必須機能
- Email とパスワードによるサインアップ / ログイン。
- Googleアカウントを利用したソーシャルログイン (OAuth)。
- パスワードのハッシュ化による安全な保存。
