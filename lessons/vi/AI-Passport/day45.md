## 3. 本日の内容

### AI の未来のトレンド

**定義**：AI が今後どのように進化し、社会や仕事に影響を与えるかを予測すること。

（Tương lai AI: những xu hướng và tác động tiếp theo của AI）

#### 1. 生成 AI の進化

```
文章・画像・音楽・動画など、さらに自然で多彩な生成が進む
```

#### 2. マルチモーダル AI

```
テキスト、画像、音声を同時に扱う AI の普及
```

#### 3. エッジ AI

```
スマートフォンや IoT 端末上で AI を動かす技術
```

#### 4. 自律システム

```
より自立して動作するロボットやエージェントの発展
```

#### 5. AI と倫理・規制の共生

```
技術進化と同時に倫理や法規制の整備も進む
```

### AI に必要なキャリアスキル

#### 1. 技術スキル

```
データ分析、機械学習、プログラミングの基礎
```

#### 2. 問題発見力

```
課題を見つけ、AI で解決する力
```

#### 3. コミュニケーション

```
技術者と現場・経営層の橋渡しをする力
```

#### 4. 倫理観・コンプライアンス

```
安全で社会的に受け入れられる AI を考える力
```

#### 5. 継続学習力

```
新しい技術や知識を学び続ける力
```

### AI キャリアの進み方

#### 1. AI エンジニア

```
モデル開発・システム構築を担当する技術職
```

#### 2. データサイエンティスト

```
データ分析とビジネス課題解決を結びつける職
```

#### 3. AI プロダクトマネージャー

```
AI サービスの企画・運用・改善を統括する職
```

#### 4. AI エシックス担当

```
倫理・法令遵守を監督する役割
```

#### 5. ビジネスユーザー

```
AI を使いこなし、現場で価値を出す人
```

### 社会の変化

#### 1. 働き方の変化

```
ルーチンワークはAIに移り、人間は創造的な仕事へシフトする
```

#### 2. 教育の変化

```
個別学習やオンライン学習がより進む
```

#### 3. 産業構造の変化

```
AI を中心とした新しい産業やサービスが生まれる
```

#### 4. 倫理的な議論の深化

```
AI の影響について、社会全体で議論が活発になる
```

## 7. 確認問題


### 問題1

将来の AI トレンドで「マルチモーダル AI」とは何ですか？

A) UI を統合したこと
B) 高速化された GPU
C) 複数の種類のデータを同時に扱う AI
D) 単一の言語だけ扱う AI

**答え**: C

**解説**: マルチモーダル AI はテキスト、画像、音声などを同時に扱います。
**ベトナム語説明**: AI đa phương thức xử lý cùng lúc nhiều loại dữ liệu.

### 問題2

エッジ AI の特徴は何ですか？

A) 現場で処理して遅延を減らすこと
B) UI を派手にすること
C) クラウドを必須にすること
D) データを削除すること

**答え**: A

**解説**: エッジ AI は現場で処理し遅延を低減します。
**ベトナム語説明**: AI biên xử lý tại chỗ giảm trễ.

### 問題3

自律システムで重視されるのは何ですか？

A) 環境を観察し自律的に判断すること
B) データを増やすだけ
C) UI を変更すること
D) 速度だけを上げること

**答え**: A

**解説**: 自律システムは環境を観察し自律判断します。
**ベトナム語説明**: Hệ thống tự trị quan sát môi trường và quyết định độc lập.

### 問題4

AI キャリアで必要な「問題発見力」とは？

A) 課題の本質を見抜く力
B) データを削除する力
C) UI をデザインする力
D) コードを書くだけの力

**答え**: A

**解説**: 問題発見力は本質的な課題を見つける力です。
**ベトナム語説明**: Khả năng phát hiện vấn đề là tìm ra cốt lõi thách thức.

### 問題5

AI エンジニアのスキルとして重要なのはどれ？

A) UI を派手にすること
B) データを隠すこと
C) 技術スキルと倫理観の両方
D) 広告運用だけ

**答え**: C

**解説**: AI エンジニアは技術と倫理の両方が求められます。
**ベトナム語説明**: Kỹ sư AI cần kỹ năng kỹ thuật và đạo đức. 

### 問題6

AI プロダクトマネージャーの役割は？

A) UI を揃えることだけ
B) コードを書くことだけ
C) ビジネス価値と技術をつなぐこと
D) データを削除すること

**答え**: C

**解説**: PM はビジネス価値と技術をつなぐ橋渡し役です。
**ベトナム語説明**: PM kết nối giá trị kinh doanh và kỹ thuật.

### 問題7

AI エシックス担当の主な役割は？

A) 倫理・法令遵守を監督すること
B) UI を飾ること
C) 速度を上げること

**解説**: エシックス担当は倫理や法令遵守を監督します。
**ベトナム語説明**: Người phụ trách đạo đức giám sát tuân thủ pháp luật và đạo đức.

### 問題8

学習を継続する力が AI キャリアで重要な理由は？

A) 技術や社会が変化し続けるから
B) UI が変わるから
C) 速度が上がるから

**ベトナム語説明**: AI thay đổi nhanh, nên cần học hỏi liên tục.

**ベトナム語説明**: Data scientist rút ra hiểu biết từ dữ liệu.
