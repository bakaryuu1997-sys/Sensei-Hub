## 3. 本日の内容

### ニューラルネットワークとは

**定義**：生物の脳（ニューロン）の構造にインスピレーションを得た、層状のAIモデル。

（Mạng thần kinh: mô hình AI lấy cảm hứng từ cấu trúc não bộ）

```
人間の脳
樹状突起（入力）
    ↓
ニューロン体
    ↓
軸索（出力）

ニューラルネットワーク
ニューロン1（入力）
    ↓
ニューロン（処理）
    ↓
ニューロン（出力）
```

### 基本的な構造

```
         入力層      隠れ層      出力層
            ●
           /│\
          / │ \
         ●  ●  ●━━●
          \ │ /    │
           \│/     ●
            ●
            
入力特徴：3個 → 隠れニューロン：3個 → 出力：2個（分類）
```

#### 1. 入力層（Input Layer）

- データを受け取る最初の層
- 例：画像なら、ピクセルの数 = 入力ニューロンの数

```
28×28 ピクセルの画像
→ 784個の入力ニューロン
```

#### 2. 隠れ層（Hidden Layer）

- 入力と出力の間で、計算と特徴抽出を行う層
- **重要**：複数の隠れ層を使うと、より複雑なパターンを学べる

```
隠れ層が多い ← 複雑なパターンに対応
隠れ層が少ない ← シンプルなパターンしか学べない

複数の隠れ層を持つニューラルネットワーク
＝ ディープラーニング（深層学習）
```

#### 3. 出力層（Output Layer）

- 最終的な結果を出力する層
- 例：画像分類なら、10個の出力ニューロン（0～9の数字）

```
手書き数字認識
→ 10個の出力ニューロン
→ 各ニューロンが「この数字の確率」を出力
```

### ニューロンの計算

各ニューロンは以下の計算を行う：

```
入力 × 重み → 合計 → 活性化関数 → 出力

y = f(w1×x1 + w2×x2 + w3×x3 + ... + b)
         ↑                            ↑
        重み                        バイアス
```

（Mỗi neuron: tích đầu vào × trọng số → hàm kích hoạt → đầu ra）

### 活性化関数（Activation Function）

**目的**：ニューロンの出力を非線形に変換し、複雑なパターンを学べるようにする。

#### ReLU（最も一般的）
```
f(x) = max(0, x)
→ 負の値は 0 に、正の値はそのまま
→ 計算が速く、効果的
```

#### シグモイド関数
```
f(x) = 1 / (1 + e^(-x))
→ 出力が 0～1 の間
→ 確率として解釈可能
→ 計算が遅い（古い方法）
```

#### tanh関数
```
f(x) = (e^x - e^(-x)) / (e^x + e^(-x))
→ 出力が -1～1 の間
→ シグモイドより学習が速い
```

### フォワードプロパゲーション（順伝播）

**プロセス**：入力データが層を通じて、出力層に到達するまでの流れ。

```
ステップ1: 入力層に入力データを入力
   ↓
ステップ2: 入力層 → 隠れ層1
   各隠れ層ニューロンが
   y = f(Σ w×x + b) を計算
   ↓
ステップ3: 隠れ層1 → 隠れ層2 ... （複数層の場合）
   ↓
ステップ4: 最後の隠れ層 → 出力層
   ↓
ステップ5: 出力層が最終結果を出力
```

**例：手書き数字認識**
```
入力：28×28 ピクセル画像
  ↓
入力層：784 ニューロン
  ↓
隠れ層1：128 ニューロン（特徴抽出）
  ↓
隠れ層2：64 ニューロン（さらに抽出）
  ↓
隠れ層3：32 ニューロン（さらに抽出）
  ↓
出力層：10 ニューロン（0～9の確率）
  ↓
結果：「この数字は 7 である確率 95%」
```

### なぜニューラルネットワークは複雑な問題を解けるか？

#### 1. 隠れ層が特徴を自動抽出
```
画像入力
  ↓
隠れ層1：エッジ（線）を検出
  ↓
隠れ層2：角を検出
  ↓
隠れ層3：形を検出
  ↓
隠れ層4：「これは 7 の形」を認識
```

#### 2. 活性化関数が非線形性を追加
```
線形な関数だけでは、複雑な曲線は描けない

f(x) = 2x + 3 （線形）
→ 複雑なパターンを学べない

活性化関数 + 複数層
→ 複雑な曲線も学べる
```

#### 3. 重みと学習
```
学習前：ランダムな重み
  ↓
訓練中：「正解に近い」ように重みを調整
  ↓
学習後：最適な重み
  ↓
結果：新しいデータでも高精度
```

## 4. 具体例

### 例1：手書き数字認識

```
ニューラルネットワーク構造：
- 入力層：784（28×28）
- 隠れ層1：128
- 隠れ層2：64
- 出力層：10

学習後：
精度 97%（テストデータ）
→ 数字 7 の精度も 95%

リアルワールド：
郵便番号認識、銀行小切手など
```

### 例2：画像分類（犬 vs 猫）

```
ニューラルネットワーク：
- 入力層：100×100×3（RGB）
- 隠れ層：複数層
- 出力層：2（犬 or 猫）

学習後：
- 犬の画像：「犬である確率 96%」
- 猫の画像：「猫である確率 93%」
```

### 例3：感情分析（テキスト）

```
入力：「このお店は素晴らしい！」
  ↓
入力層：単語をベクトルに変換
  ↓
隠れ層：感情的な特徴を抽出
  ↓
出力層：「肯定的である確率 92%」
```

## 6. 間違えやすいポイント

❌ **間違い1**: 「ニューラルネットワーク = 脳と同じ」
✅ **正解**: インスピレーション源だが、実際にはシンプルな数学計算

❌ **間違い2**: 「隠れ層が多いほど常に良い」
✅ **正解**: 過度に多いと過学習のリスク、最適な数がある

❌ **間違い3**: 「活性化関数は全て同じ」
✅ **正解**: ReLU、シグモイド、tanh など、それぞれ異なる特性

❌ **間違い4**: 「ニューロン数は任意に決める」
✅ **正解**: 問題と経験則に基づいて慎重に選ぶ

❌ **間違い5**: 「フォワードプロパゲーション = 学習」
✅ **正解**: フォワードは予測/評価、学習にはバックプロパゲーションが必要

## 7. 確認問題

### 問題1
ニューラルネットワークとは何ですか？

A) 脳の構造にインスピレーションを得たAIモデル
B) 条件を変えずに行う
C) 関係者を無視する
D) 結論がない

**答え**: A


**解説**: ニューラルネットワークは、生物の脳のニューロン構造にインスピレーションを得ていますが、実際には数学的計算を行う人工的なモデルです。

---

### 問題2
ニューラルネットワークで層が多い（深い）ことの利点は何ですか？

A) 偏ったデータで学習する
B) ファイルサイズが小さくなる
C) 直感だけで判断する
D) より複雑なパターンを学べる

**答え**: D


**解説**: 層が多いほど（深いほど）、複雑なパターンと抽象的な特徴を学ぶことができます。

---

### 問題3
隠れた層（Hidden Layer）の役割は何ですか？

A) 入力データを受け取るだけ
B) 最終結果を出力するだけ
C) 専門用語をそのまま使う
D) 特徴抽出と複雑な計算を行う

**答え**: D


**解説**: 隠れ層は、入力から直接見えない特徴を自動的に抽出し、複雑なパターンの学習に寄与します。

---

### 問題4
活性化関数（Activation Function）の役割は何ですか？

A) 出力を 0～1 に正規化する
B) ニューロンの出力を非線形に変換する
C) 使いにくい操作を設計する
D) 利用者を無視する

**答え**: B


**解説**: 活性化関数は、ニューロンの出力を非線形に変換することで、ニューラルネットワークが複雑なパターンを学ぶことを可能にします。

---

### 問題5
ReLUの特徴として正しいものはどれですか？

A) 負の値は 0、正の値はそのまま
B) 出力が -1～1 の間
C) 過学習だけを避けようとする
D) 性能よりも速度だけを重視する

**答え**: A


**解説**: ReLU（f(x) = max(0, x)）は、計算が単純で効果的で、現在最も一般的な活性化関数です。

---

### 問題6
フォワードプロパゲーションの説明として正しいものはどれですか？

A) リスクを無視する
B) 一度だけ行って終わる
C) 入力データが層を通じて出力に到達するまでの流れ
D) 結果を確認せず次に進む

**答え**: C


**解説**: フォワードプロパゲーションは、入力層から隠れ層を経由して、出力層に到達するまでのデータの流れです。

---

### 問題7
28×28 ピクセル画像をニューラルネットに入力する場合、正しい説明はどれですか？

A) 784 個の数字がある
B) 結論がない
C) データの質を無視する
D) 28×28 ピクセルの画像 = 784 ピクセル

**答え**: D


**解説**: 28×28 = 784 ピクセルの画像をフラット化すれば、入力ニューロンは 784 個必要です。

---

### 問題8
ニューラルネットが複雑なパターンを学ぶ条件として正しいものはどれですか？

A) 層が複数ある、活性化関数が非線形、重みを学習する組み合わせ
B) テストデータを学習に使う
C) 改善点を含めない
D) ニューロン数が多いから

**答え**: A


**解説**: 複数層、非線形活性化関数、学習可能な重みの組み合わせが、複雑なパターン認識を可能にします。

---

### 問題9
シグモイドと ReLU の違いとして正しいものはどれですか？

A) 評価なしで進める
B) シグモイドが常に優れている
C) 偏った対象だけを重視する
D) シグモイドは 0～1、ReLU は max(0,x)で、ReLU の方が計算が速い

**答え**: D


**解説**: シグモイドは古い方法で計算が遅く、ReLU は現代的で計算が速く、ディープラーニングで標準です。

---

### 問題10
学習中の重みの特徴として正しいものはどれですか？

A) 性能よりも速度だけを重視する
B) 学習中に自動的に調整される
C) 専門用語をそのまま使う
D) 透明性を欠く

**答え**: B


**解説**: 重みは最初ランダムに初期化されていますが、学習中に「正解に近い」ように自動的に調整されます。

## 8. 今日のまとめ

**ニューラルネットワーク**は、脳の構造にインスピレーションを得た、層状の AI モデルです。

**3つの主要な層**：
- 入力層：データを受け取る
- 隠れ層：特徴抽出と計算
- 出力層：結果を出力

**活性化関数**は、ニューロンの出力を非線形に変換し、複雑なパターン学習を可能にします。

**フォワードプロパゲーション**は、入力から出力までのデータの流れです。
