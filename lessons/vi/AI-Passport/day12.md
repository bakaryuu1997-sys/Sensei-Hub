## 3. 本日の内容

### 強化学習とは

**定義**：エージェント（学習する主体）が、環境と相互作用しながら、報酬と罰から学ぶ。

```
環境
  ↓
エージェント → 行動 → 結果
  ↑        ↓
  │    結果が良い → 報酬 ↓ この行動を強化
  └─── フィードバック
       結果が悪い → 罰 ↓ この行動を弱化
```

**3つの要素**：
1. **エージェント**：学習・行動する主体
2. **環境**：エージェントが作用する場
3. **報酬/罰**：フィードバック

### 強化学習のプロセス

```
状態S1（初期状態）
  ↓
エージェントが行動A1を実行
  ↓
環境が変化 → 状態S2 + 報酬R1
  ↓
エージェント：「行動A1は報酬をもたらした」と学ぶ
  ↓
次に状態S2になったら、類似の行動を取りやすくなる
  ↓
繰り返す...
```

### 教師あり学習 vs 強化学習

| 項目 | 教師あり学習 | 強化学習 |
|-----|------------|---------|
| 学習方法 | 「正解」から学ぶ | 「報酬」から学ぶ |
| フィードバック | 各入力に即座に正解 | 報酬は後で得られることが多い |
| 環境 | 静的 | 動的（変化する） |
| 例 | 画像認識、診断 | ゲーム、ロボット |

### 強化学習の基本概念

#### 状態（State）
- 現在の状況
- 例：ゲーム内のキャラクターの位置、敵の位置、体力

#### 行動（Action）
- エージェントが取る行動
- 例：上に移動、下に移動、攻撃、防御

#### 報酬（Reward）
```
行動 → 結果 → 報酬
         ↓
      良い結果 → +100 点
      悪い結果 → -50 点
      中立的 → 0 点
```

#### 方策（Policy）
```
「状態 S にいるとき、行動 A を取ると報酬が高い」
という規則を学ぶ

状態S1 → 行動A1 → 報酬+100
状態S2 → 行動A2 → 報酬+50
状態S1 → 行動A3 → 報酬-20
```

### Q 学習（Q-learning）

**最も基本的な強化学習アルゴリズム**

```
Q値：「状態Sで行動Aを取ったときの期待される報酬」

ステップ1: Q値をランダムに初期化
  ↓
ステップ2: エージェントが行動を取る
  ↓
ステップ3: 報酬を得る
  ↓
ステップ4: Q値を更新
        Q(S, A) ← Q(S, A) + α × (報酬 + γ × max Q(S', A') - Q(S, A))
  ↓
ステップ5: ステップ2～4を繰り返す
  ↓
Q値が収束（安定）したら終了
```

## 4. 具体例

### 例1：迷路ゲーム（ラット）

```
┌─────────────┐
│ S ・ ・ ・ G │  S: スタート
│ ・ ・ ・ ・ │  G: ゴール
│ ・ ・ ・ ・ │  ・: 道
│ ・ ・ ・ ・ │
└─────────────┘

ラット（エージェント）：
- 状態：迷路内の位置
- 行動：上下左右に移動
- 報酬：ゴール到達で +100
       移動1歩で -1（移動を抑制）

学習：
何度も迷路を走る
  → 最短ルートを学ぶ
  → 最初は 200 歩かかる
  → やがて 10 歩で到達
```

### 例2：ゲーム AI（AlphaGo）

```
状態：碁盤上の石の配置
行動：次にどこに打つか
報酬：ゲーム終了時に +1（勝利）、-1（敗北）

学習：
何千万回もゲームをプレイ
  → 最適な着手を学ぶ
  → 人間の一流棋士を超える

深層強化学習：
ニューラルネット + Q学習
```

### 例3：ロボット制御

```
状態：ロボットの位置、速度、センサー情報
行動：モーター制御
報酬：目標地点到達で +100
     落下で -1000
     電力消費 -1

学習：
ロボットが何回もシミュレーション環境で試行
  → 効率的な移動方法を学ぶ
  → 実ロボットに転移
```

### 例4：自動運転

```
状態：
- 前方の障害物
- 信号機の色
- 自車速度
- 目的地までの距離

行動：
- アクセル
- ブレーキ
- ハンドル角度

報酬：
- 安全に走行 +1
- 事故 -10000
- 信号無視 -100
- 目的地到達 +100

学習：
シミュレーション環境で運転練習
  → 安全な運転方法を学ぶ
```

## 5. 強化学習が向いている場面

#### 向いている場面
- 目標が明確（報酬で定義可能）
- 試行錯誤が許容される（ゲーム、シミュレーション）
- 長期的な報酬の最大化が重要

#### 向いていない場面
- 報酬が定義しにくい
- 試行錯誤の代価が大きい（実ロボット、医療）
- 即座のフィードバックが必要

## 7. 確認問題

### 問題1
強化学習（Reinforcement Learning）とは何ですか？

A) テストデータを学習に使う
B) データの質を無視する
C) 報酬と罰からフィードバックを受けて学ぶ
D) 重要性を無視する

**答え**: C


**解説**: 強化学習は、エージェントが報酬と罰のフィードバックを受けながら、最適な行動方法を学ぶ方法です。  
**ベトナム語説明**: Học tăng cường: từ phần thưởng và hình phạt để học hành động tối ưu.

---

### 問題2Q値とは何を訫事しますか？
A) 専門用語をそのまま使う
B) 相手に合わせない
C) 関係者を無視する
D) 「状態Sで行動Aを取ったときの期待される報酬」

**答え**: D


**解説**: Q値は、特定の状態で特定の行動を取ったときに得られる報酬の期待値を表します。  
**ベトナム語説明**: Q-value: giá trị kỳ vọng khi ở trạng thái S thực hiện hành động A.

---

### 問題3
AlphaGoのような深層強化学習の例として正しいものはどれですか？

A) ゲーム AI が何千万回もゲームをプレイして上達
B) 結論がない
C) 評価なしで進める
D) 説明を雑にする

**答え**: A


**解説**: ゲーム AI が報酬（勝利）と罰（敗北）から学ぶことは、強化学習の典型例です。  
**ベトナム語説明**: Game AI học từ thắng thua → học tăng cường.

---

### 問題4
強化学習での「エージェント」とは何ですか？

A) 相手に合わせない
B) 学習とテストのデータを混在させる
C) 結果だけを求める
D) 学習・行動する主体

**答え**: D


**解説**: 強化学習では、ロボット、ゲーム内キャラクター、自動運転車などが「エージェント」として行動します。  
**ベトナム語説明**: Agent: tác tử học tập và hành động (robot, xe tự lái...).
