## 3. 本日の内容

### AI ガバナンスとは

**定義**：AI の開発・運用に関するルール、責任、監督体制を整え、健全な利用を促進すること。

（Quản trị AI: xây dựng quy tắc và hệ thống giám sát để sử dụng AI an toàn và hiệu quả）

```
AI ガバナンス = 方針 + 監視 + 改善
```

### なぜガバナンスが必要か

#### 1. 社会的信頼の確立

```
透明な運用でユーザーや社会の信頼を得る
```

#### 2. 法令順守

```
規制やガイドラインに適合してリスクを減らす
```

#### 3. 品質と安全の維持

```
安定したサービスと安全性を確保する
```

### ガバナンス体制の要素

#### 1. 方針・ポリシー策定

```
利用範囲、責任、評価基準を決める
```

#### 2. 組織と役割定義

```
責任者、監督者、現場担当者の関係を明確にする
```

#### 3. 監査と評価

```
運用状況を定期的に確認し、改善する
```

#### 4. 利害関係者コミュニケーション

```
利用者、従業員、経営層と情報共有する
```

#### 5. 継続的改善

```
運用から得た知見を方針に反映する
```

### 具体例

#### 例1：AI 倫理委員会

```
AI の利用案件を審査し、倫理的な問題を検討する
```

#### 例2：AI 利用ポリシー

```
個人情報の扱い、差別防止、データ管理のルールを定める
```

#### 例3：リスク評価フレームワーク

```
AI はどの程度のリスクかを判定し、対応を決める
```

## 4. 試験で出やすいポイント

1. AI ガバナンスは技術だけでなく、組織とルールを含む
2. ガバナンスに必要な要素は方針策定、役割定義、監査、改善である
3. ステークホルダーとの連携が信頼構築に重要である
4. ガバナンスにより法令遵守とリスク軽減を両立する
5. AI の透明性と責任はガバナンスの中心的概念である

## 7. 確認問題


### 問題1

AI ガバナンスとは何ですか？

A) AI 利用のルールと監督の仕組み
B) データを捨てること
C) AI の速度測定
D) UI の設計

**答え**: A

**解説**: AI ガバナンスは利用ルールと監督体制を指します。
**ベトナム語説明**: Quản trị AI là quy tắc và cơ chế giám sát sử dụng AI.

### 問題2

ガバナンスが社会的信頼を確立する理由は？

A) 速度が上がるから
B) ルールと説明責任が信頼を生むから
C) データを消すから
D) UI が良くなるから

**答え**: B

**解説**: 信頼は明確なルールと説明責任から生まれます。
**ベトナム語説明**: Niềm tin đến từ quy tắc rõ ràng và trách nhiệm giải trình.

### 問題3

ガバナンス体制の要素に含まれるのはどれですか？

A) 方針・組織・監査・利害関係者連携
B) UI デザインだけ
C) 広告運用だけ
D) データ削除だけ

**答え**: A

**解説**: ガバナンスは方針、組織、監査、連携を含みます。
**ベトナム語説明**: Quản trị bao gồm chính sách, tổ chức, kiểm toán và kết nối bên liên quan.

### 問題4

AI 倫理委員会の役割は何ですか？

A) データを全部公開すること
B) 倫理的な利用基準を検討・監督すること
C) UI を作ること
D) モデルを速くすること

**答え**: B

**解説**: 倫理委員会は基準検討や監督を行います。
**ベトナム語説明**: Ủy ban đạo đức xem xét và giám sát tiêu chuẩn hành vi.

### 問題5

利害関係者とのコミュニケーションが重要な理由は？

A) 理解と協力を得て透明な運用にするため
B) モデルを小さくするため
C) UI を派手にするため
D) データを減らすため

**答え**: A

**解説**: 連携は透明で信頼できる運用に不可欠です。
**ベトナム語説明**: Liên lạc giúp đạt được hiểu biết và hợp tác rõ ràng.

### 問題6

ガバナンスで「継続的改善」が含まれるのはなぜ？

A) 速度だけを追うため
B) 状況や規制の変化に合わせて運用を改善するため
C) UI を毎日変えるため
D) データを捨てるため

**答え**: B

**解説**: 継続的改善でガバナンスは変化に対応します。
**ベトナム語説明**: Cải tiến liên tục giúp quản trị thích ứng với thay đổi.

### 問題7

AI 利用ポリシーの目的は何ですか？

A) 速度だけを上げること
B) モデルを隠すこと
C) 利用基準を明確にし安全に運用すること
D) UI を派手にすること

**答え**: C

**解説**: ポリシーは安全に利用するための基準を示します。
**ベトナム語説明**: Chính sách xác định tiêu chuẩn sử dụng an toàn.

### 問題8

リスク評価フレームワークの利点は？

A) モデルを速くすること
B) UI を改善すること
C) リスクを体系的に整理し対応策を決めること
D) データを減らすこと

**答え**: C

**解説**: フレームワークはリスク対応を体系化します。
**ベトナム語説明**: Khung đánh giá rủi ro hệ thống hóa cách ứng phó.

### 問題9

AI ガバナンスで「組織と役割定義」が必要なのはなぜ？

A) 責任を明確にし適切な判断を行うため
B) UI を派手にするため
C) 速度を上げるため
D) データを消すため

**答え**: A

**解説**: 役割定義で責任が明確になり運用が安定します。
**ベトナム語説明**: Xác định vai trò làm rõ trách nhiệm và ổn định vận hành.

### 問題10

AI 利用ポリシーに含めるべき要素はどれですか？

A) 広告文
B) 目的、範囲、責任、監査方法
C) UI の色
D) モデルの名前

**答え**: B

**解説**: ポリシーは目的・範囲・責任・監査を含むべきです。
**ベトナム語説明**: Chính sách nên gồm mục tiêu, phạm vi, trách nhiệm và kiểm toán.
