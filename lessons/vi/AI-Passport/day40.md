## 3. 本日の内容

### AI と創造性の関係

**定義**：AI を使って、アイデアの発想・文章・画像・音楽などを生成し、人間の創造活動を拡張すること。

（AI và sáng tạo: AI mở rộng khả năng sáng tác của con người）

```
AI は道具として、創造性の幅を広げる
```

### 創造的応用の特徴

#### 1. アイデアのスピード生成

```
短時間で多くの案を生み出せる
```

#### 2. 多様な表現の提案

```
文章、画像、音楽、映像などを多様に生成できる
```

#### 3. 人間と AI の協調

```
人が指示し、AI が出力。最終判断は人が行う
```

#### 4. 反復で磨く

```
AI のアウトプットをフィードバックして品質を高める
```

### クリエイティブな応用例

#### 1. 広告コピー作成

```
商品やサービスの売り文句を複数パターン生成する
```

#### 2. 画像生成

```
コンセプトアートやバナーを自動生成する
```

#### 3. 音楽制作

```
テーマに合ったメロディや伴奏を生成する
```

#### 4. ストーリー構成

```
小説や動画脚本のアイデアを補助する
```

#### 5. デザイン案の検討

```
UI / UX、ロゴ、パッケージデザインの候補を生成する
```

### AI 創作の進め方

#### 1. 目的を決める

```
何を作るのか、誰のためかを明確にする
```

#### 2. 参考例を用意する

```
スタイルやトーンの例を示すと、AI が一致しやすい
```

#### 3. フィードバックを与える

```
生成結果を評価し、改善点を指示する
```

#### 4. 人間の個性を加える

```
AI の出力に人間の感性やストーリーを融合する
```

### 注意点

#### 1. 著作権と倫理

```
既存作品のコピーに注意し、オリジナル性を守る
```

#### 2. 品質のばらつき

```
AI の生成にはばらつきがあるため、選別が必要
```

#### 3. ハルシネーション

```
事実に基づく内容は、AI の誤りに注意する
```

## 4. 試験で出やすいポイント

1. AI は創造力そのものではなく、人間の創作を拡張する道具である
2. 広告、画像、音楽、ストーリーなどの応用がある
3. 人と AI の協調が重要で、最終判断は人が行うべきである
4. 著作権や倫理に配慮する必要がある
5. 反復とフィードバックで成果を高める

## 7. 確認問題


### 問題1

AI と創造性の関係で正しいのはどれですか？

A) AI は創造性に関係しない
B) AI は人間を完全に置き換える
C) AI は常に自動で創造する
D) AI は人間の創造性を支援し拡張する

**答え**: D

**解説**: AI は人間の創造性を支援し、アイデア生成を拡張します。
**ベトナム語説明**: AI hỗ trợ và mở rộng sáng tạo của con người.

### 問題2

クリエイティブな AI の特徴に含まれないのは？

A) 多様な表現の提案
B) 人間との協調
C) アイデアのスピード生成
D) ユーザーの理解を無視すること

**答え**: D

**解説**: クリエイティブ AI はユーザー視点も大切にします。
**ベトナム語説明**: AI sáng tạo không nên bỏ qua sự thấu hiểu người dùng.

### 問題3

広告コピー作成で AI が役立つのは何ですか？

A) アイデアの複数案を素早く出せること
B) データを削除すること
C) UI を変えること
D) モデルの計算速度を上げること

**答え**: A

**解説**: AI は広告の複数案を迅速に生成できます。
**ベトナム語説明**: AI tạo nhanh các phương án ý tưởng quảng cáo.

### 問題4

クリエイティブな AI 活用で重要なのは？

A) 人間の個性を加えて編集すること
B) データを減らすこと
C) AI に全て任せること
D) UI を派手にすること

**答え**: A

**解説**: AI 出力には人間の個性を付け加えることが重要です。
**ベトナム語説明**: Cần thêm nét cá nhân con người vào kết quả AI.

### 問題5

AI 創作の進め方で「目的を決める」の意味は？

A) データを隠す
B) とにかく生成する
C) 速度だけを追う
D) 何を表現したいかを明確にする

**答え**: D

**解説**: 目的を決めることで創作の方向性が定まります。
**ベトナム語説明**: Xác định mục đích giúp định hướng sáng tạo.

### 問題6

AI 音楽制作で注意すべき点は何ですか？

A) モデルのサイズ
B) 著作権やオリジナリティの配慮
C) 色彩だけ
D) 速さだけ

**答え**: B

**解説**: 音楽制作には著作権とオリジナリティへの配慮が必要です。
**ベトナム語説明**: Sáng tác âm nhạc cần lưu ý bản quyền và tính nguyên bản.

### 問題7

ストーリー構成で AI を使うとき重要なのは？

A) 色だけを変えること
B) ただ長く書くこと
C) 構成の骨子や登場人物を明確にすること
D) 全て AI に任せること

**答え**: C

**解説**: 明確な構成とキャラクター設定が AI 活用のポイントです。
**ベトナム語説明**: Cấu trúc rõ ràng và nhân vật xác định là chìa khóa.

### 問題8

多様な表現を提案する AI の利点は？

A) 選択肢が増え発想が広がること
B) データが減ること
C) UI が速くなること
D) 音声が変わること

**答え**: A

**解説**: 多様な提案は発想の幅を広げます。
**ベトナム語説明**: Gợi ý đa dạng giúp mở rộng tư duy.

### 問題9

AI と人間の協調で大切なのは？

A) UI を派手にすること
B) 人間だけで作ること
C) AI を完全に任せること
D) AI の得意と人間の価値を組み合わせること

**答え**: D

**解説**: 協調では AI と人間の強みを組み合わせます。
**ベトナム語説明**: Hợp tác AI và con người kết hợp điểm mạnh của nhau.

### 問題10

反復で磨くということは何を意味しますか？

A) 色を変えること
B) 一回で完成させること
C) データを減らすこと
D) フィードバックをもとに何度も改善すること

**答え**: D

**解説**: 反復は改善を重ねて品質を高める手法です。
**ベトナム語説明**: Lặp lại là cải tiến nhiều lần để nâng cao chất lượng.
