## 3. 本日の内容

### AI のリスクとは

**定義**：AI が誤った判断や不適切な動作をし、個人・社会・経済・環境に悪影響を与える可能性。

（Rủi ro AI: khả năng AI gây ra hậu quả xấu cho con người hoặc xã hội）

```
AI のリスク = 可能性 × 影響度
```

### AIのリスクの種類

#### 1. 技術リスク
- モデルの誤動作
- システム障害
- セキュリティ脆弱性

#### 2. 安全リスク
- 航空機・自動運転の誤判定
- 医療診断の誤診
- 産業ロボットの事故

#### 3. 社会リスク
- 差別的判断
- フェイクニュース拡散
- 失業や格差の拡大

#### 4. プライバシーリスク
- 個人情報漏洩
- 位置情報の追跡
- 音声・映像の無断利用

### なぜ AI はリスクを持つのか

#### 1. データの偏り

```
不十分なデータ → 偏った学習 → 偏った出力
```

#### 2. モデルの不透明性

```
ブラックボックスな判断 → 理由がわからない → 監視が難しい
```

#### 3. 運用環境の変化

```
学習時と運用時で環境が異なると、想定外の動作が起こる
```

#### 4. 悪意ある利用

```
本来の用途以外に使われると、AI が害を拡大する
```

### 具体例

#### 例1：自動運転車の誤認識

```
歩行者を誤検知 → ブレーキ遅延 → 事故発生
```

#### 例2：採用スクリーニングの差別

```
過去の採用データに偏りがあると、特定の性別や属性を排除する結果になる
```

#### 例3：偽ニュース生成

```
AIが説得力のある偽情報を大量生成し、世論をかき乱す
```

## 4. リスク管理の基本

### 1. リスクの特定

```
何が起こり得るかを洗い出す
```

### 2. 影響の評価

```
そのリスクがどれくらい大きいかを判断する
```

### 3. 軽減策の検討

```
予防、検知、対応の方法を決める
```

### 4. 継続的な監視

```
運用中もリスクを見逃さず、改善を続ける
```
```

### 5. ステークホルダーとの連携

```
技術者だけでなく、利用者・法律家・倫理担当者と協力する
```
```

## 5. 試験で出やすいポイント

1. AI リスクは「AI が悪意を持つ」ではなく「望ましくない結果が起こる可能性」である
2. 技術リスク・安全リスク・社会リスク・プライバシーリスクの違い
3. データの偏りやブラックボックス性がリスクを高める
4. 継続的なリスク監視の必要性
5. AI は道具であり、運用方法がリスクを決める

## 6. 間違えやすいポイント

- 類似用語を混同しない。
- 具体例だけでなく本質も確認する。
- 日本語と英語の用語を逆に覚えない。
- 過学習と未学習を混同しない。
- 設問の文脈をよく読んで答える。

## 7. 確認問題


### 問題1

AI のリスクにはどの種類が含まれますか？

A) 技術リスク、社会リスク、プライバシーリスク、透明性リスク
B) 安全リスク、健康リスク、気候リスク、経済リスク
C) 法律リスク、政治リスク、文化リスク、宗教リスク
D) ブランドリスク、営業リスク、在庫リスク、物流リスク

**答え**: A

**解説**: AI のリスクは技術的問題、安全性、社会的影響、個人情報保護に関連するものです。
**ベトナム語説明**: Rủi ro AI bao gồm kỹ thuật, xã hội, bảo mật riêng tư và an toàn.

### 問題2

自動運転車の誤認識は主にどのリスクに該当しますか？

A) 技術リスクではない
B) プライバシーリスク
C) 安全リスク
D) 社会リスク

**答え**: C

**解説**: 誤認識は車両の安全性に直接影響し、安全リスクに当たります。
**ベトナム語説明**: Nhận dạng sai trong xe tự lái là rủi ro an toàn.

### 問題3

AI がリスクを持つ理由として正しいものはどれですか？

A) AI は人間の感情を持つから
B) モデルの不透明性やデータの偏りがあるため
C) データを使わないから
D) AI は常に正確だから

**答え**: B

**解説**: AI のリスクはモデル不透明性や偏ったデータなどから発生します。
**ベトナム語説明**: AI có rủi ro vì mô hình không minh bạch và dữ liệu bị lệch.

### 問題4

AI のプライバシーリスクは何に関係しますか？

A) UI の見た目
B) 電力消費量
C) 個人情報の漏えい
D) モデルの計算速度

**答え**: C

**解説**: プライバシーリスクは、個人情報が漏れることに関係します。
**ベトナム語説明**: Rủi ro riêng tư liên quan đến rò rỉ thông tin cá nhân.

### 問題5

AI リスク管理の最初のステップは何ですか？

A) リスクの特定
B) データの収集
C) 改善の実行
D) 顧客対応

**答え**: A

**解説**: リスク管理はまずリスクを特定してから対応策を考えます。
**ベトナム語説明**: Quản lý rủi ro bắt đầu bằng xác định rủi ro.

### 問題6

影響評価では何を確認しますか？

A) リスクが発生したときの影響度
B) 開発者の人数
C) UI の色使い
D) データの保存場所だけ

**答え**: A

**解説**: 影響評価は、リスク発生時の影響の大きさを評価します。
**ベトナム語説明**: Đánh giá ảnh hưởng xác định mức độ tác động khi rủi ro xảy ra.

### 問題7

次のうち AI リスク管理に含まれるプロセスはどれですか？

A) データを無視する
B) 一度で終わる運用
C) 継続的な監視と改善
D) モデルを公開しない

**答え**: C

**解説**: リスク管理には継続的な監視と改善が不可欠です。
**ベトナム語説明**: Quản lý rủi ro bao gồm giám sát và cải thiện liên tục.

### 問題8

AI の社会リスクはどのような問題に関係しますか？

A) バッテリーの寿命
B) 計算速度の遅さ
C) IT トラブルのみ
D) 差別や不公平な判断

**答え**: D

**解説**: 社会リスクは差別や不公平な結果に直結します。
**ベトナム語説明**: Rủi ro xã hội liên quan đến phân biệt đối xử và kết quả không công bằng.

### 問題9

AI のリスク対応で重要なのは何ですか？

A) 秘密にすること
B) テストを省略すること
C) 透明性と説明責任
D) すべて自動化すること

**答え**: C

**解説**: 透明性と説明責任により、AI の信頼性が高まります。
**ベトナム語説明**: Minh bạch và chịu trách nhiệm giúp tăng độ tin cậy AI.

### 問題10

AI リスクの「悪意ある利用」はどれですか？

A) モニタリングの強化
B) 偽情報生成やプライバシー侵害
C) モデルの最適化
D) UIを改善する

**答え**: B

**解説**: 悪意ある利用は偽情報や個人情報悪用などです。
**ベトナム語説明**: Sử dụng ác ý là tạo tin giả hoặc lạm dụng thông tin cá nhân.
