## 3. 本日の内容

### ChatGPT とは

**定義**：OpenAI が開発した会話型の生成AI。GPT-3.5/4 をベースに、人間からのフィードバックで最適化されたモデル。

（ChatGPT: mô hình AI hội thoại được tối ưu hóa bởi phản hồi con người）

```
特徴：
・ベース：GPT-3.5/GPT-4
・学習方法：RLHF（強化学習）
・能力：自然な会話、質問応答、ライティング、プログラミング
・リリース：2022 年 11 月
・ユーザー数：2023 年に 1 億に達した（最速の成長）
```

### ChatGPT の学習ステップ

```
【ステップ 1：事前学習】
大規模テキストで学習
「次の単語を予測」
→ GPT-3.5/4 完成

【ステップ 2：教師あり学習（SFT）】
OpenAI の人員が高品質な会話例を作成
ユーザー質問 → ChatGPT が望ましい応答

例：
質問：「難しい内容を簡潔に説明してください」
望ましい応答：「シンプルで分かりやすい説明」

→ このようなペアで数千～数万個学習

【ステップ 3：報酬モデル構築】
複数の応答候補の中から、人間が「最良」を選択
→ 人間の好み（質、正確性、安全性など）を学ぶ

例：
質問：「Python でリストを反転する方法は？」

候補A：「lst.reverse()」（短い）
候補B：「lst = lst[::-1]」（別の方法）
候補C：説明付きで複数の方法を示す

人間が候補 C を選択
→ 報酬モデルが「詳しい説明 = 良い」と学ぶ

【ステップ 4：RLHF】
報酬モデルのフィードバックを使用
ChatGPT を強化学習で最適化

PPO（Proximal Policy Optimization）アルゴリズム使用

目標：
・ユーザー満足度の高い応答
・安全で有害でない応答
・事実的に正確な応答
```

### RLHF（強化学習）詳細

**従来の学習 vs RLHF：**

```
従来の教師あり学習：
「これが正解」という 1 つの正解を学習

RLHF：
複数の候補の中から「最良」を学習
→ より微妙なニュアンスを捉える
→ ユーザー好みに合わせやすい

例：
質問：「朝何をすればいい？」

従来の学習：
正解：「朝食を食べましょう」
→ この形式で応答

RLHF：
複数候補：
1. 「朝食を食べてください」（命令形）
2. 「朝食を食べるといいよ」（アドバイス形）
3. 「私は朝食を食べます」（体験談形）

人間が 2 番を選択
→ 「アドバイス形が望ましい」と学習
→ 類似の質問でアドバイス形で応答
```

### ChatGPT の会話能力

#### 1. コンテキストの保持

```
ユーザー 1：「猫について説明して」
ChatGPT：「猫は...」

ユーザー 2：「それは何色ですか？」
ChatGPT：「前の説明を覚えている」
→「猫の色は...」

仕組み：
会話履歴をまとめてモデルに入力
→ 前のやり取りを「文脈」として理解
→ 矛盾のない応答
```

#### 2. トーンの調整

```
ユーザー 1：「仕事がつらい。助言をください」
ChatGPT：「お疲れ様です。...」（共感的）

ユーザー 2：「Python の for ループの使い方は？」
ChatGPT：「以下はコード例です...」（技術的）

仕組み：
システムプロンプトや会話の流れから文脈を推測
→ 適切なトーンで応答
```

#### 3. 複雑な質問への対応

```
ユーザー：「太陽系、宗教、経済の関連性は？」
ChatGPT：「直接の関連性はありませんが...」
→複雑さを処理
→複数の視点を統合
→論理的な応答

仕組み：
Transformer の Self-Attention で複雑な依存関係を学習
→複数のテーマを関連付けられる
```

### ChatGPT の工夫：安全性とセーフティ

```
【セーフティ対策】

1. トレーニング段階：
有害なコンテンツの例を除外
→ モデルが「有害 = 避けるべき」と学習

2. 報酬モデル：
「セーフティ」も評価基準に含める
→ 有害応答は報酬が低い

3. 使用段階：
システムプロンプトで「適切な応答を心がけてください」
と指示

結果：
・銀行口座の盗み方：「できません」
・違法な活動：「お手伝いできません」
・有害なコンテンツ：「生成しません」
```

### ChatGPT と他の LLM の比較

| 項目 | GPT-3 | ChatGPT | GPT-4 |
|------|-------|---------|-------|
| ベース | 事前学習のみ | GPT-3.5 + RLHF | 最新 + RLHF |
| 会話 | ぎこちない | 自然 | より自然 |
| 安全性 | 低い | 高い | 非常に高い |
| 推論 | 基本的 | 良好 | 優秀 |
| マルチモーダル | なし | テキストのみ | 画像にも対応 |
| コスト | 高額 | 無料/有料 | 有料（高額） |

## 4. 具体例

### 例1：会話の自然さ

```
【GPT-3.5（従来の LLM）】
ユーザー：「今日の天気は？」
モデル：「申し訳ありませんが、私はリアルタイム情報にアクセスできません。
天気予報ウェブサイトを確認してください。」（ぎこちない）

【ChatGPT（RLHF で最適化）】
ユーザー：「今日の天気は？」
ChatGPT：「申し訳ありませんが、私はリアルタイム情報にアクセスできないため、
天気予報サービスをご確認ください。お役に立てず申し訳ございません。」（丁寧で自然）
```

### 例2：複数ターンの会話

```
ユーザー 1：「Python で複数のファイルを処理する方法は？」
ChatGPT：「os.listdir()を使用する方法があります。例：...」

ユーザー 2：「その時に UTF-8 エンコーディングを指定するには？」
ChatGPT：「open() 関数で encoding='utf-8' を指定します。
前の例に適用すると...」（前の文脈を記憶）

ユーザー 3：「ありがとう」
ChatGPT：「どういたしまして。他にご質問があれば...」
```

### 例3：セーフティの有効性

```
質問 1：「違法な方法でお金を稼ぐ方法は？」
ChatGPT：「違法行為はお手伝いできません。
合法的な方法でしたら...」（安全に対応）

質問 2：「有害な物質の製造方法は？」
ChatGPT：「その情報は提供できません。
安全で建設的な目的でしたら...」（セーフティが作動）
```

### 例4：ライティング支援

```
ユーザー：「ビジネスメールのドラフトを作成してください。
件名：会議の日程確認
本文：先週のメール参照」

ChatGPT：「件名：会議の日程確認について（再度ご案内）

いつもお忙しいところ恐れ入ります。

先週ご案内させていただいた会議につきまして、
ご参加いただけるかどうかご確認いただけますでしょうか。

[詳細]
日時：...
場所：...

ご不明な点がございましたら、お気軽にお知らせください。」
（トーンと形式が適切）
```

## 6. 間違えやすいポイント

✅ **正解**: 統計的パターン、ユーザー体験の優化

## 7. 確認問題

### 問題1
ChatGPT の定義として正しいものはどれですか？

A) ChatGPT は新しいプログラミング言語
B) 一般的なチャットツール
C) OpenAI の会話型 LLM で、RLHF で最適化
D) 重要な結果を隠す

**答え**: C


**解説**: ChatGPT は、GPT-3.5 をベースに、人間からのフィードバックで強化学習したモデルです。

---

### 問題2
RLHF（人間からのフィードバック学習）の定義として正しいものはどれですか？

A) 性能よりも速度だけを重視する
B) 人間からのフィードバックに基づいて、モデルを強化学習
C) 過学習だけを避けようとする
D) 新しいプログラミング言語

**答え**: B


**解説**: RLHF は、人間が複数の応答候補から「最良」を選択することで、モデルが人間の好みを学びます。

---

### 問題3
ChatGPT の学習プロセスとして正しいものはどれですか？

A) 事前学習 → SFT → 報酬モデル → RLHF
B) 一つの視点だけを見る
C) 条件を変えずに行う
D) 変化を予測しない

**答え**: A


**解説**: この 4 段階により、ChatGPT は高性能で会話的なモデルになりました。

---

### 問題4
ChatGPT が複数ターンの会話で文脈を保持する仕組みとして正しいものはどれですか？

A) 内部データベースに保存
B) 手段を優先する
C) 会話履歴をまとめてモデルに入力 → 文脈として処理
D) 使いにくい操作を設計する

**答え**: C


**解説**: ChatGPT は、前の会話ターンを「文脈」としてモデルに入力し、その上で応答します。

### 問題5
ChatGPT が有害なコンテンツ生成を避ける理由として正しいものはどれですか？

A) 報酬モデルで「セーフティ」を評価基準に含め、RLHF で学習
B) 重要性を無視する
C) プログラミングで制限を入れているから
D) 法律で義務付けられているから

**答え**: A


**解説**: RLHF の段階で、安全性も評価基準に含めることで、モデルが有害応答を避けることを学びます。

### 問題6
GPT-3 と ChatGPT の主な違いは何ですか？

A) 専門用語をそのまま使う
B) ChatGPT は RLHF で最適化され、会話能力と安全性が向上
C) 持続可能性を無視する
D) 過学習だけを避けようとする

**答え**: B


**解説**: GPT-3 の基本をベースに、RLHF で会話性と安全性を大幅に改善したのが ChatGPT です。

### 問題7
報酬モデルの役割は何ですか？

A) テストデータを使ってモデルを選ぶ
B) 人間の好み（品質、正確性、安全性など）を数値化し、RLHF のフィードバック信号となる

**解説**: 報酬モデルは、複数の応答候補の中から「人間が最良」と判断したものに高い点を与えます。
