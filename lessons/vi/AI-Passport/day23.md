## 3. 本日の内容

### 生成AI とは

**定義**：新しいデータ（テキスト、画像、音声など）を生成できる AI 技術。

（AI tạo sinh: công nghệ AI có thể tạo ra dữ liệu mới）

```
従来の AI（判別AI）：
入力 → 分類・判断 → 出力
例：猫の画像 → 「これは猫です」

生成AI：
入力 → テキスト・画像・音声を生成 → 出力
例：「猫の画像を生成してください」 → 猫の画像
```

### 生成AI と従来の AI の違い

| 項目 | 従来の AI | 生成AI |
|------|----------|--------|
| 目的 | データを分類・判定 | 新しいデータを生成 |
| 出力 | カテゴリー、確率 | テキスト、画像、音声 |
| 事例 | 画像分類、迷惑メール検出 | ChatGPT、DALL-E |
| 学習対象 | ラベル付きデータ | 大規模無制限データ |
| 創造性 | ない（既知の分類のみ） | ある（新しい内容を創造） |

（Khác biệt: AI truyền thống phân loại, AI tạo sinh tạo ra dữ liệu mới）

### 生成AI が優れている理由

#### 1. 創造性

```
従来の AI：
「これは何ですか？」 → 分類のみ

生成AI：
「新しい物語を書いてください」 → 創造的なコンテンツ生成
「ユニークな画像を描いてください」 → オリジナル画像生成
```

#### 2. 事前学習の活用

```
大規模テキスト（ウェブ上のあらゆるテキスト）
→ 言語の構造を学習
→ 自動で言語を理解・生成できる
→ 特定タスクの学習データが少なくても対応

結果：少量のデータで高性能
```

#### 3. マルチタスク対応

```
従来の AI：
・犬検出用 AI
・猫検出用 AI
・車検出用 AI
→ タスクごとに異なるモデル必要

生成AI（ChatGPT など）：
・翻訳
・要約
・ライティング
・プログラミング
→ 1つのモデルが多くのタスクに対応
```

### 生成AI の仕組み

**簡略化した流れ**：

```
【学習フェーズ】
大規模テキスト（インターネット全体など）
    ↓
統計的パターン認識
「次の単語は何か」を学ぶ
    ↓
重み・パラメーターの調整
    ↓
モデル完成

【生成フェーズ】
ユーザー入力：「あかねのメディアは何ですか？」
    ↓
トークン化：「あかね」「の」「メディア」...
    ↓
モデル処理（Transformer）
「次の単語の確率分布」を計算
    ↓
確率的にサンプリング
「は」（確率 75%）を選択
    ↓
繰り返す
「。」まで生成完了
    ↓
出力：「あかねのメディアはメディアです」
```

### 大規模言語モデル（LLM）

**定義**：大規模なテキストデータで学習した言語モデル。

```
モデルサイズ（パラメーター数）：
- 小規模：数百万
- 中規模：数十億
- 大規模：数百億～数兆

例：
- GPT-2（2019）：1.5 億パラメーター
- GPT-3（2020）：1,750 億パラメーター
- GPT-4（2023）：より大規模でより高性能
```

**利点**：
- 事前学習により、様々なタスクに対応
- プロンプトエンジニアリングで精度向上
- Few-shot 学習で少量データで適応

## 4. 具体例

### 例1：ChatGPT

```
ユーザー入力：「太陽系について 200 字で説明してください」

処理：
1. テキストをトークン化
2. Transformer で意味を理解
3. 「太陽系」「200字」という制約を認識
4. 確率的にテキスト生成

出力：
「太陽系は、太陽を中心に、惑星、衛星、彗星が公転する系です。
8つの惑星（水金地火木土天海）があり、太陽の周り 46 億年前から
存在します。最大の惑星は木星で、生命が存在する可能性がある惑星は
地球です...」

特徴：
・自然な文
・要求を理解
・制約を守る
・不正確な場合もある（ハルシネーション）
```

### 例2：DALL-E（画像生成）

```
ユーザー入力：「青い目をした柴犬が、公園で遊んでいる油絵」

処理：
1. テキストを理解
2. 画像生成用 AI が図形・色・質感を計算
3. ピクセルレベルで画像を構築

出力：
「青い目の柴犬が、公園で遊ぶ油絵風の画像」が生成

特徴：
・入力テキストの指示を理解
・リアルか芸術的かを選べる
・組み合わせが存在しなくても生成可能
```

### 例3：音声合成（TTS）

```
入力テキスト：「こんにちは、私の名前は太郎です」

処理：
1. テキストを音素に変換
2. 音声パターンを生成
3. 音質を調整

出力：
自然な日本語音声（複数の声から選択可能）

応用：
・スマートフォンの読み上げ機能
・オーディオブック
・音声アシスタント
```

### 例4：コード生成（GitHub Copilot）

```
ユーザー入力（コメント）：
// 1 から n までの合計を計算する関数

処理：
1. コメントを理解
2. プログラミングパターンを学習
3. コード生成

出力：
def sum_n(n):
    return n * (n + 1) // 2

特徴：
・複数の実装方法を提案
・効率的なコードを学習
・バグがあることもある
```

## 5. 試験で出やすいポイント

1. **生成AI の定義**
   - 新しいデータを生成できる AI

2. **従来の AI との違い**
   - 判別AI（分類）vs 生成AI（創造）

3. **事前学習の利点**
   - 大規模データで基礎を学ぶ → 少データで適応

4. **LLM とは**
   - 大規模テキストで学習した言語モデル

5. **マルチタスク対応**
   - 1つのモデルで複数タスク

---

## 6. 間違えやすいポイント

❌ **間違い1**: 「生成AI = ChatGPT のみ」
✅ **正解**: 画像、音声、コード生成など、様々な種類がある

❌ **間違い2**: 「生成AI = 常に正確」
✅ **正解**: ハルシネーション（幻覚）で不正確な情報も生成

❌ **間違い3**: 「生成AI は常に新しい内容を作る」
✅ **正解**: 学習データのパターンを組み合わせているに過ぎない

❌ **間違い4**: 「LLM は完全に理解している」
✅ **正解**: 統計的にパターンを予測しているだけ

❌ **間違い5**: 「生成AI は人間に置き換わる」
✅ **正解**: 補助ツール、人間の創造性が必要

## 7. 確認問題

### 問題1
生成AI の定義として正しいのはどれですか？

A) データを分類する AI
B) 新しいデータを生成できる AI
C) ロボットを制御する AI
D) 個人情報を無断で利用する

**答え**: B


**解説**: 生成AI は、テキスト、画像、音声などの新しいデータを生成できます。

---

### 問題2
従来の AI と生成AI の主な違いは何ですか？

A) 新しい知識を避ける
B) 一つの視点だけを見る
C) 判別AI は分類、生成AI は新しいデータを生成
D) 相手に合わせない

**答え**: C


**解説**: 従来の AI は「これは何か」を判定し、生成AI は「新しい何かを作る」という根本的な違いがあります。

---

### 問題3
次のうち正しいものはどれですか？

A) 大規模データで基礎を学ぶ → 少量データで新タスクに適応
B) 変化を予測しない
C) 説明を省く
D) 結論がない

**答え**: A


**解説**: 事前学習により、少ないデータでも高性能を発揮できます。

C) 大規模なテキストデータで学習した言語モデル

**解説**: LLM は、インターネット上の大量のテキストから言語パターンを学習します。

### 問題5
生成AI が複数のタスクに対応できる理由は何ですか？

A) 事前学習により、言語の本質的なパターンを学んでいる
B) プログラムにタスクを追加している

D) 見た目だけを重視する

**答え**: A


**解説**: 大規模データでの事前学習により、様々なタスクに柔軟に対応できます。

### 問題6
生成AI の仕組みの基本となる技術は何ですか？

A) 十分に検証しない

D) テストデータを学習に使う

**答え**: B


**解説**: 生成AI は主に Transformer アーキテクチャと大規模データを組み合わせています。

### 問題7
DALL-E などの画像生成AI の学習方法は何ですか？

A) テキストと画像の対応関係
B) 十分に検証しない
C) 効果を証明しない

**答え**: A


**解説**: テキストと画像が対になっているデータセットから、テキスト → 画像への変換を学びます。

### 問題8
「ハルシネーション」とは何ですか？

A) 学習とテストのデータを混在させる

**解説**: ハルシネーションとは、AI が事実に基づかない情報を確信を持って生成する現象です。

**解説**: 生成AI は統計的にパターンを学び、確率に基づいて次のデータを予測生成します。

### 問題10

## 8. 今日のまとめ

**生成AI**は、新しいデータを生成できる AI 技術です。

**事前学習**により、大規模データから言語パターンを学び、様々なタスクに対応できます。

**Transformer**と大規模データが、生成AI の発展を可能にしました。

**応用例**：ChatGPT、DALL-E、音声合成、コード生成など

**課題**：ハルシネーション、倫理・法律問題
