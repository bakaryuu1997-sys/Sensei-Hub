## 3. 本日の内容

### AI プロジェクトの流れ

**定義**：AI をビジネス課題に適用する際の計画から運用までの工程。

（Triển khai dự án AI: từ nhận diện bài toán đến vận hành mô hình）

```
課題定義 → データ準備 → モデル開発 → 評価 → 本番運用
```

### 1. 課題定義

```
何を解決したいか、成功基準は何かを明確にする
```

- ビジネス課題の整理
- 目標の数値化
- 利害関係者の確認

### 2. データ準備

```
学習と評価に使うデータを収集・整形する
```

- データ品質の確認
- 欠損値・異常値の処理
- ラベル付け・カテゴリ整理

### 3. モデル選択・開発

```
適切な手法を選び、試作する
```

- ルールベース vs 機械学習
- 事前学習モデルの活用
- ハイパーパラメータ調整

### 4. 評価

```
精度や実用性を評価し、改善を繰り返す
```

- 精度、再現率、F1 スコアなど
- 受け入れ判定基準
- 実運用での性能確認

### 5. 本番運用

```
実システムに組み込み、継続的に監視する
```

- 実運用モニタリング
- データ更新と再学習
- 障害対応とレスポンス

### 6. 改善と継続

```
運用後も改善し、価値を持続させる
```

- フィードバックループ
- 新しいデータの取り込み
- ROI の再評価

### 実践的な課題

#### 1. データ不足

```
データが十分でないとモデル精度が上がらない
```

#### 2. 要件の曖昧さ

```
目的が不明確だと成果が出にくい
```

#### 3. 組織の抵抗

```
関係者の理解が不足すると導入が進まない
```

#### 4. 運用負荷

```
本番後の監視や保守を考慮しないと継続できない
```

### 成功のための組織要素

#### 1. 経営の支援

```
上層部の理解と予算が必要
```

#### 2. 現場との連携

```
現場の知見を取り入れ、運用しやすい仕組みにする
```

#### 3. 専門チーム

```
データサイエンティスト、エンジニア、ドメイン専門家が協力する
```

#### 4. 継続的な学習

```
運用から学び、改善を続ける文化を作る
```

## 4. 試験で出やすいポイント

1. AI プロジェクトは「課題定義→データ準備→開発→評価→運用」のサイクルである
2. PoC で小さく検証してから拡大するのが安全である
3. データ品質と要件の明確化が成功の鍵である
4. 運用後の監視・再学習が重要である
5. 組織の連携と経営支援がプロジェクト成功に不可欠である

## 7. 確認問題


### 問題1

AI プロジェクトの最初の段階は何ですか？

A) 評価
B) 本番運用
C) 課題定義
D) 改善

**答え**: C

**解説**: プロジェクトはまず課題を定義することから始まります。
**ベトナム語説明**: Dự án bắt đầu bằng xác định vấn đề.

### 問題2

データ準備で重要なのはどれですか？

A) データを全て捨てること
B) 品質の高いデータを揃えること
C) UI を派手にすること
D) モデルを速くすること

**答え**: B

**解説**: 良い AI は良いデータ準備から始まります。
**ベトナム語説明**: Dự án tốt bắt đầu từ chuẩn bị dữ liệu chất lượng.

### 問題3

モデル選択・開発で考慮するのは？

A) UI を変更すること
B) 速度だけを重視すること
C) 目的に合ったモデルを選ぶこと
D) データを毎日破棄すること

**答え**: C

**解説**: 目的に応じたモデル選択が重要です。
**ベトナム語説明**: Chọn mô hình phù hợp với mục tiêu là quan trọng.

### 問題4

評価で確認するべきものは何ですか？

A) 性能や実運用での有効性
B) 広告の数
C) UI の色
D) モデル名

**答え**: A

**解説**: 評価では性能と実運用での有効性を確認します。
**ベトナム語説明**: Đánh giá xác nhận hiệu năng và hiệu quả trong thực tế.

### 問題5

本番運用で重要なのはどれですか？

A) データを公開すること
B) 速度だけを上げること
C) 監視と迅速な対応体制
D) UI を派手にすること

**答え**: C

**解説**: 本番運用では監視と対応が必須です。
**ベトナム語説明**: Vận hành thực tế cần giám sát và phản ứng nhanh.

### 問題6

改善と継続で行うべきことは？

A) 一度で終わる
B) UI を変更するだけ
C) モデルを放置する
D) 運用結果を見て継続的に改善する

**答え**: D

**解説**: 継続的改善で AI の品質を高めます。
**ベトナム語説明**: Cải tiến liên tục giúp nâng cao chất lượng AI.

### 問題7

実践的な課題で「データ不足」が意味するのは？

A) 広告が多いこと
B) 十分な学習データがないため精度が出にくいこと
C) データが多すぎること
D) UI が見にくいこと

**答え**: B

**解説**: データ不足は学習に必要な情報が足りない状態です。
**ベトナム語説明**: Thiếu dữ liệu là không đủ thông tin để học tốt.

### 問題8

要件の曖昧さが問題になる理由は？

A) 正しいモデルや評価指標が決まらないから
B) UI が変わるから
C) データが圧縮されるから
D) 速度が落ちるから

**答え**: A

**解説**: 曖昧な要件では適切な設計ができません。
**ベトナム語説明**: Yêu cầu không rõ ràng khiến không thể thiết kế phù hợp.

### 問題9

組織の抵抗を減らすために必要なことは？

A) データを隠すこと
B) 速度を上げること
C) UI を派手にすること
D) 関係者と連携し理解を得ること

**答え**: D

**解説**: 組織内の理解を得ることで抵抗が減ります。
**ベトナム語説明**: Giải thích và hợp tác tổ chức giúp giảm kháng cự.

### 問題10

運用負荷の課題を軽減するには何が必要？

A) 広告を増やすこと
B) 自動化と適切な体制整備
C) データを減らすことだけ
D) UI を派手にすること

**答え**: B

**解説**: 運用負荷は自動化と体制整備で軽減できます。
**ベトナム語説明**: Giảm tải vận hành bằng tự động hóa và tổ chức phù hợp.
