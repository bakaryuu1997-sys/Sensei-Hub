## 3. 本日の内容

### 偏見とは

**定義**：特定の属性やグループに対して、不利益または優遇が生じる傾向。

（Thành kiến: xu hướng đối xử không công bằng với một nhóm người）

```
偏見 = データ + モデル + 社会構造の交差点
```

### バイアスの種類

#### 1. データバイアス

```
収集データが特定の性別・年齢・人種に偏っている
```

#### 2. 表現バイアス

```
ある集団がデータに十分に表れない
```

#### 3. アルゴリズムバイアス

```
学習アルゴリズムが偏りを強める
```

#### 4. 社会バイアス

```
社会の既存の差別や不平等が反映される
```

### AI と公平性の課題

```
同じ結果でも、ある人には有利で、別の人には不利になることがある
```

#### 1. 経済機会の不平等

```
採用・融資・保険で特定の層が不利になる
```

#### 2. アクセスの不平等

```
高齢者や障がい者が使いづらい設計になる
```

#### 3. 意図しない差別

```
過去のデータをそのまま使うと、不公平が再現される
```

### 公平性の尺度

#### 1. 結果の平等

```
全員に同じ割合で良い結果を出す
```

#### 2. 機会の平等

```
同じ条件で同じチャンスを提供する
```

#### 3. 個別の公平

```
似た人に似た扱いをする
```
```

### バイアス軽減の方法

#### 1. 多様なデータ収集

```
対象者を偏らせず、多様なデータを集める
```

#### 2. バイアス検出

```
公平性指標で結果を評価する
```

#### 3. インクルーシブ設計

```
多様な視点を設計に組み込む
```

#### 4. モニタリングと改善

```
運用中に差別が出ていないか監視し、改善する
```

### 具体例

#### 例1：採用AIの性別バイアス

```
過去に男性が多い職種で学習すると、女性候補を低く評価する可能性
```

#### 例2：顔認識の精度差

```
肌の色や性別によって認識精度が異なり、不公平な扱いになる
```

#### 例3：教育AIのアクセス

```
インターネット環境がない地域では、AI教材が利用できない
```

## 4. 試験で出やすいポイント

1. 偏見はデータと社会構造の両方から生じる
2. 公平性の定義は一つではなく、状況に応じて使い分ける
3. 多様なデータとインクルーシブ設計が重要
4. バイアス検出とモニタリングは運用の一部である
5. AI は公平性を改善する道具にもなるが、誤用すると不公平を強化する

## 7. 確認問題


### 問題1

AI のバイアスとは何ですか？

A) モデルの速度
B) UI のデザイン
C) 偏った判断や結果を生む要因
D) データの形式

**答え**: C

**解説**: バイアスは偏った判断や不公平な結果を生む要因です。
**ベトナム語説明**: Thiên kiến là nguyên nhân gây ra kết quả sai lệch và không công bằng.

### 問題2

データバイアスの例はどれですか？

A) 特定の属性が過剰に含まれるデータ
B) データが圧縮されている
C) モデルが高速である
D) UI が派手である

**答え**: A

**解説**: データバイアスは特定の属性が偏って含まれる場合に発生します。
**ベトナム語説明**: Dữ liệu bị lệch khi một thuộc tính bị chứa quá mức.

### 問題3

アルゴリズムバイアスの原因として正しいのは？

A) データが少ないだけではない
B) UIが見やすい
C) 学習アルゴリズムが偏ったデータを拡大する
D) モデルが早く動く

**答え**: C

**解説**: アルゴリズムは偏ったデータから不公平な予測を拡大することがあります。
**ベトナム語説明**: Thuật toán có thể khuếch đại sự lệch lệnh từ dữ liệu.

### 問題4

社会バイアスが引き起こす問題はどれですか？

A) 差別や機会不平等
B) UI が簡単になる
C) 計算が速くなる
D) データ量が減る

**答え**: A

**解説**: 社会バイアスは差別や機会不平等を引き起こします。
**ベトナム語説明**: Thiên kiến xã hội gây ra phân biệt đối xử và bất bình đẳng cơ hội.

### 問題5

公平性の尺度に「結果の平等」が含まれるのは何のため？

A) データを削除するため
B) モデルを速くするため
C) UI を統一するため
D) 異なるグループで同等の成果を目指すため

**答え**: D

**解説**: 結果の平等は異なるグループが同等の成果を得ることを目指します。
**ベトナム語説明**: Công bằng kết quả nhằm mục tiêu các nhóm khác nhau đạt được kết quả tương đương.

### 問題6

機会の平等とは何ですか？

A) 同じチャンスを提供すること
B) AI を停止すること
C) 同じ結果を強制すること
D) データを隠すこと

**答え**: A

**解説**: 機会の平等は同じスタートラインを提供することです。
**ベトナム語説明**: Công bằng cơ hội là cung cấp cùng cơ hội ban đầu.

### 問題7

多様なデータ収集がバイアス軽減に役立つ理由は？

A) UI を改善するため
B) 偏りを減らし多様な視点を含めるため
C) 速度を上げるため
D) データを減らすため

**答え**: B

**解説**: 多様なデータは偏りを減らし公平性を高めます。
**ベトナム語説明**: Thu thập đa dạng giảm lệch và tăng tính công bằng.

### 問題8

AI と公平性の課題で重要なのはどれですか？

A) モデルを大きくすること
B) データをすべて公開すること
C) 意図しない差別の防止
D) 速度を優先すること

**答え**: C

**解説**: AI の公平性課題では差別防止が重要です。
**ベトナム語説明**: Trong AI, ngăn phân biệt đối xử vô ý là quan trọng.

### 問題9

アクセスの不平等が引き起こすのは何ですか？

A) データの破壊
B) モデルの圧縮
C) 色の違い
D) サービス利用機会の格差

**答え**: D

**解説**: アクセス不平等は利用機会の格差につながります。
**ベトナム語説明**: Bất bình đẳng truy cập dẫn đến khác biệt cơ hội sử dụng.

### 問題10

個別の公平性とはどのような考え方ですか？

A) 全員に同じ結果を与えること
B) 似た状況の人に同じ扱いをすること
C) データを削除すること
D) UI を派手にすること

**答え**: B

**解説**: 個別公平は似た個人を同じように扱う考え方です。
**ベトナム語説明**: Công bằng cá nhân là đối xử như nhau với những người có hoàn cảnh tương tự.
