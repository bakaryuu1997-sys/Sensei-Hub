## 3. 本日の内容

### AI セキュリティとは

**定義**：AI システムを攻撃や不正利用から守り、安全に運用すること。

（Bảo mật AI: bảo vệ hệ thống AI khỏi tấn công và rò rỉ dữ liệu）

```
AI セキュリティ = データ保護 + モデル保護 + 運用保護
```

### 代表的な攻撃手法

#### 1. モデル汚染攻撃

```
悪意あるデータで学習を汚染し、誤動作を誘発する
```

#### 2. 敵対的サンプル

```
見た目は正しくても、AI が誤認識する入力を作る
```

#### 3. データ漏洩

```
不適切な管理により、個人情報や機密情報が流出する
```

#### 4. API 侵害

```
認証をすり抜け、AI API を悪用する
```

### 防御策

#### 1. アクセス制御

```
必要な人だけがアクセスできるようにする
```

#### 2. データ暗号化

```
保存や通信時にデータを暗号化して守る
```

#### 3. 監査ログ

```
操作履歴を記録し、不正を検知できるようにする
```

#### 4. サプライチェーン管理

```
外部モデル・データの信頼性を確認する
```

#### 5. テストと脆弱性診断

```
攻撃を想定した検証を行い、弱点を修正する
```

### 具体例

#### 例1：公開APIの不正利用

```
公開されたAI APIに大量リクエストを送り、サービス停止やコスト増を狙う
```

#### 例2：学習データの漏洩

```
顧客情報を含むデータが外部に流出し、信用失墜が起こる
```

#### 例3：敵対的画像攻撃

```
交通標識にわずかな改ざんを加え、自動運転の誤判断を誘発する
```

## 4. 試験で出やすいポイント

1. AI セキュリティはデータ、モデル、運用のすべてを守ること
2. モデル汚染、敵対的サンプル、データ漏洩が代表的なリスクである
3. アクセス制御、暗号化、監査ログが基本的な防御策である
4. 供給連鎖リスクにも注意する必要がある
5. テストや脆弱性診断は運用前だけでなく継続して行うべきである

## 7. 確認問題


### 問題1

AI セキュリティでの「モデル汚染攻撃」とは？

A) 学習データや訓練プロセスを操作する攻撃
B) 広告を表示する攻撃
C) 電源を切る攻撃
D) UI を壊す攻撃

**答え**: A

**解説**: モデル汚染攻撃は学習過程に悪意あるデータを混入させます。
**ベトナム語説明**: Tấn công nhiễm bẩn mô hình thao túng dữ liệu huấn luyện.

### 問題2

敵対的サンプルの目的は何ですか？

A) UI を改善すること
B) 速度を上げること
C) モデルの判断を誤らせること
D) データを減らすこと

**答え**: C

**解説**: 敵対的サンプルはモデルを騙して誤判断させます。
**ベトナム語説明**: Mẫu đối kháng gây nhầm lẫn mô hình.

### 問題3

データ漏洩対策として有効なのは？

A) UI を派手にする
B) 広告を出す
C) データを消すだけ
D) 暗号化とアクセス制御

**答え**: D

**解説**: 暗号化とアクセス制御は漏洩防止に有効です。
**ベトナム語説明**: Mã hóa và kiểm soát truy cập ngăn rò rỉ dữ liệu.

### 問題4

API 侵害に対する防御策はどれですか？

A) UI を変更すること
B) モデルを小さくすること
C) データを消すこと
D) 認証・認可とレートリミット

**答え**: D

**解説**: API 侵害には認証やレート制限が重要です。
**ベトナム語説明**: Bảo vệ API cần xác thực và giới hạn tỷ lệ truy cập.

### 問題5

アクセス制御が守るものは何ですか？

A) 速度を上げること
B) 権限のない者の利用を防ぐこと
C) UI を派手にすること
D) データを破壊すること

**答え**: B

**解説**: アクセス制御は権限のない利用を防ぎます。
**ベトナム語説明**: Kiểm soát truy cập ngăn người không có quyền sử dụng.

### 問題6

サプライチェーン管理がセキュリティに必要なのは？

A) データを削除するため
B) 外部依存の安全性を確保するため
C) UI を派手にするため
D) 速度を求めるため

**答え**: B

**解説**: 依存する外部要素の安全性を確保することが目的です。
**ベトナム語説明**: Quản lý chuỗi cung ứng đảm bảo an toàn cho thành phần bên ngoài.

### 問題7

公開 API の不正利用で起こりやすいことは？

A) データが減る
B) 不正アクセスや過剰なリクエスト
C) 速度が上がる
D) UI が派手になる

**答え**: B

**解説**: 不正利用はアクセス乱用や攻撃につながります。
**ベトナム語説明**: Lạm dụng API công khai dẫn đến truy cập trái phép, tấn công.

### 問題8

学習データ漏洩のリスクを減らすには？

A) 最小限のデータ保持と暗号化
B) UI を変える
C) 速度を上げる
D) 広告を追加する

**答え**: A

**解説**: データ漏洩対策には最小化と暗号化が有効です。
**ベトナム語説明**: Giảm rủi ro rò rỉ bằng giữ dữ liệu tối thiểu và mã hóa.

### 問題9

敵対的画像攻撃では何が狙われますか？

A) 速度だけ
B) データの形式
C) UI の色
D) 画像認識モデルの誤判定

**答え**: D

**解説**: 敵対的画像攻撃は画像認識モデルの誤判定を狙います。
**ベトナム語説明**: Tấn công ảnh đối kháng nhắm vào nhận diện hình ảnh.

### 問題10

AI セキュリティでログ管理が重要なのはなぜですか？

A) 不正アクセスや異常の追跡・検知に役立つから
B) UI を派手にするため
C) モデルを速くするため
D) データを破棄するため

**答え**: A

**解説**: ログ管理は不正検知や事後調査のために重要です。
**ベトナム語説明**: Quản lý nhật ký giúp phát hiện và truy vết hành vi trái phép.
