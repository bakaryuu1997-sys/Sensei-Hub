## 3. 本日の内容

### 説明責任とは

**定義**：AI が出した結果について、誰が何に責任を持つかを明確にすること。

（Trách nhiệm giải trình: xác định ai sẽ chịu trách nhiệm khi AI gây ra vấn đề）

```
説明責任 = 誰が何を説明するか
```

### 透明性とは

**定義**：AI の仕組みや判断過程を利用者や監督者に見せること。

（Minh bạch: cho thấy cách AI hoạt động và quyết định như thế nào）

```
透明性があると、信頼と改善が進む
```

### 説明可能なAIの必要性

#### 1. 誤りを検知するため

```
なぜそう判断したのかがわからないと、修正できない
```

#### 2. 利用者の安心のため

```
判断根拠がわかれば、結果を受け入れやすい
```

#### 3. 規制対応のため

```
説明要求に対応できることが法令順守の条件になる
```

### 具体的な手法

#### 1. モデルカード

```
用途、データ、制限、性能をまとめた文書
```

#### 2. フィーチャー寄与分析

```
どの入力が結果に影響したかを可視化する
```

#### 3. LIME / SHAP

```
個別の予測に対して、各変数の影響を説明する
```

#### 4. 履歴ログと説明レポート

```
入力、判断、出力、検証結果を記録する
```

### 具体例

#### 例1：融資審査AI

```
「年収と勤続年数が審査結果に影響しました」と説明する
```

#### 例2：医療診断AI

```
「この画像の部位に異常があるため、追加検査を推奨します」と説明する
```

### 透明性の限界

```
複雑なモデルでは完全に説明することが難しい
```
```

#### 1. ビジネス機密とのバランス

```
内部アルゴリズムすべてを公開する必要はないが、利用者には適切に説明する
```

#### 2. 誤解されるリスク

```
技術的すぎる説明は利用者に伝わらない
```

## 4. 試験で出やすいポイント

1. 説明責任は「誰が責任を持つか」を明らかにすることである
2. 透明性は「仕組みと根拠を見せること」
3. モデルカードやLIME/SHAPは説明可能性の手法
4. 完全な透明性とビジネス機密は両立が必要
5. 説明は誤り検知や信頼構築につながる

## 7. 確認問題


### 問題1

説明責任が必要な理由はどれですか？

A) AI の判断過程を説明できること
B) データを増やすだけ
C) モデルを早く作ること
D) UI を派手にすること

**答え**: A

**解説**: 説明責任は AI の判断過程を説明できることです。
**ベトナム語説明**: Giải trình cần giải thích được quá trình ra quyết định của AI.

### 問題2

透明性が利用者に与えるメリットは何ですか？

A) より速い処理
B) より派手な画面
C) 安心感と信頼
D) データ容量削減

**答え**: C

**解説**: 透明性は利用者に安心感と信頼を与えます。
**ベトナム語説明**: Minh bạch đem lại cảm giác an tâm và tin cậy cho người dùng.

### 問題3

モデルカードは何のために使われますか？

A) モデルの特徴や利用条件を明示するため
B) 学習速度を上げるため
C) UI を整理するため
D) モデルを圧縮するため

**答え**: A

**解説**: モデルカードはモデルの説明情報を提供します。
**ベトナム語説明**: Model card cung cấp thông tin mô tả về mô hình.

### 問題4

LIME / SHAP はどのような手法ですか？

A) UI デザイン手法
B) 予測の説明を行うための解釈手法
C) データを圧縮する手法
D) 暗号化手法

**答え**: B

**解説**: LIME / SHAP は機械学習の予測を説明するための手法です。
**ベトナム語説明**: LIME/SHAP là phương pháp giải thích dự đoán máy học.

### 問題5

説明可能な AI が必要な理由として正しいのは？

A) 計算を速くするため
B) データを増やすため
C) 誤りを検知しやすくするため
D) UI を派手にするため

**答え**: C

**解説**: 説明可能性は誤り検知や信頼性向上に役立ちます。
**ベトナム語説明**: Khả năng giải thích giúp phát hiện sai sót và tăng độ tin cậy.

### 問題6

フィーチャー寄与分析は何を示しますか？

A) モデルの実行時間
B) 各特徴量が予測に与える影響

**解説**: 寄与分析は特徴量ごとの影響度を示します。
**ベトナム語説明**: Phân tích đóng góp cho thấy mức độ ảnh hưởng của từng đặc trưng.

履歴ログと説明レポートの目的は？
