## 3. 本日の内容

### ハルシネーション とは

**定義**：生成AI が、実在しない情報や事実に基づかない情報を、確信を持って生成する現象。

（Ảo tưởng: AI tạo ra thông tin không tồn tại với sự tự tin）

```
特徴：
・AI が自信満々に嘘をつく
・ユーザーは見分けにくい
・事実と虚構が混在
・特に固有名詞で顕著
```

### ハルシネーション が起こる理由

#### 理由1：統計的パターンマッチング

```
LLM の本質：
「次の単語を予測する確率分布」

学習データ内に：
「太郎は医者で、診察を___」→ 「している」高確率
「花子は弁護士で、___」 → 「...」

類似パターンから：
「田中は（存在しない人物）で、___」
→ もっともらしい単語を生成
→ ハルシネーション
```

#### 理由2：学習データの不完全性

```
学習データに含まれていない情報は：
AI は「知らない」ではなく、推測で答える

例：
「2025 年の東京オリンピック」
学習データ（～2023 年 4 月）には存在しない
→「あると思われる情報」を生成
```

#### 理由3：確信度と事実性の分離

```
AI の構造：
・確信度 ≠ 事実性

「太陽は地球の周りを回っている」
確信度：90%（学習データに多く含まれる）
事実性：0%（実は逆）

AI は「確信度が高い」ものを返す
→ 事実でも根拠がなくても返す
```

（AI chọn dựa trên độ tin cậy thống kê, không phải sự thật）

#### 理由4：トレーニングデータの特性

```
学習データ内に存在する誤情報：
・ウェブ上の誤った情報
・古い情報
・個人の意見（事実ではない）

AI がこれを学習
→ 確信度高く、不正確な情報を返す
```

## 4. ハルシネーション の具体例

### 例1：架空の本

```
質問：「山田太郎著『AI の未来』について教えてください」

ChatGPT の応答（ハルシネーション）：
「山田太郎の『AI の未来』は、2020 年に発行され、
AI と人間の関係について深く考察した重要な著作です。
第 1 章では...」

事実：
「山田太郎」という著者も、『AI の未来』という書籍も存在しない
→ AI が完全に作り上げた
```

### 例2：存在しない学者

```
質問：「Dr. Robert Smith の論文『量子 AI の理論』について」

ChatGPT の応答（ハルシネーション）：
「Dr. Robert Smith は、2015 年に量子 AI の理論を提唱した
著名な研究者です。彼の論文は...」

事実：
存在しない学者で、学生が試験的に作った名前

注意：
確信を持って架空の経歴や論文を述べる
→ ユーザーが引用してしまう可能性がある
```

### 例3：誤った統計データ

```
質問：「日本の 2024 年の失業率は？」

ChatGPT の応答（ハルシネーション）：
「日本の 2024 年の失業率は 3.2% です」

事実：
・学習データ（～2023 年 4 月）には 2024 年データなし
・AI が推測で答えた可能性
→ 実際の失業率と異なる
```

### 例4：医学情報

```
質問：「頭痛に対する『クアチン200』という薬について」

ChatGPT の応答（ハルシネーション）：
「クアチン 200 は頭痛治療に一般的に使用される薬で、
処方箋が必要です。用量は...」

事実：
「クアチン 200」という薬は存在しない
→ 医学的なハルシネーション
→ 患者が危険にさらされる可能性
```

### 例5：URLやメールアドレス

```
質問：「OpenAI のカスタマーサポートのメールアドレスは？」

ChatGPT の応答（ハルシネーション）：
「support@openai-official.com です」

事実：
存在しないメールアドレス
→ ユーザーが詐欺サイトへ導かれる可能性
```

## 5. ハルシネーション への対策

### 対策1：ファクトチェック

```
生成AI の出力を、常に検証する習慣

方法：
1. 信頼できるソースで確認
2. 複数のソースで交差確認
3. 実例や引用がある場合、それを確認

例：
「Dr. Robert Smith の論文」
→ Google Scholar で検索
→ 存在しなければ、ハルシネーション
```

#### 対策2：知識カットオフの理解

```
「ChatGPT の学習データは 2023 年 4 月まで」
→ 2024 年以降の情報は信頼性低い

ユーザーの心構え：
「AI は最新情報は持っていない」
→ 最新データは別途確認
```

#### 対策3：プロンプトの工夫

```
❌ 不効果的：
「CEO の名前は？」

✅ 効果的：
「【重要】知らない場合は『わかりません』と答えてください。
推測で答えないでください。CEO の名前は何ですか？」

→ AI に「不確実性」を認識させる
```

#### 対策4：外部知識の統合

```
RAG（Retrieval-Augmented Generation）：
AI の回答 + 外部データベース検索

例：
ユーザー質問：「2024 年の株価は？」

AI の処理：
1. リアルタイムデータベースから 2024 年株価を取得
2. 取得したデータと組み合わせて回答
3. 根拠（出典）も提示

結果：
ハルシネーション削減
```

#### 対策5：モデルの選択

```
より大規模で最適化されたモデル：
ハルシネーション率が低い傾向

比較：
- GPT-3：ハルシネーション率 10～15%
- GPT-3.5：ハルシネーション率 5～10%
- GPT-4：ハルシネーション率 2～5%

ただし：
完全には排除不可
```

#### 対策6：信頼性スコアの表示

```
今後の改善方向：

AI が「この情報の信頼度は 60%」のように
確信度を表示

ユーザーが意思決定できる

例：
「この情報は学習データから推測したもので、
信頼度 40% です。ファクトチェックをお勧めします。」
```

## 6. ハルシネーション の種類

| 種類 | 説明 | 例 |
|------|------|-----|
| 存在物幻覚 | 存在しないものを生成 | 架空の本、著者 |
| 属性幻覚 | 誤った属性を付与 | 実在する人物が実在しない論文を書いた |
| 関係幻覚 | 存在しない関係を生成 | 実在しない人物同士の関係 |
| 推論幻覚 | 誤った推論 | 1+1=3 |
| 知識幻覚 | 古い或いは誤った知識 | 廃止された情報を現在も有効と述べる |

## 9. 確認問題

### 問題1
ハルシネーションの定義として正しいものはどれですか？

A) 事実でない情報を確信を持って生成
B) 偏りを放置する
C) 利用者の声を無視する
D) 対象を定めない

**答え**: A

**解説**: AI が統計的に「もっともらしい」内容を、事実のように述べる現象です。

---

### 問題2
LLM のハルシネーションの原因として正しいものはどれですか？

A) AI が故意に嘘をつく
B) 直感だけで判断する
C) 説明責任を果たさない
D) LLM が統計的にパターンマッチング → 確信度 ≠ 事実性

**答え**: D

**解説**: LLM は「次の単語の確率」に基づくため、事実性とは別に確信度が決まります。

---

### 問題3
ハルシネーションの具体例として正しいものはどれですか？

A) 失敗を否定する
B) 透明性を欠く
C) 被害を考えない
D) 架空の本、医学情報、存在しないメールアドレス

**答え**: D

**解説**: これらは典型的なハルシネーション例です。

---

### 問題4
ハルシネーション対策として正しいものはどれですか？

A) 一つの視点だけを見る
B) 利用者の意見を無視する
C) 新しいコンピュータを買う
D) ファクトチェック、RAG、プロンプト工夫、信頼性スコア表示

**答え**: D

**解説**: 複数の対策を組み合わせることでリスク軽減が可能です。

---

### 問題5
モデルの知識カットオフを示す代表例として正しいものはどれですか？

A) モデルの学習データの終了日（例：2023 年 4 月）
B) 偏ったデータで学習する
C) 説明責任を果たさない
D) 公平性を無視する

**答え**: A

**解説**: カットオフ後の情報は、AI は持っていないため、推測で答える可能性があります。

---

### 問題6
次のうち正しいものはどれですか？

A) 「太陽は地球の周りを回る」（学習データに多い→確信度高、事実性低）
B) 使いにくい操作を設計する
C) 関係者を見ない
D) 改善点を含めない

**答え**: A

**解説**: 古い情報が学習データに多いと、AI は高い確信度で述べますが、事実ではありません。

---

### 問題7
次のうち正しいものはどれですか？

A) 透明性を欠く
B) 過去の例だけに頼る
C) AI に新しいデータベース
D) 外部知識を検索して統合 → ハルシネーション削減

**答え**: D

**解説**: AI の回答に、信頼できる外部ソースの情報を統合する手法です。

---

### 問題8
次のうち正しいものはどれですか？

A) データの偏りを見ない
B) いいえ、LLM の本質的な特性→完全排除不可
C) はい、新しいモデルで解決
D) 見た目だけを重視する

**答え**: B

**解説**: より大規模なモデルでも、ハルシネーション は起こる可能性があります。

---

### 問題9
次のうち正しいものはどれですか？

A) 変化を予測しない
B) インターネットが遅くなる

D) ユーザーが誤った医学情報に基づいて治療 → 健康被害

**答え**: D

**解説**: 医学・法律・金融など、誤った情報が直接危害をもたらす分野は特に危険です。
