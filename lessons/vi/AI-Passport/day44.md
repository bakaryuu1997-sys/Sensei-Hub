## 3. 本日の内容

### AI 評価の基本

**定義**：AI が期待される通りに動作しているかを、数値や指標で確認すること。

（Đánh giá AI: đo lường hiệu suất và độ tin cậy của mô hình）

```
評価 = 期待値と実際の差を測ること
```

### 代表的な指標

#### 1. 精度（Accuracy）

```
全体のうち、正しく予測できた割合
```

#### 2. 再現率（Recall）

```
実際の正解のうち、検出できた割合
```

#### 3. 適合率（Precision）

```
予測が正解だった割合
```

#### 4. F1 スコア

```
精度と再現率のバランスを取った指標
```

#### 5. AUC / ROC

```
分類モデルの性能を曲線で評価する指標
```

### 実運用での評価

#### 1. 監視指標

```
予測精度、エラー率、応答時間などを継続監視する
```

#### 2. データドリフト

```
入力データの分布が時間とともに変化すること
```

#### 3. ラベルドリフト

```
正解データの分布が変化すること
```

#### 4. ユーザー評価

```
実際の利用者の満足度やフィードバックを確認する
```

### 改善サイクル

#### 1. 評価

```
現在の性能を測定する
```

#### 2. 原因分析

```
精度低下の要因を特定する
```

#### 3. 改善

```
データ追加、特徴量改善、モデル再学習を行う
```

#### 4. 再評価

```
改善後に再度性能を確認する
```

### モデル劣化の対策

#### 1. 定期再学習

```
新しいデータで定期的にモデルを更新する
```

#### 2. モニタリングアラート

```
性能が下がったら通知する仕組み
```

#### 3. A/B テスト

```
新旧モデルを比較し、安全に切り替える
```

#### 4. フォールバック

```
異常時は従来のルールベースに戻す
```

## 7. 確認問題


### 問題1

AI 評価で「精度（Accuracy）」は何を示しますか？

A) 正しく分類された割合
B) 速度
C) UI の見やすさ
D) データ量

**答え**: A

**解説**: 精度は全体の中で正しく分類された割合です。
**ベトナム語説明**: Độ chính xác là tỷ lệ dự đoán đúng trên tổng.

### 問題2

再現率（Recall）は何を重視しますか？

A) 速度
B) 実際に正しいものをどれだけ拾えたか
C) UI の色
D) データの圧縮率

**答え**: B

**解説**: 再現率は実際の正例をどれだけ見つけたかです。
**ベトナム語説明**: Recall đánh giá bao nhiêu trường hợp thật sự đúng được tìm thấy.

### 問題3

適合率（Precision）はどれを示しますか？

A) 予測が正しかった割合
B) データ量
C) 処理時間
D) UI を派手にした割合

**答え**: A

**解説**: 適合率は予測した正例のうち正しかった割合です。
**ベトナム語説明**: Precision là tỷ lệ trong số dự đoán đúng, có bao nhiêu là thật sự đúng.

### 問題4

F1 スコアは何の調和平均ですか？

A) コストと利益
B) 適合率と再現率
C) データ量とUI
D) 精度と速度

**答え**: B

**解説**: F1 は適合率と再現率の調和平均です。
**ベトナム語説明**: F1 là trung bình điều hòa giữa precision và recall.

### 問題5

AUC / ROC は何を評価しますか？

A) モデルの大きさ
B) UI のデザイン
C) データの圧縮率
D) 二値分類モデルの識別能力

**答え**: D

**解説**: AUC/ROC は分類器の識別能力を評価します。
**ベトナム語説明**: AUC/ROC đánh giá khả năng phân biệt của mô hình.

### 問題6

実運用での評価に含まれるものはどれ？

A) データドリフトやユーザー評価の監視
B) UI の色だけ
C) モデルのファイル名
D) バッテリー電力

**答え**: A

**解説**: 実運用ではデータドリフトやユーザー評価を監視します。
**ベトナム語説明**: Trong vận hành thực tế, giám sát drift dữ liệu và đánh giá người dùng.

### 問題7

データドリフトとは何ですか？

A) UI が変わること
B) 広告が増えること
C) 入力データの分布が変化すること
D) モデルが壊れること

**答え**: C

**解説**: データドリフトはデータ分布の変化を指します。
**ベトナム語説明**: Drift dữ liệu là sự thay đổi phân phối dữ liệu đầu vào.

### 問題8

ラベルドリフトはどのような変化ですか？

A) UI が変わること
B) 正解ラベルの分布が変わること
C) 速度が変わること
D) モデルの大きさが変わること

**答え**: B

**解説**: ラベルドリフトはラベル分布の変化です。
**ベトナム語説明**: Drift nhãn là sự thay đổi phân phối nhãn đúng.

### 問題9

評価サイクルで「原因分析」は何を目的とする？

A) UI を変えること
B) データを捨てること
C) 問題の根本原因を見つけること
D) 速度を上げること

**答え**: C

**解説**: 原因分析は問題の根本原因を特定するためです。
**ベトナム語説明**: Phân tích nguyên nhân tìm ra cội nguồn vấn đề.

### 問題10

評価後に行う「再評価」の意味は？

A) 速度を落とすこと
B) データを削除すること
C) UI を派手にすること
D) 改善後の効果を確認すること

**答え**: D

**解説**: 再評価は改善の効果を確認するステップです。
**ベトナム語説明**: Đánh giá lại xác nhận hiệu quả sau cải tiến.
