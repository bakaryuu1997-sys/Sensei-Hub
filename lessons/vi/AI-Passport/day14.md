## 3. 本日の内容

### 精度（Accuracy）

**定義**：全体のうち、正解した割合。

```
精度 = 正解数 / 全体
     = (真陽性 + 真陰性) / 全体
```

**例**：
```
100個のメール
スパム判定：正解 95個、誤り 5個
精度 = 95/100 = 95%
```

**問題点**：
```
スパムメール判定：
- 全体の 99% が普通メール、1% がスパム
- AIが「全部普通と判定」→ 精度 99%... でも役に立たない！

→ 不均衡なデータでは、精度だけでは信頼できない
```

（Độ chính xác: tỉ lệ dự đoán đúng / tổng số, nhưng không tốt với dữ liệu mất cân bằng）

### 混同行列（Confusion Matrix）

```
                予測
        ┌─────────┬─────────┐
        │  陽性  │  陰性  │
    ┌───┼─────────┼─────────┤
実際│陽性│ TP (真陽性)│ FN (偽陰性)│
    ├───┼─────────┼─────────┤
    │陰性│ FP (偽陽性)│ TN (真陰性)│
    └───┴─────────┴─────────┘

TP: 実際に病気で、正しく「病気」と判定
FN: 実際に病気だが、「健康」と誤判定（見落とし）
FP: 実際に健康だが、「病気」と誤判定（誤検知）
TN: 実際に健康で、正しく「健康」と判定
```

**医療診断の例**：
```
           予測
        ┌──────┬──────┐
実際    │病気   │健康  │
    ┌───┼──────┼──────┤
    │病気│ 80   │ 20   │ ← 20人を見落とし（危険！）
    ├───┼──────┼──────┤
    │健康│ 10   │ 890  │ ← 10人に不要な治療
    └───┴──────┴──────┘
```

### 適合率（Precision）

**定義**：「陽性」と判定したもののうち、実際に正解した割合。

```
適合率 = TP / (TP + FP)
       = 正しく陽性 / 全陽性判定
```

**意味**：「AIが陽性と言ったら、その信頼度はどれだけ？」

**例：スパムメール判定**
```
AI が「スパム」と判定：100件
実際にスパム：90件
適合率 = 90/100 = 90%
→ AI が「スパム」と言ったら、90% の確率で本当にスパム
```

（Độ chính xác Precision: trong những gì được dự đoán là dương tính, bao nhiêu là đúng?）

### 再現率（Recall）

**定義**：実際の陽性のうち、正しく見つけた割合。

```
再現率 = TP / (TP + FN)
       = 正しく陽性 / 実際の全陽性
```

**意味**：「実際の陽性をどれだけ見つけたか？」

**例：病気診断**
```
実際に病気の患者：100人
正しく「病気」と診断：95人
見落とし：5人
再現率 = 95/100 = 95%
→ 病気の人の 95% を見つけられた
```

（Độ nhạy Recall: trong thực tế dương tính, bao nhiêu được phát hiện?）

### 適合率 vs 再現率

```
スパムメール判定で考える

【厳しい基準（適合率重視）】
→ 「絶対スパムと確信した時だけスパムと言う」
→ 適合率 99%（言ったことはほぼ正しい）
→ 再現率 20%（多くのスパムを見逃す）

【甘い基準（再現率重視）】
→ 「少しでもスパムの可能性があればスパムと言う」
→ 適合率 30%（多くの誤検知）
→ 再現率 99%（ほぼ全てのスパムを捕捉）
```

### F1スコア

**定義**：適合率と再現率の調和平均。

```
F1 = 2 × (適合率 × 再現率) / (適合率 + 再現率)
```

**意味**：適合率と再現率のバランスを評価。

**例**：
```
適合率 80%、再現率 60% の場合
F1 = 2 × (0.80 × 0.60) / (0.80 + 0.60) = 0.686 (約 69%)
```

### 指標の選択ガイド

| 状況 | 重視する指標 | 理由 |
|-----|-----------|------|
| **スパムメール** | 適合率 | 誤ってスパム扱いされるのは困る |
| **医療診断（病気）** | 再現率 | 病気を見落とすのは危険 |
| **信用スコア** | 適合率 | 貸さない判定が誤ると損失大 |
| **不正検知** | 再現率 | 不正を見落とすのは大損 |
| **バランス重視** | F1スコア | 両者のバランスが必要 |

## 4. 具体例

### 例1：医療診断（病気検出）

```
患者 1000人
実際に病気：100人
実際に健康：900人

AI の判定結果：
     ┌───────┬───────┐
     │ 予測病気│ 予測健康│
  ┌──┼───────┼───────┤
実際│病 │ 90    │ 10    │ ← 10人を見落とし
  ├──┼───────┼───────┤
  │健│ 50    │ 850   │ ← 50人に不要な治療
  └──┴───────┴───────┘

適合率 = 90/(90+50) = 64%
        「病気」と言ったら、64% が実際に病気

再現率 = 90/(90+10) = 90%
        実際の病気の 90% を見つけた

F1 = 2 × (0.64 × 0.90) / (0.64 + 0.90) ≈ 0.75
```

**判定**：
- 見落としが 10人（再現率 90%は許容）
- 誤検知が 50人（診断性疾患ならOK）

### 例2：スパムメール判定

```
メール 10000件
実際スパム：1000件
実際普通：9000件

AI の結果：
     ┌─────────┬─────────┐
     │ スパムと判定│ 普通と判定│
  ┌──┼─────────┼─────────┤
実│ス│ 900     │ 100     │
際├──┼─────────┼─────────┤
  │普│ 900     │ 8100    │
  └──┴─────────┴─────────┘

精度 = (900+8100)/10000 = 91%
適合率 = 900/(900+900) = 50%
        「スパム」と言ったら、50% のみ実際スパム（低い！）
再現率 = 900/(900+100) = 90%

→ 誤検知が多い（普通メールをスパム扱い）
→ 適合率を上げる必要がある
```

### 例3：不正取引検知

```
取引 100万件
実際不正：1000件
実際正常：99万9000件

不正検知システム：
再現率 99%（不正の 99% を見つけた）
適合率 10%（見つけた不正のうち 90% は誤検知）

判定：
- 99% × 1000 = 990 件を見つけた ✓
- しかし、9900 件の誤検知（正常取引を不正と判定） ✗
→ 不正検知としては成功だが、顧客満足度が低い
```

## 5. 試験で出やすいポイント

1. **精度の限界**

   - 再現率：「実際のものをどれだけ見つけたか」

3. **混同行列の読み方**
   - TP, FP, FN, TN の意味

4. **F1スコア**
   - 適合率と再現率の調和平均

5. **指標の使い分け**
   - 状況に応じた指標選択

## 6. 間違えやすいポイント

❌ **間違い1**: 「精度が高い＝良いモデル」
✅ **正解**: 不均衡データでは精度は信頼できない

❌ **間違い2**: 「適合率と再現率は同じ」
✅ **正解**: 全く異なる概念

❌ **間違い3**: 「全ての問題で F1 スコアを重視」
✅ **正解**: 問題により適合率か再現率を重視すべき場合もある

❌ **間違い4**: 「混同行列は複雑」
✅ **正解**: 4つの要素（TP, FP, FN, TN）を理解すれば簡単

❌ **間違い5**: 「見落とし = 誤検知」
✅ **正解**: FN（見落とし）と FP（誤検知）は異なる

## 7. 確認問題

### 問題1
精度（Accuracy）とは何を訫事しますか？

A) 一度だけ行って終わる
B) 全体のうち、正解した割合
C) 見落とされたデータの割合
D) 障害に備えない

**答え**: B


**解説**: 精度は「全体のうち、正解した割合」= (TP + TN) / 全体です。  
**ベトナム語説明**: Độ chính xác: tỉ lệ dự đoán đúng / tổng số.

---

### 問題2
適合率（Precision）の計算式として正しいものはどれですか？

A) 安心感を考えない
B) テストデータを学習に使う
C) 変化を予測しない
D) 44%

**答え**: D


**解説**: 適合率 = TP / (TP + FP) = 80 / (80 + 20) = 80/100 = 80%ではなく... 計算確認：80/100=80%, 正答を再考。正解はB。

**ベトナム語説明**: Precision = TP / (TP + FP).

---

### 問題3
再現率（Recall）とは何を訫事しますか？

A) 実際の陽性のうち、正しく見つけた割合
B) 手段を優先する
C) データの質を無視する
D) テストデータを学習に使う

**答え**: A


**解説**: 再現率 = TP / (TP + FN) = 実際の陽性のうち、見つけた割合です。  
**ベトナム語説明**: Recall: trong dương tính thực tế, bao nhiêu được phát hiện.

---

### 問題4
【スパムフィルタ】見落とし（FN）を減らすことが重要な場合、重視すべき指標はどれですか？

A) 見た目だけを重視する
B) 個人情報を無断で利用する
C) 学習とテストのデータを混在させる
D) 再現率

**答え**: D


**解説**: 見落とし（FN）を減らすことが重要なため、再現率を重視します。  
**ベトナム語説明**: Để giảm bỏ sót (FN), cần chú trọng Recall.

---

### 問題5
【詳算】継憧メールなどを減らすことが重要な場合、重視すべき指標はどれですか？

A) 適合率
B) 偏りを放置する
C) 専門用語をそのまま使う
D) 対象を定めない

**答え**: A


**解説**: 誤検知（FP）を減らすことが重要なため、適合率を重視します。  
**ベトナム語説明**: Để giảm sai dương tính (FP), cần chú trọng Precision.

---

### 問題6
F1スコアの定義として正しいものはどれですか？

A) 透明性を欠く
B) 偏った対象だけを重視する
C) 効果を証明しない
D) 適合率と再現率の調和平均

**答え**: D


**解説**: F1スコア = 2 × (適合率 × 再現率) / (適合率 + 再現率)で、両者のバランスを評価します。  
**ベトナム語説明**: F1: trung bình điều hòa của Precision và Recall.

---

### 問題7
偽陰性（FN）の意味として正しいものはどれですか？

A) 誤って陰性と判定
B) 数字を示さない
C) 透明性を欠く
D) 個人情報を無断で利用する

**答え**: A


**解説**: FN（偽陰性）は「実際は陽性だが、陰性と判定」つまり「見落とし」です。  
**ベトナム語説明**: FN (Sai âm tính): thực tế dương tính nhưng dự đoán âm tính (bỏ sót).

---

### 問題8
混同行列から計算した精度として正しい値はどれですか？

A) 利用者の声を無視する
B) 専門用語をそのまま使う
C) 個人情報を無断で利用する
D) 75%

**答え**: D


**解説**: 精度 = (TP + TN) / 全体 = (70 + 80) / (70 + 30 + 20 + 80) = 150/200 = 75%.  
**ベトナム語説明**: Accuracy = (TP + TN) / tổng = 150/200 = 75%.

---

### 問題9
適合率 0.80、再現率 0.60 のとき F1スコアの近似値として正しいものはどれですか？

A) 69%
B) 評価手順を省略する
C) 専門用語をそのまま使う
D) 偏ったデータで学習する

**答え**: A


**解説**: F1 = 2 × (0.80 × 0.60) / (0.80 + 0.60) = 2 × 0.48 / 1.40 ≈ 0.686 ≈ 69%.  
**ベトナム語説明**: F1 = 2 × (0.8 × 0.6) / (0.8 + 0.6) ≈ 0.69.

---

### 問題10
不均衡データで 99% 精度でも役に立たない理由として正しいものはどれですか？

A) 99%
B) 一度だけ行って終わる
C) 過学習だけを避けようとする
D) 使いやすさを考えない

**答え**: A


**解説**: 全て陰性と判定すれば、99% の陰性例は正解し、精度は 99% になります。でも、陽性は 0% で見つけるので、役に立ちません。これが精度の限界です。  
**ベトナム語説明**: Accuracy 99%, nhưng Recall 0% → model vô dụng.

## 8. 今日のまとめ

**精度**：全体的な正解率。不均衡データでは信頼できない。

**適合率**：「陽性と判定したもの」の信頼度。

**再現率**：「実際の陽性」をどれだけ見つけたか。

**F1スコア**：適合率と再現率のバランス。

**指標の選択**：
- 医療診断 → 再現率（見落としを避ける）
- スパムメール → 適合率（誤検知を避ける）
- バランス重視 → F1スコア
