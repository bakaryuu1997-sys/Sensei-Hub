## 3. 本日の内容

### 教師なし学習とは

**定義**：「正解が付いていないデータ」から、自動的にパターンやグループを見つける。

```
入力（特徴のみ）
    ↓
機械学習
（正解なしで、自動的にパターンを探す）
    ↓
グループ化 / パターン発見 / 異常検知
（人間が結果を解釈）
```

**特徴**：
- 正解がないので、「正解」という概念がない
- 機械が自動的にデータの構造を見つける
- 結果の解釈は人間が行う

### 教師あり学習 vs 教師なし学習

| 項目 | 教師あり学習 | 教師なし学習 |
|-----|------------|------------|
| 正解データ | 必要 | 不要 |
| 入力 | 特徴 + 正解 | 特徴のみ |
| 出力 | 予測（正解に基づく） | グループ / パターン |
| 学習方法 | 「正解と比較」 | 「データの構造を探す」 |
| 例 | スパム判定、診断 | 顧客セグメント、異常検知 |

### 教師なし学習の2つの主要なタイプ

#### 1. クラスタリング（Clustering）

**定義**：似たデータを自動的にグループに分ける。

```
顧客データ
（名前、年齢、購入履歴など）
    ↓
クラスタリング
    ↓
グループA（若い女性）
グループB（中年男性）
グループC（高齢者）
```

##### K-means クラスタリング

**最も一般的なアルゴリズム**

```
ステップ1: K個の中心点をランダムに設定
           （例：K=3なら、3グループに分ける）
   ↓
ステップ2: 各データを最も近い中心点にあてがう
   ↓
ステップ3: 各グループの平均を計算し、新しい中心点にする
   ↓
ステップ4: ステップ2～3を繰り返す
   ↓
安定化したら終了
```

**視覚化**：
```
グループ1の中心● ─── データ・データ・データ
グループ2の中心● ─── データ・データ・データ
グループ3の中心● ─── データ・データ・データ
```

#### 2. 次元削減（Dimensionality Reduction）

**定義**：多くの特徴を持つデータから、最も重要な特徴だけを抽出する。

```
元のデータ
特徴1（年齢）
特徴2（収入）
特徴3（購入回数）
特徴4（滞在時間）
特徴5（クリック数）
... 50個の特徴
    ↓
次元削減
    ↓
最も重要な特徴だけ
特徴A（顧客価値）
特徴B（購買活動）
（2～3個の特徴に削減）
```

**メリット**：
- データを可視化しやすくなる
- 計算速度が速くなる
- ノイズが減り、精度が上がる

##### 主成分分析（PCA）

```
例：学生データ
数学の成績、英語の成績、国語の成績...
    ↓
PCA
    ↓
主成分1：「全体的な学力」
主成分2：「理系 vs 文系」
（2つの主成分で、ほぼ説明可能）
```

### クラスタリングの活用例

#### 1. 顧客セグメンテーション

```
データ：10万人の顧客
特徴：年齢、収入、購買頻度、平均購入額
    ↓
クラスタリング（K=5）
    ↓
グループA：VIP（高額購買者）
グループB：頻繁利用者（多く買う）
グループC：時々利用者
グループD：新規顧客
グループE：休止中
```

**ビジネス活用**：
- グループAには VIP サービス
- グループDには 新規顧客割引
- グループEには 再活性化キャンペーン

#### 2. 異常検知

```
データ：毎日のサーバーアクセス数
通常：1000～2000件/日
    ↓
ある日：突然100万件
    ↓
クラスタリング
→ この日は「異常グループ」に分類
→ DDoS 攻撃の可能性を検知
```

### 次元削減の活用例

#### 1. データ可視化

```
元のデータ：50個の特徴
    ↓
PCA で 2 次元に削減
    ↓
2D グラフに表示可能
（コンピューター画面で可視化）
    ↓
グループの分布が一目瞭然
```

#### 2. 画像圧縮

```
元の画像：100万ピクセル × RGB（300万次元）
    ↓
次元削減
    ↓
10万ピクセル × RGB（30万次元）
    ↓
ファイルサイズ：1/10 に削減
品質：ほぼ同じ
```

## 4. 具体例

### 例1：SNS ユーザーのセグメンテーション

**データ**：
- ツイート数
- フォロワー数
- 平均いいね数
- リツイート率

**クラスタリング結果**：
- グループA：インフルエンサー（多くのフォロワー、高いエンゲージメント）
- グループB：アクティブユーザー（多くツイート、中程度のエンゲージメント）
- グループC：ライトユーザー（少数ツイート）

**マーケティング活用**：
- グループAには 広告配信
- グループBには コンテンスト参加呼びかけ

### 例2：不正取引検知

**データ**：クレジットカード取引
- 取引額
- 取引場所
- 取引時間
- 過去との比較

**クラスタリング結果**：
- 正常クラスター：通常のパターン
- 異常クラスター：不正の可能性
  - 深夜の大額取引
  - 通常と異なる場所からの取引
  - 高速連続取引

### 例3：ニュース記事の自動分類

**データ**：記事テキスト（正解ラベルなし）

**クラスタリング結果**：
- グループA：政治関連
- グループB：スポーツ関連
- グループC：テクノロジー関連
- グループD：エンタメ関連

（人間が後から「このグループは政治」と解釈）

## 5. 試験で出やすいポイント

1. **教師なし学習の定義**
   - 正解なしのデータからパターンを見つける

2. **クラスタリング vs 次元削減**
   - クラスタリング：グループ化
   - 次元削減：特徴削減

3. **教師あり vs 教師なし**
   - あり：正解が必要
   - なし：正解が不要

4. **K-means の基本**
   - K個に分ける、繰り返す

5. **活用場面**
   - 顧客セグメント、異常検知など

---

## 6. 間違えやすいポイント

- 正解がないからといって何でも教師なし学習になるわけではない。
- クラスタリングと次元削減の違いを混同しない。
- 訓練データとテストデータの役割を忘れない。
- K の選び方を適当にしない。
- 結果の解釈は人間の判断が必要である。

## 7. 確認問題

### 問題1
教師なし学習（Unsupervised Learning）とは何ですか？

A) 結論がない
B) 正解なしのデータからパターンを自動発見
C) 社会の影響を考えない
D) 監査を避ける

**答え**: B

**解説**: 教師なし学習は、「正解が付いていないデータ」から、機械が自動的にグループやパターンを見つける方法です。  
**ベトナム語説明**: Học không giám sát: không dữ liệu có nhãn, máy tự tìm mô hình.

---

### 問題2
クラスタリング（Clustering）の目的は何ですか？

A) 似たデータを自動グループ化
B) 対象を定めない
C) 目的を明確にしない
D) 手段を優先する

**答え**: A

**解説**: クラスタリングは、類似したデータを自動的にグループに分ける技術です。  
**ベトナム語説明**: Phân cụm: tự động nhóm dữ liệu tương tự lại với nhau.

---

### 問題3K-meansアルゴリズムでの"K"は何を訫事しますか？
A) 専門用語をそのまま使う
B) 障害に備えない
C) テストデータを使ってモデルを選ぶ
D) グループの個数

**答え**: D

**解説**: K は、データを分けるグループの個数を表します。K=3なら3グループ、K=5なら5グループです。  
**ベトナム語説明**: K = số cụm (nhóm) muốn chia dữ liệu.

---

### 問題4
次元削減（Dimensionality Reduction）の目的は何ですか？

A) 対象を定めない
B) 重要性を無視する
C) データを可視化、計算速度を上げ、ノイズを減らす
D) 手段を優先する

**答え**: C

**解説**: 次元削減により、高次元データを低次元に変換し、可視化、高速化、ノイズ除去を実現します。  
**ベトナム語説明**: Giảm chiều: hình dung, tốc độ, giảm nhiễu.

---

### 問題5
教師なし学習が効果的な場合はどれですか？

A) 正解が明確で豊富な場合
B) 検証を省略する
C) 正解がない、または正解の定義が難しい場合
D) 結論がない

**答え**: C

**解説**: 顧客セグメンテーション、異常検知など、「正解が定義しにくい問題」で教師なし学習が活躍します。  
**ベトナム語説明**: Học không giám sát phù hợp: không rõ đáp án hoặc định nghĩa khó.

## 8. 今日のまとめ

教師なし学習は、**「正解がないデータ」から自動的にパターンを見つける**方法です。

2つの主要なタイプがあります：
- **クラスタリング**：似たデータをグループ化（顧客セグメント、異常検知など）
- **次元削減**：重要な特徴だけ抽出（データ可視化、画像圧縮など）

教師あり学習とは異なり、正解がないので、結果の解釈は人間が行う必要があります。

K-means は最も一般的なクラスタリング手法です。
