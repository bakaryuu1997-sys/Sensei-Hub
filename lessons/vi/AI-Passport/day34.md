## 3. 本日の内容

### プライバシーと個人情報

**定義**：プライバシーは人の生活や情報を守る概念。個人情報は個人を特定できるデータ。

（Quyền riêng tư: bảo vệ thông tin cá nhân khỏi sự xâm phạm）

```
氏名、住所、電話番号、メールアドレス、位置情報、顔画像、健康情報 など
```

### データ保護の基本原則

#### 1. 目的限定

```
収集目的を明確にし、その目的以外に使わない
```

#### 2. 最小化

```
必要な情報だけを収集する
```

#### 3. 正確性

```
データを正しく保ち、古い情報は更新・削除する
```

#### 4. 保管期間の制限

```
目的達成後は不要データを削除する
```

#### 5. 安全管理

```
アクセス制御や暗号化で保護する
```

### AI とプライバシーのリスク

#### 1. 学習データの漏洩

```
個人情報が含まれたデータが外部に流出する可能性
```

#### 2. モデル反転攻撃

```
公開されたモデルから訓練データを再構築する攻撃
```

#### 3. データの無断利用

```
同意なしに音声や映像、個人履歴を学習に利用する
```

### 対策技術

#### 1. 匿名化・疑似匿名化

```
個人を特定できない形にする
```

#### 2. 差分プライバシー

```
統計解析にノイズを加え、個人の特定を防ぐ
```

#### 3. セキュアなデータ管理

```
アクセス権限、ログ監視、暗号化を徹底する
```

#### 4. 同意の明確化

```
何を、なぜ使うかを利用者に理解させて同意を得る
```

### 具体例

#### 例1：音声アシスタント

```
「OK Google」などが聞き取った会話が意図せず記録されるリスク
```

#### 例2：健康データ分析

```
健康診断結果をAIで解析する場合、個人の病歴が漏れると重大
```

#### 例3：位置情報の追跡

```
行動履歴から個人の生活パターンを推測されるリスク
```

## 4. 法律と規制の例

### 1. GDPR（EU）

```
個人データの利用を厳格に制限し、同意と権利を保護する
```

### 2. 個人情報保護法（日本）

```
第三者提供や匿名加工情報に関するルールを定める
```

### 3. CCPA（米国カリフォルニア州）

```
消費者が自分のデータ利用を管理できる権利を与える
```

## 7. 確認問題


### 問題1

「目的限定」はデータ保護の原則で何を意味しますか？

A) 収集目的を明確にしてその目的でのみ使う
B) データを無期限に保存する
C) すべてのデータを公開する
D) AI に任せる

**答え**: A

**解説**: 目的限定はデータを収集した目的以外に使わないことです。
**ベトナム語説明**: Mục đích hạn chế là chỉ dùng dữ liệu cho mục đích đã xác định.

### 問題2

データ最小化の考え方は何ですか？

A) 必要最低限のデータだけを扱う
B) ユーザーに知らせない
C) できるだけ多くのデータを集める
D) データを全自動で保存する

**答え**: A

**解説**: 最小化は収集・保持するデータを最小限にすることです。
**ベトナム語説明**: Tối thiểu hóa là chỉ thu thập dữ liệu cần thiết nhất.

### 問題3

差分プライバシーは何を守りますか？

A) 個々の情報が特定されないようにする
B) モデルの速度を上げる
C) データを圧縮する
D) UI を改善する

**答え**: A

**解説**: 差分プライバシーは個人の特定を防ぐ技術です。
**ベトナム語説明**: Bảo mật sai phân ngăn thông tin cá nhân bị xác định.

### 問題4

モデル反転攻撃のリスクはどれですか？

A) 電力が増える
B) UI が壊れる
C) 学習データから個人情報が再構築される可能性
D) 速度が遅くなる

**答え**: C

**解説**: モデル反転はモデルから訓練データを逆算される攻撃です。
**ベトナム語説明**: Tấn công đảo mô hình có thể phục hồi dữ liệu huấn luyện.

### 問題5

匿名化の目的は何ですか？

A) 個人を識別できないようにすること
B) アクセス制御を外すこと
C) データを削除すること
D) モデルを学習させること

**答え**: A

**解説**: 匿名化は個人が識別されないようにする処理です。
**ベトナム語説明**: Ẩn danh giúp không thể xác định cá nhân.

### 問題6

セキュアなデータ管理で重要な対策はどれですか？

A) データを公開すること
B) ログを消すこと
C) データを複製すること
D) 暗号化とアクセス制御

**答え**: D

**解説**: 暗号化とアクセス制御はデータ管理の基本です。
**ベトナム語説明**: Mã hóa và kiểm soát truy cập là cơ bản cho dữ liệu an toàn.

### 問題7

同意の明確化が必要な理由は？

A) データを増やすため
B) AI の性能を上げるため
C) モデルを速くするため
D) 利用者がデータ利用を理解できるようにするため

**答え**: D

**解説**: 同意を明確にすることで利用者はデータ利用を理解できます。
**ベトナム語説明**: Làm rõ đồng ý giúp người dùng hiểu cách dùng dữ liệu.

### 問題8

AI とプライバシーのリスクに含まれないのはどれですか？

A) モデル反転
B) 無断利用
C) データ漏洩
D) 画面の色

**答え**: D

**解説**: 画面の色はプライバシーリスクとは直接関係ありません。
**ベトナム語説明**: Màu màn hình không phải là rủi ro riêng tư.

### 問題9

学習データの漏洩を防ぐために重要なのは？

A) モデルを大きくする
B) アクセス管理と暗号化
C) ファイル名を変えるだけ
D) UI を改善する

**答え**: B

**解説**: アクセス管理と暗号化は漏洩防止に重要です。
**ベトナム語説明**: Quản lý truy cập và mã hóa giúp ngăn rò rỉ dữ liệu.

### 問題10

AI のプライバシー対策で「目的以外の利用をしない」ことは何と呼ぶ？

A) 目的限定
B) 正確性
C) 安全管理
D) 最小化

**答え**: A

**解説**: 目的限定は収集目的以外で使わない原則です。
**ベトナム語説明**: Mục đích hạn chế là không dùng dữ liệu ngoài mục đích đã định.
