## 3. 本日の内容

### 過学習（Overfitting）とは

**定義**：モデルが学習データに「過度に最適化」され、新しいデータに対応できなくなる現象。

（Quá khớp: mô hình học thuộc lòng dữ liệu huấn luyện → không khái quát được dữ liệu mới）

```
学習データ
  ↓
モデルが「すべてを完璧に覚える」
  ↓
学習データ精度：99%
  ↓
新しいデータ精度：40%... 失敗！
```

**過学習のイメージ**：
```
学習データ（10個の点）
      ● ● ●
    ●   ● ●
  ●       ●
      ● ● ●

過学習：複雑な曲線で全ての点を通す
        （新しい点には対応できない）

適切：簡単な直線で大まかに傾向をつかむ
        （新しい点にも対応）
```

### 未学習（Underfitting）とは

**定義**：モデルが十分に学習できず、学習データすら精度が低い。

（Học thiếu: mô hình quá đơn giản → không hiểu dữ liệu）

```
未学習の場合
  ↓
学習データ精度：60%
テストデータ精度：55%
  ↓
（両方低い = 学習が不十分）
```

**未学習のイメージ**：
```
学習データ（複雑な分布）
      ● ● ●
    ●   ● ●
  ●       ●
      ● ● ●

未学習：単純な直線
        （データの複雑さを捉えられない）

適切：複雑さと単純さのバランス
```

### 過学習 vs 未学習 vs 適切

| 状態 | 学習精度 | テスト精度 | 原因 | 解決法 |
|-----|--------|---------|------|------|
| **未学習** | 低い | 低い | モデルが簡単すぎ | 複雑さ↑、データ↑、学習時間↑ |
| **適切** | 高い | 高い | バランスが取れている | 現状維持 |
| **過学習** | 非常に高い | 低い | モデルが複雑すぎ | 正則化、早期停止、データ↑ |

### 過学習の原因

#### 1. モデルが複雑すぎ
```
シンプルな問題に複雑なモデル
  ↓
「これはこの値、これはあの値」と全部覚える
  ↓
ノイズまで覚えてしまう
```

#### 2. 学習データが少ない
```
10個の点 → モデルが全部覚える
100万個の点 → ノイズが目立つ、覚えきれない
```

#### 3. 学習が長すぎ
```
ステップ1～100：精度が上がる
ステップ101～1000：データを「覚える」に変わる
```

### 過学習の解決方法

#### 1. 正則化（Regularization）

**定義**：モデルの複雑さにペナルティを与える。

```
L1 正則化（ラッソ回帰）
損失関数 = 予測誤差 + λ × |重み|
           ↑            ↑
        学習          複雑さへのペナルティ

複雑なモデル → ペナルティが増加 → 最適化時に避ける
```

#### 2. 早期停止（Early Stopping）

```
ステップ1～100：学習データ精度↑、テスト精度↑
ステップ101～：学習データ精度↑、テスト精度↓（過学習開始！）
       ↓
ステップ100で停止（過学習前に止める）
```

#### 3. データ増強（Data Augmentation）

```
データ 100個 → 過学習リスク高い
  ↓
増強（回転、ノイズ追加など）
  ↓
データ 1000個 → 過学習リスク低い
```

#### 4. ドロップアウト（Dropout）

```
ニューラルネット内の一部のニューロンを、
ランダムに「オフ」にする
  ↓
モデルが複数のサブモデルを学ぶ効果
  ↓
過学習が減る
```

### 学習曲線で診断

```
適切な学習：
精度 ↑
  │     テスト精度
  │    /
  │   /
  │  /―――― (収束)
  │ /
  └─────→ 学習ステップ

過学習：
精度 ↑
  │     学習精度 ―――
  │    /│
  │   / │ テスト精度
  │  /  │ ↓（低下！）
  │ /   │
  └─────→ 学習ステップ

未学習：
精度 ↑
  │  
  │   ―― 学習精度
  │  /
  │ / (上昇が遅い)
  │/
  └─────→ 学習ステップ
```

### バイアス・分散トレードオフ

```
バイアス：モデルの系統的なエラー
分散：結果のばらつき

未学習：高バイアス、低分散
        （常に同じ低い精度）

適切：中程度のバイアス、中程度の分散
      （高い精度）

過学習：低バイアス、高分散
        （学習データでは高、テストでは低）
```

## 4. 具体例

### 例1：手書き数字認識

**未学習の場合**：
```
モデル：単純な線形回帰
精度：学習 70%、テスト 68%
→ モデルが複雑さを理解できない
→ 解決：ニューラルネットを使う
```

**適切な場合**：
```
モデル：中層ニューラルネット
精度：学習 95%、テスト 93%
→ バランスが取れている
```

**過学習の場合**：
```
モデル：100層の深いニューラルネット
精度：学習 99.9%、テスト 70%
→ 学習データを「覚えている」
→ 解決：ドロップアウト、正則化を使う
```

### 例2：不動産価格予測

**未学習**：
```
特徴：面積のみ
精度：低い
→ 築年数、立地などの情報を使わない
```

**適切**：
```
特徴：面積、築年数、立地、駅距離など
精度：学習 88%、テスト 85%
```

**過学習**：
```
特徴：面積、築年数、立地...と無関係な特徴も大量に追加
精度：学習 99%、テスト 50%
```

## 5. 試験で出やすいポイント

1. **過学習の定義**
   - 学習データには精度が高いが、テストで低い

2. **未学習の定義**
   - 学習データにも精度が低い

3. **原因と解決法**
   - 過学習：正則化、早期停止、データ増強
   - 未学習：モデルを複雑に、データを増やす

4. **学習曲線の読み方**
   - グラフから過学習・未学習を判断

5. **バイアス・分散トレードオフ**
   - 完全にはトレードオフが存在

---

## 6. 間違えやすいポイント

❌ **間違い1**: 「学習精度が高い＝良いモデル」
✅ **正解**: テスト精度も高くないと意味がない

❌ **間違い2**: 「データはいくらあっても良い」
✅ **正解**: 低質なデータは逆に害になる

❌ **間違い3**: 「複雑なモデルは常に優れている」
✅ **正解**: シンプルでバランスが取れたモデルが最良

❌ **間違い4**: 「過学習は悪い、避けるべき」
✅ **正解**: ある程度の過学習は必要、完全には避けられない

❌ **間違い5**: 「早期停止＝常に良い」
✅ **正解**: 問題によって、早期停止がベストとは限らない

## 7. 確認問題

### 問題1
過学習（Overfitting）とは何ですか？

A) 学習データに過度に最適化され、新データに対応できなくなる
B) 対象を限定しすぎる
C) 結果だけを求める
D) テストデータで精度が高い

**答え**: A


**解説**: 過学習は「学習データは完璧だが、新しいデータでは精度が低い」という現象です。  
**ベトナム語説明**: Quá khớp: mô hình học thuộc lòng dữ liệu huấn luyện → không đúng trên dữ liệu mới.

---

### 問題2
未学習（Underfitting）とは何ですか？

A) 学習データ精度が非常に高い
B) 学習データ精度も低く、テスト精度も低い
C) 結果だけを求める
D) ルールより速度を優先する

**答え**: B


**解説**: 未学習は、モデルが十分に学習できていないため、学習データ精度もテスト精度も低いのが特徴です。  
**ベトナム語説明**: Học thiếu: độ chính xác trên cả dữ liệu huấn luyện và kiểm tra đều thấp.

---

### 問題3
過学習を減らす方法として正しいものはどれですか？

A) テストデータを使って学習する
B) 対象を定めない
C) 監査を避ける
D) 正則化、早期停止、データ増強

**答え**: D


**解説**: 正則化、早期停止、データ増強などの方法で、過学習を減らせます。  
**ベトナム語説明**: Giảm quá khớp: chính quy hóa, dừng sớm, tăng dữ liệu.

---

### 問題4過学習の的型的な信号として正しいものはどれですか？
A) 過学習だけを避けようとする
B) 学習精度は上がるが、テスト精度が下がり始める
C) 学習精度と テスト精度が一緒に上がる
D) 個人情報を無断で利用する

**答え**: B


**解説**: 過学習では、学習を進めても学習精度は上がるのに、テスト精度が下がり始めるのが典型的です。  
**ベトナム語説明**: Tín hiệu quá khớp: độ chính xác trên dữ liệu huấn luyện ↑, nhưng trên dữ liệu kiểm tra ↓.

---

### 問題5「早期停止」（Early Stopping）とは何ですか？
A) テスト精度が下がり始めたら学習を止める
B) 結果だけを求める
C) 被害を考えない
D) ランダムに学習を止める

**答え**: A


**解説**: 早期停止は、テスト精度が低下し始めたら学習を中断し、過学習を防ぐ方法です。  
**ベトナム語説明**: Dừng sớm: khi độ chính xác kiểm tra bắt đầu giảm → dừng huấn luyện.

---

### 問題6
ドロップアウトの目的として正しいものはどれですか？

A) ニューロンをランダムに「オフ」にして過学習を減らす
B) 評価手順を省略する
C) 失敗を否定する
D) 結果を確認せず次に進む

**答え**: A


**解説**: ドロップアウトは、ニューラルネットの一部ニューロンをランダムに無効化し、過学習を減らす技術です。  
**ベトナム語説明**: Dropout: tắt ngẫu nhiên một số neuron → giảm quá khớp.

---

### 問題7
データ増強による効果として正しいものはどれですか？

A) テストデータを学習に使う
B) 失敗を否定する
C) 一度だけ行って終わる
D) データの量を増やし、過学習を減らす

**答え**: D


**解説**: データ増強で、回転、ノイズ追加などにより、見かけ上のデータ量を増やし、過学習リスクを低減させます。  
**ベトナム語説明**: Tăng dữ liệu: thêm dữ liệu nhân tạo → giảm quá khớp.

---

### 問題8
未学習を改善する方法として正しいものはどれですか？

A) 説明責任を果たさない
B) テストデータを使ってモデルを選ぶ
C) 過学習だけを避けようとする
D) モデルを複雑にする、データを増やす、学習時間を増やす

**答え**: D


**解説**: 未学習は、モデルが簡単すぎる、または学習が不十分なため、モデルを複雑にしたり、データやステップを増やしたりして改善します。  
**ベトナム語説明**: Cải thiện học thiếu: mô hình phức tạp hơn + dữ liệu nhiều hơn + học lâu hơn.

---

### 問題9
バイアスと分散の関係として正しい説明はどれですか？

A) バイアスを減らすと分散が増え、逆も同じ（トレードオフ関係）
B) 更新を怠る
C) 見た目だけを重視する
D) 対象を定めない

**答え**: A


**解説**: 複雑なモデルはバイアスは低いが分散が高く、シンプルなモデルはその逆という、トレードオフ関係があります。  
**ベトナム語説明**: Đánh đổi sai lệch-phương sai: giảm sai lệch → tăng phương sai (hoặc ngược lại).

---

### 問題10
学習精度が高くテスト精度が低い状態は何ですか？

A) 偏りを放置する
B) 利用者の意見を無視する
C) 過学習
D) データの偏りを見ない

**答え**: C


**解説**: この状況は典型的な過学習です。モデルが学習データを「覚えている」ので、学習精度は高いが、新しいデータ（テスト）では対応できません。  
**ベトナム語説明**: Độ chính xác huấn luyện cao, kiểm tra thấp = quá khớp.

## 8. 今日のまとめ

**過学習**：学習データに過度に最適化され、テスト精度が低い状態。

**未学習**：モデルが十分に学習できず、両方の精度が低い状態。

**適切な学習**：学習精度もテスト精度も高い、バランスの取れた状態。

**解決法**：
- 過学習 → 正則化、早期停止、データ増強、ドロップアウト
- 未学習 → モデルを複雑に、データを増やす、学習時間を増やす

学習曲線を読み取ることで、過学習・未学習を診断できます。
