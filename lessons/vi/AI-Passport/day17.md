## 3. 本日の内容

### ニューロンの計算式

**ニューロンは以下の計算を行う**：

```
y = f(Σ(w × x) + b)

y: 出力
f: 活性化関数
w: 重み
x: 入力
b: バイアス
Σ: 合計
```

**例**：

```
入力：x1 = 2, x2 = 3, x3 = 1
重み：w1 = 0.5, w2 = 0.3, w3 = 0.2
バイアス：b = 0.1
活性化関数：ReLU

計算：
ステップ1: 重み付き和 = (0.5 × 2) + (0.3 × 3) + (0.2 × 1) + 0.1
                    = 1 + 0.9 + 0.2 + 0.1 = 2.2

ステップ2: 活性化関数を適用 = ReLU(2.2) = 2.2
                          （ReLU は負の値を 0 にするだけ）

出力：y = 2.2
```

（Mỗi neuron: y = f(Σ(w × x) + b) - tính toán như vậy）

### 重み（Weight）の役割

**定義**：入力に対する「重要度」を制御するパラメーター。

```
重みが大きい入力
→ 最終的な出力に大きく影響

重みが小さい入力
→ 最終的な出力に小さく影響

重みが負
→ 入力が増えると出力が減る
```

**例：病気診断**

```
入力1（年齢）：w1 = 0.3
入力2（体温）：w2 = 0.8
入力3（症状）：w3 = 0.5

体温の重みが大きい（0.8）
→ 体温の変化が診断に大きく影響
```

### バイアス（Bias）の役割

**定義**：ニューロンが「どのくらい簡単に活性化するか」を制御するパラメーター。

```
バイアスが大きい（正）
→ 重み付き和が小さくても活性化しやすい

バイアスが小さい（負）
→ 重み付き和が大きくても活性化しにくい

バイアス = 0 がない場合の「しきい値」
```

**例**：

```
バイアスなし：
y = f(0.5 × x)
→ x = 0 の時も常に f(0) で評価

バイアスあり：
y = f(0.5 × x + 2)
→ x = 0 の時は f(2) で評価
→ より柔軟なモデル
```

### 重み × 入力 vs バイアス

| 要素 | 役割 | 例 |
|-----|------|-----|
| **重み** | 入力の「重要度」 | 体温は重要（w 大）、気分は重要度低い（w 小） |
| **バイアス** | ニューロンの「活性化しやすさ」 | 元々活性化しやすい疾患ならバイアス大 |

### 損失関数（Loss Function）

**定義**：予測値と実際の値がどれだけ異なるかを数値化。

```
損失 = |予測値 - 実際の値|
```

**例：分類問題**

```
実際：犬（ラベル = 1）
予測：犬である確率 0.8
損失：小さい（正解に近い）

実際：犬（ラベル = 1）
予測：猫である確率 0.1
損失：大きい（正解と遠い）
```

### 勾配降下法（Gradient Descent）

**定義**：損失を最小化するために、重みを反復的に更新する学習アルゴリズム。

```
ステップ1: ランダムな重みで開始
   ↓
ステップ2: 予測を計算、損失を計算
   ↓
ステップ3: 「損失を減らすには、どの方向に重みを変えるべき？」
          を計算（勾配を計算）
   ↓
ステップ4: 重みを少し更新
   重み = 重み - (学習率 × 勾配)
   ↓
ステップ5: ステップ2～4を繰り返す
   ↓
損失が収束したら終了
```

**視覚化**：

```
損失
  │     ●●
  │   ●●
  │  ●
  │ ●
  │●
  └───────────→ 重み

●の軌跡が谷（最小値）に向かって移動
= 勾配降下法の動作
```

### 学習率（Learning Rate）

**定義**：各ステップで重みをどのくらい変えるかを制御。

```
学習率が大きい
→ 大きく更新（速く学習、ただし最小値を飛ばすリスク）

学習率が小さい
→ 少しずつ更新（ゆっくり学習、安定）
```

**例**：

```
学習率 = 0.1（大きい）
重みの更新が大きく、速く収束するが不安定

学習率 = 0.001（小さい）
重みの更新が小さく、ゆっくり収束、安定
```

### バックプロパゲーション（Backpropagation）

**定義**：出力層から入力層へ、勾配を逆伝播させて、すべての重みを効率的に更新する方法。

```
フォワード（予測）
入力 → 隠れ層 → 出力 → 損失を計算

バックプロパゲーション（学習）
出力層の勾配を計算
   ↓
隠れ層の勾配を計算（出力層から逆伝播）
   ↓
入力層の勾配を計算（隠れ層から逆伝播）
   ↓
全ての重みを更新
```

## 4. 具体例

### 例1：シンプルなニューロン学習

```
問題：温度と湿度から、雨が降るか予測

ニューロン：
入力1（温度）：x1 = 25
入力2（湿度）：x2 = 80
重み1：w1 = 初期値 0.3
重み2：w2 = 初期値 0.1
バイアス：b = 0.2

ステップ1（初期化）：
重み = [0.3, 0.1], バイアス = 0.2

ステップ2（予測）：
y = σ(0.3 × 25 + 0.1 × 80 + 0.2)
  = σ(7.5 + 8 + 0.2) = σ(15.7) ≈ 0.99
  → 「雨が降る確率 99%」

ステップ3（実際）：
実際に雨が降った（正解 = 1）
損失 = 小さい（予測が正しかった）

ステップ4（学習）：
損失がすでに小さいため、重みはあまり変わらない
```

### 例2：重みの調整プロセス

```
初期状態：w = 0.5 で、損失 = 0.3（大きい）
   ↓
イテレーション1：w を 0.55 に更新 → 損失 = 0.25（減少）
   ↓
イテレーション2：w を 0.60 に更新 → 損失 = 0.15（減少）
   ↓
イテレーション3：w を 0.62 に更新 → 損失 = 0.10（減少）
   ↓
イテレーション4：w を 0.63 に更新 → 損失 = 0.09（ほぼ変わらず）
   ↓
収束（w ≈ 0.63 が最適）
```

### 例3：学習率の影響

```
学習率 0.1（大きい）：
w: 0.5 → 0.6 → 0.8 → 1.2 → 0.9 → ...（不安定に振動）

学習率 0.001（小さい）：
w: 0.5 → 0.501 → 0.502 → 0.503 → ...（ゆっくり確実）
```

## 5. 試験で出やすいポイント

1. **ニューロンの計算式**
   - y = f(Σ(w × x) + b)

2. **重みの役割**
   - 入力の「重要度」を制御

3. **バイアスの役割**
   - ニューロンの「活性化しやすさ」を制御

4. **勾配降下法**
   - 損失を最小化する学習アルゴリズム

5. **学習率の影響**
   - 大きい = 速く、不安定 / 小さい = 遅く、安定

## 6. 間違えやすいポイント

❌ **間違い1**: 「重みとバイアスは同じ」
✅ **正解**: 重みは入力の重要度、バイアスは活性化しやすさ

❌ **間違い2**: 「勾配降下法は常に最適値に到達」
✅ **正解**: 局所最適値に陥ることもある

❌ **間違い3**: 「学習率は大きいほど良い」
✅ **正解**: 大きすぎると不安定、小さすぎると遅い

❌ **間違い4**: 「バイアスなしでも大丈夫」
✅ **正解**: バイアスはモデルの表現力を大幅に向上させる

❌ **間違い5**: 「重みは固定値」
✅ **正解**: 学習中に継続的に更新される

## 7. 確認問題

### 問題1
ニューロンの基本的な数学的表現として正しいものはどれですか？

A) y = f(Σ(w × x) + b)
B) 見た目だけを重視する
C) 多様性を無視する
D) ルールより速度を優先する

**答え**: A


**解説**: ニューロンは、重み付き入力の合計にバイアスを加え、活性化関数で変換します。

---

### 問題2ニューラルネットワークの学習で、新しいダータに対する予測精度を改善する鍵を打つというをどれですか？
A) 評価手順を省略する
B) ニューロンを活性化する
C) 学習とテストのデータを混在させる
D) 入力の「重要度」を制御する

**答え**: D


**解説**: 重みが大きいほど、その入力が最終出力に大きく影響します。

---

### 問題3
グラディエント樋降（Gradient Descent）の役割は何ですか？

A) 偏った対象だけを重視する
B) 重要性を無視する
C) ニューロンの「活性化しやすさ」を制御する
D) 監査を避ける

**答え**: C


**解説**: バイアスが大きい（正）ほど、ニューロンが活性化しやすくなります。

---

### 問題4
損失関数の役割として正しいものはどれですか？

A) 偏りを放置する
B) 対象を定めない
C) 直感だけで判断する
D) 予測値と実際の値の誤差を数値化したもの

**答え**: D


**解説**: 損失関数は、モデルの予測がどれだけ実際の値から外れているかを測ります。

---

### 問題5
勾配降下法の目的として正しいものはどれですか？

A) 十分に検証しない
B) 指標を提示しない
C) テストデータを学習に使う
D) 損失を最小化するために、重みを反復的に更新する学習アルゴリズム

**答え**: D


**解説**: 勾配降下法は、損失の勾配に基づいて、最適な重みを見つけるアルゴリズムです。

---

### 問題6
学習率が大きすぎると何が起こるか、正しいものはどれですか？

A) 結果を確認せず次に進む
B) 最小値を飛ばしてしまい、不安定になる可能性
C) 一度だけ行って終わる
D) データを使わない

**答え**: B


**解説**: 学習率が大きすぎると、最適値の周辺で振動し、収束しないことがあります。

---

### 問題7
バックプロパゲーションの役割として正しいものはどれですか？

A) 出力層から入力層へ、勾配を逆伝播させてすべての重みを効率的に更新する
B) ネットワークを逆さにする
C) 偏った対象だけを重視する
D) データの偏りを見ない

**答え**: A


**解説**: バックプロパゲーションにより、全層の重みを効率的に計算・更新できます。

---

### 問題8
重みの初期化方法として正しいものはどれですか？

A) 目的や結果を省略する
B) 重みは 0 に初期化される
C) 重みは 1 に初期化される
D) 複数の正解がある、初期値が 0.5、ランダムなど、様々な方法がある

**答え**: D


**解説**: 重みはランダムに初期化されることが一般的です（0は特殊なケース）。

---

### 問題9
学習率が小さい場合の学習の特徴として正しいものはどれですか？

A) 使いやすさを考えない
B) 関係者を見ない
C) 学習がゆっくりで、多くのイテレーションが必要
D) 効果を測定しない

**答え**: C


**解説**: 学習率が小さすぎると、重みの更新が細かすぎて、収束に非常に時間がかかります。

---

### 問題10
バイアスがない場合のモデルの表現力として正しいものはどれですか？

A) 専門用語をそのまま使う
B) 利用者の意見を無視する
C) 持続可能性を無視する
D) モデルの表現力（原点を通る直線しか表現できない）

**答え**: D


**解説**: バイアスがないと、ニューロンは「原点を通る直線」の形のパターンしか学べません。
