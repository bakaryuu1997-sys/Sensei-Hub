## 3. 本日の内容

### 3つの技術の関係図

```
┌─────────────────────────────────────┐
│      人工知能（AI）                 │
│  ～ コンピューターが人間のように    │
│        考える全技術 ～              │
│                                     │
│  ┌──────────────────────────────┐  │
│  │  機械学習（ML）              │  │
│  │  ～ データから自動学習する ～ │  │
│  │                              │  │
│  │  ┌────────────────────────┐ │  │
│  │  │ 深層学習（DL）         │ │  │
│  │  │ ～ 複雑なニューラル     │ │  │
│  │  │    ネットワーク ～     │ │  │
│  │  └────────────────────────┘ │  │
│  │  + 従来型ML                  │  │
│  │   （決定木、SVMなど）        │  │
│  └──────────────────────────────┘  │
│  + 非学習型AI                      │
│   （ルールベースシステムなど）    │
└─────────────────────────────────────┘
```

（Mối quan hệ: AI là tổng thể, ML là một phần của AI, DL là một phần của ML）

### レベル1：人工知能（AI）- 最も広い概念

**定義**：コンピューターが人間のように考えて、判断・予測・学習ができる技術全体。

（AI: máy tính có thể suy nghĩ, quyết định, dự đoán, học tập giống con người）

**含むもの**：
1. 機械学習 → データから自動学習
2. 従来型AI → ルールを人間が入力

**例**：
- スマートフォンの顔認識 → AI
- 医者の診断システム → AI
- チェスのプログラム → AI
- ChatGPT → AI

AIは最も広い傘のような概念です。中身がいろいろあります。

### レベル2：機械学習（Machine Learning）- AIの部分集合

**定義**：データから自動的にパターンを学ぶ技術。人間がルールを入力する必要がない。

（ML: máy tự động tìm ra quy luật từ dữ liệu mà không cần con người ghi rõ）

**キーポイント**：
- 人間：「この条件ならこうしろ」と指示しない
- 機械：「1000個の例から、どんなパターンがあるか」を自分で学ぶ

**例**：
- メールのスパム判定：スパムメール 10万件 + 普通のメール 10万件 → AI自動学習
- 医者の診断：患者1000人のデータ → パターン学習
- 商品推薦：購入履歴のデータ → 「この人はこれを好きそう」と自動判定

### レベル3：深層学習（Deep Learning）- 機械学習の一種

**定義**：ニューラルネットワークという複数の層を持つ数学モデルを使った機械学習。

（DL: sử dụng mạng nơ-ron với nhiều lớp để học từ dữ liệu）

**ニューラルネットワークとは**：

脳の神経細胞（ニューロン）の構造をまねた数学モデルです。

```
入力層 → 隠れ層1 → 隠れ層2 → 隠れ層3 → 出力層
  |         |         |         |        |
画像    計算...      計算...    計算...   「猫です」
```

（Mạng nơ-ron: bắt chước cấu trúc não người với nhiều lớp tính toán）

**「深層」とは**：
- 昔の機械学習：層が1～2個
- 深層学習：層が10個、100個、1000個という「深い」ネットワーク

層が多いほど、複雑なパターンを学べます。

### 違いを整理する表

| 項目 | AI | 機械学習 | 深層学習 |
|-----|----|---------|---------| 
| 定義 | 人間のように考える技術全体 | データから自動学習する技術 | ニューラルネット使った機械学習 |
| 範囲 | 最も広い | AIの一部 | 機械学習の一部 |
| ルール入力 | 人間が入力する場合も | ほぼしない | しない |
| 計算の複雑さ | 様々 | 中程度 | 非常に複雑 |
| 必要なデータ | 少なくても可 | 中程度 | 大量（数百万件） |
| 処理時間 | 短い場合が多い | 中程度 | 長い（数日かかることも） |

### なぜ分ける必要があるのか？

**例えば、メールのスパム判定：**

**方法1：従来型AI**
- ルール：「『確認してください』という日本語 + 添付ファイル = スパム」
- プログラマーが手で50個のルールを書く
- 単純だが、新しいスパムに対応できない

**方法2：従来型機械学習**
- スパムとスパムでないメール各1000件を見せる
- 決定木というシンプルなモデルで学習
- 80%の精度
- 速い

**方法3：深層学習**
- スパムとスパムでないメール各100万件を見せる
- 複雑なニューラルネットワークで学習
- 99%の精度
- 時間がかかるが、精度が高い

状況によって、どの技術を使うかは変わります。

## 4. 具体例

### 例1: 猫と犬の分類

**昔のAI（ルールベース）**
- 規則を書く：「耳が立っていて、髭があれば猫」
- 結果：新しい髪型の猫には対応できない

**従来型機械学習**
- 猫1000、犬1000の画像を見せる
- アルゴリズム：決定木、SVM
- 精度：85%

**深層学習**
- 猫100万、犬100万の画像を見せる
- ニューラルネットワーク：100層以上
- 精度：99%

### 例2: ChatGPT

- **AI**としてのChatGPT：人間のように質問に答える
- **機械学習**としてのChatGPT：インターネットの文章から自動学習
- **深層学習**としてのChatGPT：「Transformer」という複雑なニューラルネットワークを使用

### 例3: 自動運転

- **AI**：安全に運転する判断全体
- **機械学習**：カメラ映像から信号・車・人を自動認識
- **深層学習**：CNN（画像用ニューラルネット）で物体検出

## 5. 試験で出やすいポイント

1. **3つの関係図を描ける**
   - AIが最も大きい → 機械学習はその中 → 深層学習はさらにその中

2. **それぞれの定義を説明できる**
   - AI：人間のような知能
   - ML：データから自動学習
   - DL：ニューラルネット使った機械学習

3. **従来型機械学習 vs 深層学習の違い**
   - 層の数、必要なデータ量、精度、計算時間

4. **使い分けの理由**
   - 問題が単純 → 従来型ML
   - 問題が複雑 + データ大量 → 深層学習

5. **技術の歴史的流れ**
   - ルールベースAI → 従来型ML → 深層学習

## 6. 間違えやすいポイント

❌ **間違い1**: 「AI = 機械学習 = 深層学習」
✅ **正解**: AIが最も大きい概念。中に機械学習、さらに中に深層学習がある

❌ **間違い2**: 「機械学習 = ニューラルネットワーク」
✅ **正解**: 機械学習には決定木、SVM、ニューラルネットなど複数の方法がある

❌ **間違い3**: 「深層学習は常に従来型MLより優れている」
✅ **正解**: データが少ない場合、深層学習は逆に精度が悪い。問題による

❌ **間違い4**: 「ニューラルネットワーク = 脳」
✅ **正解**: ニューラルネットワークは脳を「まね」た数学モデル。本物の脳ではない

❌ **間違い5**: 「深層学習は『深い』だから『高級』」
✅ **正解**: 深いだけが良いわけではない。単純な問題には向かない

## 7. 確認問題

### 問題1
AIと機械学習の最大の違いは何ですか？

A) 技術の新しさ  
B) AIは最も大きい概念で、機械学習はAIの一部  
C) AIの方が簡単  
D) 価格  

**答え**: B  
**解説**: AIは人間のような知能全体を指します。機械学習はそのAIの中の、「データから学ぶ」という方法の一つです。  
**ベトナム語説明**: AI là tổng thể, ML là một phần của AI.

---

### 問題2
深層学習で「深層」とは何を意味しますか？

A) 深さ感覚  
B) ニューラルネットワークの層の数が多い  
C) 難しいという意味  
D) 地下に埋まっている  

**答え**: B  
**解説**: 「深層」は「層が多い」という意味です。1層、2層という浅いネットワークに対して、10層、100層という深いネットワークを使うことが深層学習です。  
**ベトナム語説明**: "Sâu" = số lớp nơ-ron nhiều (10, 100, 1000 lớp).

---

### 問題3
以下のうち、従来型機械学習に含まれるものはどれですか？

A) ChatGPT  
B) 決定木とサポートベクトルマシン（SVM）  
C) ニューラルネットワークだけ  
D) ルールベースシステム  

**答え**: B  
**解説**: 決定木とSVMは深層学習が流行する前から使われてきた機械学習の方法です。ニューラルネットではなく、シンプルな数学モデルを使います。  
**ベトナム語説明**: Decision Tree và SVM là phương pháp ML truyền thống, không dùng nơ-ron.

---

### 問題4
なぜ機械学習が「学習」と呼ばれるのですか？

A) 人間が勉強するから  
B) データから自動的にパターンを見つけるから  
C) プログラムが楽しいから  
D) 学校で使うから  

**答え**: B  
**解説**: 機械学習は、人間が「ルールを入力」するのではなく、機械が「データから自動的にパターンを学ぶ」ことから「学習」と呼ばれます。  
**ベトナム語説明**: ML tự động tìm quy luật từ dữ liệu → gọi là "học".

---

### 問題5
医療診断システムで大量の患者データから疾病パターンを自動的に学ぶシステムは、どのカテゴリに属しますか？

A) AI  
B) AI かつ 機械学習  
C) AI かつ 機械学習 かつ 深層学習  
D) 従来型AI  

**答え**: B  
**解説**: 患者データから自動学習する＝機械学習です。ニューラルネットワークを使っているかどうか次第で、深層学習かどうかが決まります。しかし、とにかくAIかつ機械学習です。  
**ベトナム語説明**: Tự động học từ dữ liệu → ML. Có dùng nơ-ron hay không → quyết định DL.

---

### 問題6
深層学習が従来型機械学習より必ず優れている理由は何ですか？

A) 層の数が多いから  
B) そうとは限らない。データが少ない場合は従来型の方が良い場合もある  
C) 新しいから  
D) より複雑だから  

**答え**: B  
**解説**: 深層学習は大量のデータが必要です。データが100件しかない場合、逆に従来型機械学習の方が精度が良い場合があります。  
**ベトナム語説明**: DL cần dữ liệu khổng lồ. Nếu dữ liệu ít → ML truyền thống tốt hơn.

### 問題7
ニューラルネットワークとは何ですか？

A) インターネットのネットワーク  
B) 脳の細胞をまねた数学モデル  
C) プログラミング言語  
D) コンピューターの構造  

**答え**: B  
**解説**: ニューラルネットワークは脳の神経細胞（ニューロン）の構造を数学的に再現したモデルです。深層学習で使われます。  
**ベトナム語説明**: Mạng nơ-ron bắt chước cấu trúc não người bằng toán học.

### 問題8
スマートフォンの顔認識機能は、「AI」「機械学習」「深層学習」のどれに該当しますか？

A) AIだけ  
B) AIと機械学習  
C) AI、機械学習、深層学習すべて  
D) 深層学習だけ  

**答え**: C  
**解説**: 顔認識は：
- AIである（人間のように顔を認識する知能）
- 機械学習である（大量の顔写真から学ぶ）
- 深層学習である（CNNというニューラルネットワークを使う）

**ベトナム語説明**: Nhận diện khuôn mặt: AI (có trí tuệ) + ML (học từ dữ liệu) + DL (dùng CNN).

### 問題9
「決定木」と「ニューラルネットワーク」の関係は何ですか？

A) 同じもの  
B) 決定木がニューラルネットワークの一部  
C) どちらも機械学習の方法だが、異なるアプローチ  
D) ニューラルネットワークが決定木より常に優れている  

**答え**: C  
**解説**: 決定木とニューラルネットワークは両方とも機械学習ですが、全く異なる方法です。どちらが「優れている」かは問題次第です。  
**ベトナム語説明**: Cây quyết định và mạng nơ-ron: cả hai là ML nhưng phương pháp khác nhau.

### 問題10
来年、新しい「超高度な学習技術」が発明されたとします。それはAI、機械学習、深層学習のどれに該当するでしょうか？

A) 新しいカテゴリを作る必要がある  
B) 深層学習の中に入るだろう  
C) AIの中に入る可能性が高い。その技術によって機械学習や深層学習に該当するかどうかは変わる  
D) 何にも該当しない  

**答え**: C  
**解説**: AIの定義は広いので、新しい技術もAIに含まれる可能性が高いです。ただし、データから学ぶかどうかで機械学習に該当するかが決まります。  
**ベトナム語説明**: AI là khái niệm rộng. Công nghệ mới có thể vào trong AI, nhưng ML/DL hay không phụ thuộc vào đặc điểm của nó.

## 8. 今日のまとめ

AIは最も広い概念で、「コンピューターが人間のように考える技術全体」です。

その中に機械学習があり、「データから自動的にパターンを学ぶ」という方法を提供します。

さらにその中に深層学習があり、「複数の層を持つニューラルネットワーク」を使って、複雑なパターンを学びます。

3つの技術は包含関係にあり、それぞれ異なる範囲と目的を持っています。

問題によって、どの技術が適切かは変わります。
