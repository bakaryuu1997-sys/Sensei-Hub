# Day 9: 学習データとテストデータ / Dữ liệu huấn luyện và dữ liệu kiểm tra

- 良いデータセットの条件を知ることができる
- データの前処理の重要性を理解できる

## 3. 本日の内容

### なぜデータ分割が必要か

**悪い例**：
```
学習データ = テストデータ
     ↓
機械が学習データを完璧に覚えている
     ↓
「精度100%！完璧！」
     ↓
新しいデータで精度30%... 失敗！
```

（Vấn đề: Máy học thuộc lòng dữ liệu → Không thích nghi với dữ liệu mới）

**良い例**：
```
データ全体を2つに分割
     ↓
学習データ (70%) → 機械が学ぶ
テストデータ (30%) → 精度を測定
     ↓
新しいデータでも 70% の精度が出ることが期待できる
```

（Chia dữ liệu → Đo độ chính xác thực tế → Biết ML thực sự tốt cỡ nào）

### データ分割の比率

#### 推奨される分割比率

```
学習データ : テストデータ : 検証データ = 70 : 20 : 10
または
学習データ : テストデータ = 80 : 20
または
学習データ : テストデータ = 60 : 40
```

**ケースごとに異なる**：
- データが多い場合（100万件以上）：70 : 20 : 10
- データが少ない場合（1000件以下）：交差検証（Cross-validation）を使う
- 時系列データ：古いデータで学習、新しいデータでテスト

#### 各データセットの役割

| データセット | 役割 | 比率 | 用途 |
|-----------|------|------|------|
| 学習データ | 機械が学ぶ | 60～80% | AIモデルのパラメーターを調整 |
| テストデータ | 精度を測定 | 20～40% | 最終的な精度を評価 |
| 検証データ | ハイパーパラメーター調整 | 10～20% | モデル選択、過適合の判定 |

### データの質の重要性

#### 1. 欠落値（Missing Value）

**問題**：
```
患者データ
年齢: 45
体重: ?  ← 欠落
血圧: 120/80
```

**対処法**：
- 平均値で埋める（Mean imputation）
- 中央値で埋める（Median imputation）
- 機械学習で予測して埋める
- その行をぜんぶ削除する

#### 2. 外れ値（Outlier）

**問題**：
```
年齢データ：25, 30, 28, 32, 200, 29...
             ↑ 明らかに間違い
```

**対処法**：
- 統計的に判定して削除
- ログ変換で圧縮
- 別の値に置き換え

#### 3. 不均衡（Imbalance）

**問題**：
```
スパム判定データ
普通のメール：990件
スパムメール：10件
     ↓
機械が「常に普通と判定」すれば 99% の精度... 不正確！
```

（Vấn đề: Dữ liệu mất cân bằng → ML học về lớp chính → Không phát hiện lớp hiếm）

**対処法**：
- サンプリング：多数クラスを減らす、少数クラスを増やす
- 重み付け：少数クラスに高い重みを与える
- SMOTE などの手法を使う

#### 4. ノイズ

**問題**：
```
センサーが間違った値を記録
温度：25.3℃ (正確)
温度：999℃  ← ノイズ
```

**対処法**：
- フィルタリング
- 外れ値除去
- スムージング

### データの前処理（Preprocessing）の流れ

```
生データ
    ↓
1. 欠落値処理
    ↓
2. 外れ値除去/調整
    ↓
3. 正規化/標準化
    ↓
4. 不均衡対策
    ↓
5. 特徴選択/抽出
    ↓
クリーンなデータ（学習に準備完了）
```

（Tiền xử lý: biến dữ liệu thô thành dữ liệu sạch）

### 正規化（Normalization）と標準化（Standardization）

**なぜ必要か**：
```
年齢：25～80
年収：300万～1000万
    ↓
スケールが大きく異なるので、機械学習アルゴリズムに影響する
```

**正規化（0～1 の範囲）**：
```
正規化値 = (値 - 最小値) / (最大値 - 最小値)
例：年齢 45 → (45-25) / (80-25) = 0.36
```

**標準化（平均0、標準偏差1）**：
```
標準化値 = (値 - 平均値) / 標準偏差
例：年齢 45、平均 50、標準偏差 10 → (45-50)/10 = -0.5
```

### データセット分割の注意点

#### 1. ランダム分割

```
良い：
データをシャッフルして、ランダムに分割
     ↓
学習データとテストデータにほぼ同じ分布
```

#### 2. 時系列データ

```
悪い：
ランダムに分割
     ↓
テストデータが過去、学習データが未来？
（時間をさかのぼる） → 非現実的

良い：
2020年データ → 学習
2021年データ → テスト
     ↓
時間の流れを守る
```

#### 3. グループ分割

```
悪い：
医療データ（患者1000人 × 100日分）
ランダムに分割
     ↓
同じ患者のデータが学習とテストに混在
     ↓
「学習データから見たことある患者」とテストする
     ↓
精度が不正確

良い：
患者ごとにグループ分割
患者1～700 → 学習
患者701～1000 → テスト
```

### 良いデータセットの条件

#### 1. 十分な量

```
経験則（Empirical Rule）
- 深層学習：100万件以上が理想
- 従来型ML：1000～10000件で OK
- データが少ない場合：交差検証、データ増強を使う
```

#### 2. 代表性

```
バイアスなし：
インドの人口の機械学習で、全員をムンバイから集める ← ダメ
全インド地域から集める ← 良い
```

#### 3. 一貫性

```
ラベル付けの基準が統一されている
例：「スパム」の定義が一貫している
```

#### 4. 妥当性

```
データが問題に合致している
例：猫の認識AIを作るのに、犬の画像ばかり学習データにしている ← ダメ
```

## 4. 具体例

### 例1：医療診断の場合

**データセット**：
- 患者データ 5000 件
- 病気ありの患者：500 件
- 病気なしの患者：4500 件（不均衡！）

**分割**：
- 学習データ：3500 件（85%）
- テストデータ：1500 件（15%）

**前処理**：
- 不均衡対策：病気ありのデータを 4倍に増やす
- 欠落値：年齢などの欠落を中央値で埋める
- 正規化：年齢、血圧などを 0～1 の範囲に

**結果**：
- 学習データで精度：92%
- テストデータで精度：90%
  （ほぼ同じ → 良好）

### 例2：時系列データ（株価予測）

**ダメな分割**：
```
2020年 1月～2021年12月のデータ
ランダムに分割
学習：2020年7月、2021年3月、2020年2月など...
テスト：2021年6月、2020年9月など...
     ↓
「時間を遡ってテスト」→ 非現実的
     ↓
精度が高く見える（でも実運用では失敗）
```

**良い分割**：
```
2020年1月～9月 → 学習
2020年10月～12月 → テスト
     ↓
時間の流れを守る
     ↓
実運用に合致した評価
```

### 例3：SNS データのバイアス

**ダメな例**：
```
Twitter のデータだけを使って「人間の意見」を学習
     ↓
Twitter のユーザーは偏っている（若い、都市部、高学歴）
     ↓
一般的な意見ではない
```

**良い例**：
```
複数のプラットフォーム、複数の地域、複数の年代から集める
```

## 6. 間違えやすいポイント

❌ **間違い1**: 「学習データとテストデータは同じでいい」
✅ **正解**: 別である必要がある。精度測定の信頼性に関わる

❌ **間違い2**: 「データが多いほど常に良い」
✅ **正解**: 低質なデータは逆に害になる

❌ **間違い3**: 「正規化は不要」
✅ **正解**: 多くの ML アルゴリズムで正規化が重要

❌ **間違い4**: 「時系列データもランダムに分割」
✅ **正解**: 時間順で分割する必要がある

❌ **間違い5**: 「データの前処理は簡単」
✅ **正解**: ML プロジェクト全体の 80% が前処理に費やされることも

## 7. 確認問題

### 問題1
なぜデータ分割が必要ですか？

A) 透明性を欠く
B) 学習に使ったデータでテストすると、精度の測定が不正確になるから
C) 関係者を見ない
D) 偏ったデータで学習する

**答え**: B


**解説**: 学習に使ったデータで精度を測ると、機械は「これらのデータは完璧に学習している」ため、実際より高い精度が出ます。  
**ベトナム語説明**: Nếu dùng dữ liệu học cho test → Độ chính xác cao giả tạo.

---

### 問題2
データ分割の推奨比率はどれですか？

A) 70:20:10 または 80:20
B) 十分に検証しない
C) 偏ったデータで学習する
D) テストデータを学習に使う

**答え**: A


**解説**: 一般的には 70:20:10（学習:テスト:検証）または 80:20（学習:テスト）が推奨されます。  
**ベトナム語説明**: Tỉ lệ chuẩn: 70:20:10 hoặc 80:20.

---

### 問題3
欠落値（Missing Value）をどう処理しますか？

A) 見た目だけを重視する
B) 専門用語をそのまま使う
C) 平均値で埋める、中央値で埋める、削除するなどの方法がある
D) 課題を伝えない

**答え**: C


**解説**: 欠落値は複数の方法で処理できます。データの性質に応じて選択します。  
**ベトナム語説明**: Xử lý giá trị thiếu: điền trung bình, trung vị, xóa dòng...

---

### 問題4
アンバランス（不均衡）とは何ですか？

A) 学習とテストのデータを混在させる
B) テストデータを学習に使う
C) 異なるクラスのサンプル数が大きく異なる
D) 偏ったデータで学習する

**答え**: C


**解説**: 例えば、スパムメール 10件 vs 普通のメール 990件。この不均衡により、AIが多数クラスに偏って学ぶ可能性があります。  
**ベトナム語説明**: Mất cân bằng: lớp A có 1000 mẫu, lớp B chỉ 10 mẫu.

---

### 問題5
時系列データを分割するときに注意することはどれですか？

A) 検証を省略する
B) 時間の流れが破壊され、非現実的な評価になる
C) テストデータを学習に使う
D) 偏ったデータで学習する

**答え**: B


**解説**: 時系列データをランダムに分割すると、テストデータが過去、学習データが未来になる可能性があり、時間をさかのぼる非現実的な状況になります。  
**ベトナム語説明**: Dữ liệu chuỗi thời gian không nên chia ngẫu nhiên → Phá vỡ thứ tự thời gian.

---

### 問題6
正規化（Normalization）の目的は何ですか？

A) 透明性を欠く
B) 失敗を否定する
C) 障害に備えない
D) データの値の範囲を統一する

**答え**: D


**解説**: 正規化により、異なるスケールのデータを 0～1 の範囲に統一し、ML アルゴリズムが公平に学べるようにします。  
**ベトナム語説明**: Chuẩn hóa: biến dữ liệu nhiều tỷ lệ khác nhau thành khoảng 0～1 đồng nhất.

---

### 問題7
実際のMLプロジェクトで、前処理に費やされる時間の割合はおよそどれくらいですか？

A) 改善点を含めない
B) 安心感を考えない
C) テストデータを学習に使う
D) 80% 以上

**答え**: D


**解説**: 実際の ML プロジェクトでは、80% 以上の時間が前処理に費やされることが多いです。  
**ベトナム語説明**: Tiền xử lý chiếm 80% thời gian dự án ML.

---

### 問題8
良いデータセットの条件として正しいものはどれですか？

A) テストデータを学習に使う
B) データが多いデータセット
C) 偏ったデータで学習する
D) バイアスなく、全体を代表するデータセット

**答え**: D


**解説**: 代表性のあるデータセットは、全体の特性を正確に反映しており、バイアスがありません。  
**ベトナム語説明**: Dữ liệu đại diện: phản ánh đầy đủ đặc tính của tổng thể, không có thiên lệch.

---

### 問題9
検証データ（Validation Data）の役割は何ですか？

A) 学習とテストのデータを混在させる
B) 偏りを放置する
C) ハイパーパラメーター調整、過適合判定
D) 偏ったデータで学習する

**答え**: C


**解説**: 検証データは、AIが学習中にハイパーパラメーターを調整したり、過適合が起きていないかを判定したりするのに使われます。  
**ベトナム語説明**: Dữ liệu xác thực: điều chỉnh siêu tham số, phát hiện over-fitting.

---

### 問題10
不均衡データで実用的なデータセットの条件として正しいものはどれですか？

A) 学習とテストのデータを混在させる
B) 十分な量、代表性、一貫性、妥当性すべてが必要
C) 障害に備えない
D) テストデータを学習に使う

**答え**: B


**解説**: 良いデータセットには、数量的な十分性、バイアスのない代表性、ラベリングの一貫性、問題への妥当性などが必要です。  
**ベトナム語説明**: Dữ liệu tốt: đủ số lượng + không thiên lệch + nhãn nhất quán + phù hợp bài toán.

## 8. 今日のまとめ

データ分割は、機械学習の**信頼性の根本**です。

推奨比率は学習：テスト：検証 = 70:20:10 です。

データの前処理は ML プロジェクト全体の 80% 以上を占めることもあります。

欠落値、外れ値、不均衡、ノイズなど、複数の問題に対処する必要があります。

正規化・標準化により、データを統一スケールに変換することが重要です。

時系列データやグループデータは、特別な分割方法が必要です。
