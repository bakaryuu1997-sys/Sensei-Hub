## 3. 本日の内容

### 教育分野の AI 応用

**定義**：学習者ごとに最適な教材や支援を提供し、学びの効率を高めること。

（AI trong giáo dục: cá nhân hóa học tập và hỗ trợ giảng dạy）

```
AI は「学習の個別化」と「教師の負担軽減」を両立する
```

#### 1. 学習管理

- 学習進捗の可視化
- 弱点の自動検出
- リコメンデーション教材

#### 2. 自動採点・フィードバック

- 選択式テストの採点
- 自由記述の要点抽出
- 学習アドバイスの生成

#### 3. 会話型チューター

- 問題を対話形式で説明
- 疑問に応じた補足説明
- 英語学習やプログラミング学習の支援

### 医療分野の AI 応用

**定義**：医療データを分析して、診断・治療・予防を支援すること。

（AI trong y tế: hỗ trợ xác định bệnh và chăm sóc sức khỏe）

#### 1. 画像診断支援

- CT / MRI / X線の異常検出
- がんの早期発見
- 放射線医の支援

#### 2. 電子カルテ分析

- 患者履歴の傾向分析
- リスク因子の抽出
- 治療計画の最適化

#### 3. 予防医療

- 生活習慣データからリスク予測
- 健康管理アプリによる通知
- 早期警戒システム

### 教育・医療での共通メリット

#### 1. 個別最適化

```
一人ひとりに合わせた支援で成果を高める
```

#### 2. 早期発見と対応

```
問題を早く見つけて、適切な対応につなげる
```

#### 3. 効率化

```
専門家の作業を支援し、負担を軽減する
```

### 注意点

#### 1. プライバシー

```
学習履歴や健康データは厳格に管理する
```

#### 2. 説明責任

```
診断や指導の根拠を明確にする
```

#### 3. 過信の危険

```
AI を過信せず、人間が最終判断を行う
```

#### 4. バイアスと公平性

```
偏ったデータで不公平な判断につながらないよう注意する
```

## 4. 試験で出やすいポイント

1. 教育では個別最適化と自動フィードバックが中心
2. 医療では画像診断・カルテ分析・予防医療が代表例
3. プライバシーと説明責任が特に重要な領域である
4. AI は支援ツールであり、人間の最終判断が必要である
5. 導入成功には専門家との協働が不可欠である

## 7. 確認問題


### 問題1

教育分野の AI 応用で期待されるのは？

A) 速度だけを上げること
B) データ削除
C) 個別最適化された学習支援
D) UI を派手にすること

**答え**: C

**解説**: AI は個別最適化された学習を支援します。
**ベトナム語説明**: AI hỗ trợ học tập cá nhân hóa.

### 問題2

医療分野での AI 活用例に含まれるのはどれですか？

A) 音声合成
B) UI 変更
C) 広告配信
D) 画像診断支援

**答え**: D

**解説**: 医療では画像診断支援が代表的な AI 活用例です。
**ベトナム語説明**: Trong y tế, AI hỗ trợ chẩn đoán hình ảnh.

### 問題3

自動採点・フィードバックの利点は何ですか？

A) データ容量が減ること
B) 外部公開されること
C) UI が派手になること
D) 学習者への迅速な対応が可能になること

**答え**: D

**解説**: 自動採点は迅速な学習フィードバックを提供できます。
**ベトナム語説明**: Chấm điểm tự động giúp phản hồi nhanh cho người học.

### 問題4

会話型チューターで重要なのはどれですか？

A) 対話を通じて学習者を支援すること
B) ただ会話すること
C) モデルを大きくするだけ
D) データを減らすこと

**答え**: A

**解説**: 会話型チューターは学習者との対話で支援します。
**ベトナム語説明**: Gia sư hội thoại hỗ trợ người học qua tương tác.

### 問題5

教育・医療の共通メリットに含まれないのは？

A) 持続可能なエネルギー
B) 個別最適化
C) 効率化
D) 早期発見と対応

**答え**: A

**解説**: 環境エネルギーは教育・医療の共通メリットではありません。
**ベトナム語説明**: Năng lượng bền vững không phải lợi ích chung của giáo dục và y tế.

### 問題6

プライバシーの注意点として正しいのは？

A) データを公開すること
B) すべて記録すること
C) 速度を優先すること
D) 個人情報を適切に扱うこと

**答え**: D

**解説**: プライバシーでは個人情報を適切に扱うことが重要です。
**ベトナム語説明**: Riêng tư cần xử lý dữ liệu cá nhân phù hợp.

### 問題7

説明責任について正しい説明はどれ？

A) 結果を隠すこと
B) 結果やプロセスを説明できること
C) UI を派手にすること
D) 速さだけを重視すること

**答え**: B

**解説**: 説明責任はプロセスや結果を説明できることです。
**ベトナム語説明**: Trách nhiệm giải trình là giải thích được kết quả và quá trình.

### 問題8

過信の危険は何を引き起こす可能性がありますか？

A) データが増えること
B) 誤った判断を見逃すこと
C) UI が簡単になること
D) 速度が上がること

**答え**: B

**解説**: AI を過信すると誤りを見逃す危険があります。
**ベトナム語説明**: Tin tưởng quá mức AI có thể bỏ sót sai sót.

### 問題9

教育・医療での AI 応用で重要な共通点は？

A) データを消すこと
B) 速度を上げることだけ
C) 利用者の信頼と安全性
D) 色を変えること

**答え**: C

**解説**: どちらも利用者の信頼と安全性が重要です。
**ベトナム語説明**: Cả hai đều cần đáng tin cậy và an toàn đối với người dùng.

### 問題10

個別最適化とは何を目指しますか？

A) UI を見やすくすること
B) 全員に同じ対応をすること
C) 速度だけを上げること
D) 一人ひとりに合った支援を行うこと

**答え**: D

**解説**: 個別最適化は一人ひとりの特性に合わせた支援を目指します。
**ベトナム語説明**: Cá nhân hóa hướng đến hỗ trợ phù hợp với từng người.
