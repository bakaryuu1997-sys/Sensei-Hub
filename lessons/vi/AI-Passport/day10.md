## 3. 本日の内容

### 教師あり学習とは

**定義**：「正解が付いたデータ」から学ぶ機械学習の方法。

```
入力 → 機械学習 → 出力
(特徴)           (ラベル/正解)
       ↑
    正解が付いている！
```

**例**：
```
メールの文章 → スパム判定 → スパム / 普通
   (入力)                   (正解)

患者の症状 → 診断 → 病気A / 病気B / 健康
  (入力)              (正解)
```

### 教師あり学習の2つの主要なタイプ

#### 1. 分類（Classification）

**定義**：入力データを、カテゴリ（クラス）に分ける。

**離散的な出力**：
```
出力は「スパム」または「普通」
出力は「犬」「猫」「鳥」「うさぎ」のいずれか
出力は「病気」または「健康」
```

#### 二値分類（Binary Classification）
- 2つのカテゴリのみ
- 例：メール（スパム/普通）、医療診断（病気/健康）、感情分析（肯定/否定）

```
データ
  ↓
機械学習
  ↓
カテゴリAまたはカテゴリB
```

#### 多クラス分類（Multi-class Classification）
- 3個以上のカテゴリ
- 例：手書き文字認識（0～9の10個）、アイリス分類（3種類）

```
データ
  ↓
機械学習
  ↓
カテゴリA または B または C または D...
```

#### 2. 回帰（Regression）

**定義**：入力データから、連続的な数値を予測する。

**連続的な出力**：
```
明日の気温：23.5℃
株価：1,250円
売上：500万円
```

```
データ
  ↓
機械学習
  ↓
数値（任意の値可能）
```

### 分類 vs 回帰

| 項目 | 分類 | 回帰 |
|-----|------|------|
| 出力 | カテゴリ（離散） | 数値（連続） |
| 例 | 画像分類、メール判定 | 価格予測、気温予測 |
| 可能な出力の数 | 有限（決まっている） | 無限（任意） |
| アルゴリズム | ロジスティック回帰、SVM、決定木など | 線形回帰、ニューラルネットなど |

### 教師あり学習のプロセス

```
ステップ1: データセット準備
（正解付きデータを集める）
    ↓
ステップ2: データ分割
（学習用 70%、テスト用 30%）
    ↓
ステップ3: 特徴抽出
（重要な特徴を選ぶ）
    ↓
ステップ4: モデル選択
（アルゴリズムを選ぶ）
    ↓
ステップ5: 学習
（正解から学ぶ）
    ↓
ステップ6: 予測
（新しいデータに対して予測）
    ↓
ステップ7: 評価
（テストデータで精度を測定）
```

### 教師あり学習が向いている場面

#### 向いている場面
- 正解が明確に存在する
- 十分な量の正解付きデータがある
- 過去のパターンが未来に繰り返される

**例**：
- メールスパム判定（正解が明確：スパムまたは普通）
- 医療診断（患者の正確な診断結果がある）
- 売上予測（過去の売上データが豊富）

#### 向いていない場面
- 正解が不明確または複数ある
- 正解付きデータが足りない
- 新しい状況ばかりで過去のパターンが通用しない

## 4. 具体例

### 例1：スパムメール判定（二値分類）

**データセット**：
```
メール1：「確認してください」 + 添付ファイル → スパム
メール2：「ご用件をお聞きします」 + 通常 → 普通
...
メール100万件
```

**特徴**：
- 「確認してください」という文字が含まれるか
- 添付ファイルがあるか
- 送信者が信頼できるか
- etc...

**モデル**：
```
特徴 → ロジスティック回帰 → 確率：75% → スパムと判定
       または SVM
```

### 例2：アイリス分類（多クラス分類）

**データセット**：
```
花のがく片（sepal）の長さ、幅
花びら（petal）の長さ、幅
       ↓
→ アイリス setosa / versicolor / virginica のいずれか
```

**特徴**：4つの測定値
**出力**：3つのカテゴリ

### 例3：不動産価格予測（回帰）

**データセット**：
```
面積：120m²
年数：10年
立地：渋谷駅から徒歩5分
     ↓
→ 価格：5000万円
```

**特徴**：面積、築年数、立地など
**出力**：連続的な価格

## 5. 試験で出やすいポイント

1. **教師あり学習の定義**
   - 正解付きデータから学ぶ

2. **分類 vs 回帰**
   - 分類：カテゴリ、回帰：数値

3. **実例の判定**
   - 「これは分類か回帰か」と聞かれる

4. **二値分類 vs 多クラス分類**
   - 2つ vs 3個以上

5. **向いている場面**
   - 正解が明確で、データが十分

---

## 6. 間違えやすいポイント

- 分類と回帰を逆に考えない。
- 正解がないデータでも教師あり学習と思わない。
- 過学習と未学習を混同しない。
- 精度だけを見て良しとしない。
- 教師あり学習が常に最適とは限らない。

## 7. 確認問題

### 問題1
教師あり学習（Supervised Learning）の特徴は何ですか？

A) ルールより速度を優先する
B) 条件を変えずに行う
C) データに正解が付いている
D) データに正解が付いていない

**答え**: C

**解説**: 教師あり学習は、「正解が付いたデータ」を学習に使う方法です。  
**ベトナム語説明**: Học có giám sát: dữ liệu có nhãn (label) - đáp án đúng.

---

### 問題2
分類（Classification）と回帰（Regression）の違いは何ですか？

A) 目的や結果を省略する
B) 分類：カテゴリ（離散）、回帰：数値（連続）
C) 持続可能性を無視する
D) 安心感を考えない

**答え**: B

**解説**: 分類は「スパム/普通」のような決まったカテゴリに分ける。回帰は「23.5℃」のような連続的な数値を予測する。  
**ベトナム語説明**: Phân loại: thể loại. Hồi quy: số liệu liên tục.

---

### 問題3
手書き文字認識（0～9）は、分類と回帰のどちらの例ですか？

A) データの偏りを見ない
B) 手書き文字認識（0～9）
C) 偏りを放置する
D) ルールより速度を優先する

**答え**: B

**解説**: 手書き文字認識は「0」「1」...「9」のいずれかに分ける分類です。  
**ベトナム語説明**: Nhận diện chữ viết tay: phân loại vào 10 thể loại (0-9).

---

### 問題4
気温予測は、分類と回帰のどちらの例ですか？

A) 直感だけで判断する
B) 公平性を無視する
C) 評価なしで進める
D) 気温予測

**答え**: D

**解説**: 気温予測は「23.5℃」などの連続的な数値を予測するので、回帰です。  
**ベトナム語説明**: Dự đoán nhiệt độ: hồi quy (dự đoán giá trị liên tục).

---

### 問題5
教師あり学習が効果的な場合はどれですか？

A) 正解が明確で、十分なデータがある
B) 表示だけを変える
C) 重要性を無視する
D) 利用者の声を無視する

**答え**: A

**解説**: 教師あり学習は、正解が明確で十分な量の正解付きデータがあるとき、最も効果的です。  
**ベトナム語説明**: Học có giám sát phù hợp: đáp án rõ ràng + dữ liệu đủ.

## 8. 今日のまとめ

教師あり学習は、**「正解が付いたデータ」から学ぶ**機械学習の方法です。

2つの主要なタイプがあります：
- **分類**：カテゴリに分ける（スパム/普通、犬/猫など）
- **回帰**：数値を予測する（気温、株価など）

教師あり学習のプロセスは、データ準備 → 分割 → 特徴抽出 → モデル選択 → 学習 → 予測 → 評価という、7ステップを経ます。

正解が明確で、十分なデータがあるとき、教師あり学習は非常に効果的です。

明日は「**教師なし学習**」を学びます。

教師あり学習は「正解付きデータ」を使いますが、教師なし学習は「正解なしのデータ」から、自動的にグループやパターンを見つけます。

顧客セグメンテーション、データ圧縮、異常検知など、様々な応用があります。
