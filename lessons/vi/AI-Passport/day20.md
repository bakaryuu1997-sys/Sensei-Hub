## 3. 本日の内容

### RNN とは

**定義**：時系列データ処理に特化した深層学習モデル。前の時間ステップの情報を「記憶」できるループ構造を持つ。

（RNN: xử lý dữ liệu chuỗi thời gian, có khả năng "nhớ" thông tin từ bước thời gian trước）

```
通常のニューラルネット：
各入力は独立して処理

RNN：
現在の入力 + 前のステップの「記憶」を合わせて処理
→ 時系列の文脈を保持
```

### 時系列データとは

**定義**：時間順序のあるデータ。過去が未来に影響する。

```
例：
- テキスト：「私は」「猫を」「飼っている」← 順序が重要
- 株価：昨日の価格が今日に影響
- 天気：過去のパターンが未来の天気に影響
- 音声：前の音が次の音に影響
```

（Dữ liệu chuỗi: quá khứ ảnh hưởng đến tương lai）

### RNN の基本構造

#### 単一の RNN セル

```
前のステップの隠れ状態（記憶） h_{t-1}
         ↓
現在の入力 x_t → [RNN セル] → 現在の隠れ状態 h_t
         ↓
         y_t（出力）

計算式：
h_t = tanh(W_h × h_{t-1} + W_x × x_t + b)
y_t = W_y × h_t + b'

h_t：現在の「記憶」
W：重み
b：バイアス
```

#### 時系列での処理

```
ステップ1：
入力：「私」
隠れ状態：h_1 = RNN(「私」, 初期隠れ状態)

ステップ2：
入力：「は」
隠れ状態：h_2 = RNN(「は」, h_1)
←「は」の意味を「私」の文脈で理解

ステップ3：
入力：「猫」
隠れ状態：h_3 = RNN(「猫」, h_2)
←「猫」を「私は」の文脈で理解

ステップ4：
入力：「を」
隠れ状態：h_4 = RNN(「を」, h_3)
...
```

### RNN の課題：勾配消失問題

**問題**：時間ステップが多いと、学習が難しくなる。

```
長い時系列（100ステップ）：
・勾配が指数関数的に小さくなる
・遠い過去の情報が学習されない
・結果：短期的な依存関係のみ学習
```

### LSTM（Long Short-Term Memory）

**定義**：勾配消失問題を解決した RNN の改良版。長期の依存関係を学べる。

```
通常の RNN：
隠れ状態が「上書き」されるだけ

LSTM：
「セル状態」という別の記憶を持つ
→ 長期的な情報が保持される
```

#### LSTM の構造

```
LSTM セル
    ↓
3つのゲート：
1. 忘却ゲート：「どの情報を捨てるか」
2. 入力ゲート：「どの新しい情報を足すか」
3. 出力ゲート：「どの情報を出力するか」

例：
文「私は昨日公園で友達に会った」

忘却ゲート：「昨日」は重要、「公園で」の詳細は忘れる
入力ゲート：「友達に会った」は重要、覚える
出力ゲート：次のステップで必要な情報を選んで出力
```

### GRU（Gated Recurrent Unit）

**定義**：LSTM を簡略化したもの。同等の性能で計算が速い。

```
LSTM：3つのゲート
GRU：2つのゲート（リセットゲート、更新ゲート）

結果：
GRU の方が計算が速く、小規模データセットに向く
LSTM の方が複雑なパターンに対応
```

## 4. 具体例

### 例1：自然言語処理（テキスト生成）

```
入力：「私は」
RNN：この 2 単語を処理し、次の単語の確率を計算
出力：「猫」（確率 80%）「犬」（確率 15%）

次のステップ：
入力：「私は猫」
RNN：この 3 単語を処理（前の記憶を使用）
出力：「を」（確率 90%）

結果：
「私は猫を飼っている」
のような自然な文を生成
```

### 例2：機械翻訳

```
入力（日本語）：「私は毎日走ります」

ステップ1-4：各単語を処理し、隠れ状態を更新
隠れ状態に「意味」が蓄積される

ステップ5：隠れ状態から「意味」を抽出
出力（英語）：「I run every day」

アーキテクチャ：Seq2Seq（エンコーダー-デコーダー）
```

### 例3：株価予測

```
過去 30 日の株価データ
→ RNN で処理
→ 隠れ状態に「トレンド」が蓄積
→ 31 日目の株価を予測

精度：従来の方法より優れることが多い
```

### 例4：音声認識

```
入力音声（1秒分）：
各フレーム（10ms）を順に処理
→ RNN が音の文脈を理解
→「ありがとう」と認識

精度：非常に高い（99% 以上）
```

## 5. 試験で出やすいポイント

1. **RNN の定義**
   - 時系列処理に特化、ループ構造で過去を記憶

2. **時系列データの特徴**
   - 時間順序がある、過去が未来に影響

3. **LSTM の利点**
   - 勾配消失問題を解決、長期依存を学べる

4. **GRU の利点**
   - LSTM より計算が速い、簡潔

5. **RNN の応用**
   - テキスト生成、機械翻訳、音声認識

---

## 6. 間違えやすいポイント

❌ **間違い1**: 「RNN は全てのタスクで LSTM が最良」
✅ **正解**: 小規模データセットなら GRU も良い場合がある

❌ **間違い2**: 「時系列 = 常に RNN が最適」
✅ **正解**: 従来の統計方法（ARIMA など）が優れることもある

❌ **間違い3**: 「LSTM = Transformer より優れている」
✅ **正解**: Transformer は LSTM より高性能

❌ **間違い4**: 「RNN は長い時系列（1000 ステップ）に対応」
✅ **正解**: LSTM でも、極端に長いと難しい

❌ **間違い5**: 「勾配消失問題は完全に解決」
✅ **正解**: LSTM で軽減されるが、完全には解決されない

## 7. 確認問題

### 問題1
RNN（再帰型ニューラルネットワーク）の特徴は何ですか？

A) 時系列処理に特化、ループ構造で過去を記憶
B) 一般的なニューラルネット
C) 数字を示さない
D) リスクを無視する

**答え**: A


**解説**: RNN は、前のステップの隠れ状態を保持し、時系列の文脈を理解します。

---

### 問題2
RNN が隠れ状態を使って保持できるものとして正しいものはどれですか？

A) 過去の情報を「記憶」できる
B) 利用者を無視する
C) 結果だけを求める
D) 数字を示さない

**答え**: A


**解説**: RNN は隠れ状態を通じて、過去の情報を保持し、時系列の文脈を理解できます。

---

### 問題3
RNN の「勾配消失問題」とは何ですか？

A) テストデータを使ってモデルを選ぶ
B) 過去の例だけに頼る
C) 継続学習をしない
D) 時間ステップが多いと、勾配が指数関数的に小さくなり、遠い過去が学習されない

**答え**: D


**解説**: 時間ステップが長いと、逆伝播で勾配がほぼ 0 になり、学習が進まなくなります。

---

### 問題4
LSTM の主な改善点は何ですか？

A) セル状態により、長期の依存関係を学べる
B) パラメーター数が少ない
C) 結果だけを求める
D) 説明を雑にする

**答え**: A


**解説**: LSTM は「セル状態」という追加の記憶により、勾配消失問題を緩和し、長期依存を学べます。

---

### 問題5
GRU（Gated Recurrent Unit）の特徴は何ですか？

A) 評価手順を省略する
B) LSTM の簡略版、同等性能で計算が速い
C) 社会の影響を考えない
D) 課題を伝えない

**答え**: B


**解説**: GRU は LSTM の 3 つのゲートを 2 つに削減し、計算効率を上げました。

---

### 問題6
自然言語処理でのRNNの応用例は何ですか？

A) 説明責任を無視する
B) 使いにくい操作を設計する
C) 過去の単語の文脈から次の単語を予測
D) 専門用語をそのまま使う

**答え**: C


**解説**: RNN は過去の単語情報を記憶し、文脈に基づいて次の単語を予測できます。

---

### 問題7
RNNにおける「隠れ状態（Hidden State）」とは何ですか？

A) 更新を怠る
B) 個人情報を無断で利用する
C) 前のステップからの「記憶」、モデルの内部状態
D) 結果だけを求める

**答え**: C


**解説**: 隠れ状態は、前のステップの情報を保持し、現在のステップに渡されます。

---

### 問題8
機械翻訳でのエンコーダー-デコーダーアーキテクチャの役割は何ですか？

A) 結論がない
B) 結果を確認せず次に進む
C) 監査を避ける
D) 入力言語を隠れ状態に圧縮 → 出力言語を生成（言語が異なるため）

**答え**: D


**解説**: エンコーダーが入力言語の「意味」を隠れ状態に圧縮し、デコーダーが別の言語で出力します。

---

### 問題9
RNN が実用的に扱える時系列の長さはどの程度ですか？

A) 説明責任を果たさない
B) 学習とテストのデータを混在させる
C) 偏ったデータで学習する
D) 一般的には 50～100 ステップ（LSTM でも 200～300 ステップが限界）

**答え**: D


**解説**: LSTM でも極度に長い時系列は難しく、Transformer などの別の手法が使われます。

---

### 問題10
RNN の応用例は何ですか？

A) テキスト生成、機械翻訳、音声認識、株価予測
B) 説明責任を果たさない
C) 対象を定めない
D) 過去の例だけに頼る

**答え**: A


**解説**: RNN は時系列データならあらゆる分野に応用できます。

## 8. 今日のまとめ

**RNN**は、時系列処理に特化した深層学習モデルです。

**ループ構造**により、前のステップの情報を「記憶」できます。

**勾配消失問題**は RNN の課題で、LSTM と GRU で改善されます。

**LSTM**は長期依存を学べます。**GRU**は LSTM を簡略化したものです。

**応用例**：テキスト生成、機械翻訳、音声認識、株価予測など
