## 3. 本日の内容

### AI と自動化の違い

**定義**：AI は知的な判断や推論を行い、自動化はその判断を用いて作業を実行する仕組み。

（AI và tự động hóa: AI quyết định, tự động hóa thực hiện）

```
自動化 = AI の判断 + 実行の流れ
```

### 自動化の適用領域

#### 1. 事務作業

- データ入力の自動化
- 伝票処理
- 申請書のチェック

#### 2. IT 運用

- サーバー監視
- 障害対応の自動化
- 定期レポート生成

#### 3. 製造ライン

- ロボットによる組み立て
- 品質検査の自動化
- 在庫管理

#### 4. 営業支援

- 見積書作成
- 顧客情報更新
- 受注ステータス管理

### 自動化の価値

#### 1. 一貫性

```
同じ手順を正確に繰り返せる
```

#### 2. スピード

```
人より速く処理できる
```

#### 3. コスト削減

```
手作業を減らし、ミスを減らす
```

#### 4. フォーカスの転換

```
人はより高度な仕事に集中できる
```
```

### 自動化の進め方

#### 1. 対象業務の選定

```
繰り返しが多く、ルールが明確な作業を選ぶ
```

#### 2. フローの可視化

```
現状の手順を整理し、改善点を見つける
```

#### 3. AI と定型処理の組み合わせ

```
AI で判定し、定型処理で実行する
```

#### 4. 検証と監視

```
自動化後も結果を確認し、誤動作を防ぐ
```

#### 5. セミオート運用

```
重要な判断は人が最終確認する運用もある
```

### 注意点

#### 1. ブラックボックス化

```
自動化の理由がわからないと修正が難しい
```

#### 2. 例外処理

```
想定外のケースに対応する仕組みが必要
```

#### 3. 影響範囲の確認

```
自動化の失敗が広範囲に影響しないようにする
```

## 7. 確認問題


### 問題1

AI と自動化の違いで正しいのは？

A) AI は全て手作業で作る
B) AI は判断や学習を含む、自動化は定型処理の効率化
C) AI はデータを使わない
D) 自動化は学習を含まない

**答え**: B

**解説**: AI は学習や判断を含み、自動化は定型作業の効率化です。
**ベトナム語説明**: AI gồm học và quyết định, tự động hóa là tối ưu hóa tác vụ định hình.

### 問題2

自動化の適用領域で事務作業に適しているものは？

A) UI を装飾すること
B) 定型入力や仕分け作業
C) 倫理議論
D) クリエイティブ制作

**答え**: B

**解説**: 事務作業では定型入力や仕分けが自動化に適しています。
**ベトナム語説明**: Trong công việc văn phòng, tự động hóa phù hợp với nhập liệu và phân loại định hình.

### 問題3

自動化の価値として「一貫性」は何を意味する？

A) 速度だけを上げること
B) UI を派手にすること
C) 同じ作業を安定して繰り返すこと
D) 結果を変え続けること

**答え**: C

**解説**: 一貫性は同じ品質で繰り返し処理できることです。
**ベトナム語説明**: Tính nhất quán là lặp lại ổn định với cùng chất lượng.

### 問題4

自動化の導入で「フォーカスの転換」が意味するのは？

A) UI を変更する
B) データを減らす
C) 機械だけで全て行う
D) 人は創造的な業務に集中できるようになる

**答え**: D

**解説**: 自動化により人は単純作業から創造的業務へ集中できます。
**ベトナム語説明**: Tự động hóa giúp con người chuyển sang công việc sáng tạo.

### 問題5

自動化の進め方で「対象業務の選定」が重要な理由は？

A) 適用効果の高い業務を先に選ぶため
B) データを隠すため
C) UI を飾るため
D) 速さだけを重視するため

**答え**: A

**解説**: 適切な対象選定で効果的な自動化が実現します。
**ベトナム語説明**: Chọn nghiệp vụ phù hợp giúp tự động hóa hiệu quả hơn.

### 問題6

AI と定型処理の組み合わせで期待されるのは何ですか？

A) 速度の低下
B) データの喪失
C) UI の複雑化
D) 柔軟性と効率性の両立

**答え**: D

**解説**: AI と定型処理の組み合わせで柔軟かつ効率的になります。
**ベトナム語説明**: Kết hợp AI và xử lý định kỳ đem lại linh hoạt và hiệu quả.

### 問題7

検証と監視が自動化で必要な理由は？

A) 速度を上げるためだけ
B) UI を派手にするため
C) データを隠すため
D) 自動化した結果が期待通りか確認するため

**答え**: D

**解説**: 検証と監視で自動化の品質を維持します。
**ベトナム語説明**: Kiểm chứng và giám sát giữ chất lượng tự động hóa.

### 問題8

セミオート運用とは何ですか？

A) 自動化と人の判断を組み合わせる運用
B) UI を変更する運用
C) データを捨てる運用
D) 完全に手動で行う運用

**答え**: A

**解説**: セミオートは自動化と人の判断を併用します。
**ベトナム語説明**: Bán tự động kết hợp tự động và quyết định con người.

### 問題9

営業支援における自動化の効果は？

A) データを消すこと
B) 定型作業を効率化し顧客対応を改善する
C) UI を派手にするだけ
D) AI を隠すこと

**答え**: B

**解説**: 営業支援は定型作業効率化で顧客対応を改善します。
**ベトナム語説明**: Trong bán hàng, tự động hóa cải thiện công việc định hình và hỗ trợ khách hàng.

### 問題10

自動化の「フローの可視化」が意味するのは？

A) UI を変更すること
B) モデルを小さくすること
C) 業務手順を図にして理解しやすくすること
D) データを暗号化すること

**答え**: C

**解説**: 可視化で業務手順が明確になり改善しやすくなります。
**ベトナム語説明**: Minh họa quy trình giúp dễ hiểu và cải tiến.
