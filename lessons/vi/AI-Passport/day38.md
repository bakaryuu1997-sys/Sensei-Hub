## 3. 本日の内容

### 安全なAI運用とは

**定義**：AI を実際に使う際に、誤動作・悪用・事故を防ぎ、安定した品質を維持すること。

（Vận hành AI an toàn: vận hành sao cho AI không gây ra sự cố và luôn đáng tin cậy）

```
安全運用 = 予防 + 監視 + 対応
```

### 安全運用の 3 つの柱

#### 1. 予防

```
設計段階でリスクを減らす仕組みを作る
```

#### 2. 監視

```
運用中に異常を検知する
```

#### 3. 対応

```
問題が起きたときに速やかに対処する
```

### 重要な運用プロセス

#### 1. テスト

```
訓練データ・モデル・運用環境を検証する
```

#### 2. モニタリング

```
出力品質、バイアス、性能、セキュリティを監視する
```

#### 3. インシデント対応

```
問題発生時に原因を特定し、復旧と再発防止を行う
```

#### 4. バージョン管理

```
モデルやデータの変更履歴を管理し、切り戻し可能にする
```

#### 5. レッドチーミング

```
攻撃者の目線でAIの弱点を検証する
```

### セキュリティの観点

#### 1. アクセス制御

```
誰がどのデータ・モデルにアクセスできるかを制限する
```

#### 2. データ保護

```
機密データの暗号化やログ管理を徹底する
```

#### 3. 供給連鎖リスク

```
外部データや第三者モデルの信頼性を確認する
```

### 具体例

#### 例1：有害なプロンプト対応

```
危険な命令が来たときに、安全な回答や拒否応答を返す仕組み
```

#### 例2：モデル劣化の検知

```
時間の経過で性能が落ちたら再学習や交換を行う
```

#### 例3：不正アクセスの監査

```
不審なアクセスやデータの異常をリアルタイムで検知する
```

---

## 4. 安全なAI運用のポイント

1. 運用は開発後も継続する責任である
2. モニタリングは品質管理の基盤である
3. インシデント対応計画はあらかじめ用意する
4. セキュリティと私たちの信頼は表裏一体である
5. リスクはゼロにできないが、適切な運用で低減できる

## 7. 確認問題


### 問題1

安全なAI運用の 3 つの柱に含まれるのはどれですか？

A) 学習、推論、保存
B) 設計、開発、廃棄
C) 販売、マーケティング、サポート
D) 予防、監視、対応

**答え**: D

**解説**: 安全運用は予防、監視、対応の3つの柱で成り立ちます。
**ベトナム語説明**: Bảo mật vận hành gồm phòng ngừa, giám sát, ứng phó.

### 問題2

運用プロセスで「レッドチーミング」は何を目的としますか？

A) 攻撃者の視点で弱点を発見する
B) UI を最適化する
C) 売上を上げる
D) データを削除する

**答え**: A

**解説**: レッドチーミングは攻撃視点で脆弱性を検証します。
**ベトナム語説明**: Red teaming tìm lỗ hổng từ góc nhìn kẻ tấn công.

### 問題3

モニタリングでチェックすべきものはどれですか？

A) モデルの挙動と性能変化
B) UI の色
C) 開発者の人数
D) 広告の表示回数

**答え**: A

**解説**: モニタリングはモデル挙動や性能ドリフトを監視します。
**ベトナム語説明**: Giám sát theo dõi hành vi mô hình và drift hiệu suất.

### 問題4

インシデント対応で最初に行うべきことは？

A) データを全部公開
B) 問題の特定と影響範囲の把握
C) モデルを削除
D) UI を変更

**答え**: B

**解説**: 対応ではまず問題の特定と影響範囲を確認します。
**ベトナム語説明**: Ứng phó bắt đầu bằng xác định vấn đề và phạm vi tác động.

### 問題5

セキュリティ観点で重要な対策はどれですか？

A) 音声認識
B) 成績評価
C) アクセス制御、データ保護、サプライチェーン管理
D) 画面デザイン

**答え**: C

**解説**: セキュリティにはアクセス制御とデータ保護が重要です。
**ベトナム語説明**: An ninh cần kiểm soát truy cập và bảo vệ dữ liệu.

### 問題6

有害なプロンプト対応の目的は何ですか？

A) モデルを小さくすること
B) 速度を上げること
C) 悪用や危険な出力を防ぐこと
D) UI を派手にすること

**答え**: C

**解説**: 有害プロンプト対応は危険な出力を防ぐためです。
**ベトナム語説明**: Xử lý prompt độc hại ngăn đầu ra nguy hiểm.

### 問題7

モデル劣化の検知に必要なのはどれですか？

A) UI を変更すること
B) データを捨てること
C) 継続的な監視と評価
D) ラベルを消すこと

**答え**: C

**解説**: 劣化を見つけるには継続的な監視と評価が必要です。
**ベトナム語説明**: Phát hiện suy giảm cần giám sát và đánh giá liên tục.

### 問題8

供給連鎖リスクで注意すべきものは？

A) UI の色
B) 電力供給のみ
C) 広告の数
D) 外部コンポーネントやサービスの安全性

**答え**: D

**解説**: 供給連鎖リスクは外部要素の安全性に関係します。
**ベトナム語説明**: Rủi ro chuỗi cung ứng liên quan đến an toàn dịch vụ/thiết bị bên ngoài.

### 問題9

安全なAI運用で「予防」に含まれるのはどれですか？

A) 運用後の改善のみ
B) UI を派手にすること
C) データを隠すこと
D) 設計段階からのリスク低減

**答え**: D

**解説**: 予防は設計段階でリスクを低減することです。
**ベトナム語説明**: Phòng ngừa là giảm rủi ro ngay từ giai đoạn thiết kế.

### 問題10

AI 運用における「対応」は何を指しますか？

A) 新しいモデルの研究
B) UI の変更
C) 広告を表示すること
D) 問題発生時の迅速な対策と復旧

**答え**: D

**解説**: 対応はインシデント発生時の対策と復旧を指します。
**ベトナム語説明**: Ứng phó là hành động nhanh chóng khi sự cố xảy ra.
