## 3. 本日の内容

### ディープラーニングとは

**定義**：複数の隠れ層を持つニューラルネットワーク。

（Học sâu: mạng thần kinh với nhiều lớp ẩn）

```
浅いニューラルネット
入力層 → 隠れ層1 → 出力層

ディープラーニング
入力層 → 隠れ層1 → 隠れ層2 → 隠れ層3 → ... → 出力層
```

**「Deep」（深い）の定義**：
```
層数 2～3個：浅い
層数 4～10個：中程度
層数 10個以上：深い（ディープラーニング）

現代的なモデル：100層以上
```

### 浅いネットワーク vs ディープラーニング

| 項目 | 浅いネットワーク | ディープラーニング |
|-----|----------------|----------------|
| 層数 | 1～2層 | 3層以上 |
| 学習能力 | シンプルなパターン | 複雑で抽象的なパターン |
| 必要なデータ | 少なくても OK | 大量のデータが必要 |
| 計算量 | 少ない | 非常に多い |
| 学習時間 | 短い | 非常に長い |
| ハードウェア | CPU で OK | GPU が必須 |

### 階層的な特徴抽出

**重要なコンセプト**：層が深いほど、より抽象的な特徴を学べる。

```
画像認識の例：

入力画像（ピクセル）
    ↓
隠れ層1：エッジ（線）を検出
    ↓
隠れ層2：角や曲線を検出
    ↓
隠れ層3：目、鼻、口などの部位を検出
    ↓
隠れ層4：「顔」という高レベルな概念を認識
    ↓
出力層：「この人物は誰か」を判断
```

（Từ dưới lên: chi tiết → trừu tượng）

**利点**：
```
低レベルの特徴から、段階的に高レベルの特徴を学ぶ
→ より効率的で理解しやすい表現
```

### ディープラーニングが可能になった3つの要因

#### 1. 大量のデータ（ビッグデータ）

```
2000年代初期：
- インターネット上の画像数：百万枚程度
- モデルの過学習リスク：非常に高い

2010年代以降：
- インターネット上の画像数：数十億枚
- モデルの過学習リスク：低い
- 複雑な深層学習モデルを学習できる
```

#### 2. GPU（グラフィックスプロセッサ）

```
CPU：汎用、複数タスク処理
→ 1個の計算は高速だが、大量の並列計算は苦手

GPU：画像処理に最適化
→ 行列計算などの並列計算が得意
→ ディープラーニングの計算に最適
```

**速度比較**：
```
CPU での深層学習：数週間～数ヶ月
GPU での深層学習：数時間～数日
```

#### 3. アルゴリズムの改善

```
2012年：ReLU 活性化関数の発見
→ シグモイドより学習が速い

2012年：ドロップアウト
→ 過学習を防ぐ

2014年：バッチ正規化
→ 学習の安定性と速度を向上

現代：様々な最適化手法が開発
```

### ディープラーニングのメリット

#### 1. 自動特徴抽出

```
従来の機械学習：
人間が特徴を手動で設計
→ ドメイン知識が必要、時間がかかる

ディープラーニング：
特徴を自動的に学習
→ 人間の手を少なくできる
```

#### 2. 複雑なパターン認識

```
従来の ML：線形な関係のみ
ディープラーニング：複雑で非線形な関係も学べる
```

#### 3. スケーラビリティ

```
データが増えると、精度も向上
→ 大量データとの相性が良い
```

### ディープラーニングのデメリット

#### 1. 大量のデータが必要

```
小規模データセット（1000件以下）
→ ディープラーニングは過学習のリスク
→ 浅い機械学習の方が良い
```

#### 2. 計算量が膨大

```
GPU 不足：学習に数週間
電力消費：大規模モデルは非常に電力を消費
```

#### 3. ブラックボックス問題

```
深いネットワーク：何を学んでいるか理解しにくい
→ 医療診断など、説明が必要な分野では問題
```

### ディープラーニングの構造

```
一般的な構造：

入力層（784ニューロン）
    ↓
隠れ層1（512ニューロン）
    ↓
隠れ層2（256ニューロン）
    ↓
隠れ層3（128ニューロン）
    ↓
隠れ層4（64ニューロン）
    ↓
出力層（10ニューロン）

層が深いほど、モデルは複雑
```

## 4. 具体例

### 例1：ImageNet と AlexNet（2012年）

```
背景：
- ImageNet：100万枚の画像を 1000 カテゴリに分類

AlexNet（ディープラーニング）：
- 層数：8層
- GPU：2つの NVIDIA GPU
- 学習時間：5～6日

結果：
- 精度：74.3%（それまでのベスト 63.3%）
- 大革新！→ ディープラーニングの時代開始
```

### 例2：手書き数字認識

```
浅いネットワーク：
- 隠れ層：1層（100ニューロン）
- 精度：95%

ディープラーニング：
- 隠れ層：4層（784 → 512 → 256 → 64）
- 精度：99.5%
- より複雑なパターンを学べる
```

### 例3：自然言語処理

```
従来の機械学習：
- 単語の特徴を手動で設計
- 文法ルールを入力

ディープラーニング（RNN/Transformer）：
- 単語の意味を自動的に学習
- 文脈を理解できる

結果：ChatGPT のような高度な言語モデル
```

## 5. 試験で出やすいポイント

1. **ディープラーニングの定義**
   - 複数隠れ層を持つニューラルネットワーク

2. **浅い vs 深い**
   - 層数、学習能力、必要なデータ量の違い

3. **階層的特徴抽出**
   - 低レベル → 高レベルの特徴へ

4. **DL が可能になった3要因**
   - ビッグデータ、GPU、アルゴリズム改善

5. **メリット・デメリット**
   - 自動特徴抽出 vs 大量データ必要、ブラックボックス

---

## 6. 間違えやすいポイント

❌ **間違い1**: 「ディープラーニング = 常に最良の方法」
✅ **正解**: 小規模データセットでは、浅い ML の方が良い場合もある

❌ **間違い2**: 「層が多いほど常に精度が上がる」
✅ **正解**: 過度に深いと過学習リスク、最適な深さがある

❌ **間違い3**: 「ディープラーニングは理解できない（ブラックボックス）」
✅ **正解**: 工夫次第で、ある程度は理解できる技術がある

❌ **間違い4**: 「GPU なしでディープラーニングはできない」
✅ **正解**: CPU でも可能だが、非常に遅い

❌ **間違い5**: 「ディープラーニング = 必ず優れている」
✅ **正解**: 問題や状況によって、最適な手法は異なる

### 問題1
ディープラーニングの定義として正しいのはどれですか？

A) 複数の隠れ層を持つニューラルネットワーク
B) 説明責任を果たさない
C) 浅いニューラルネットワーク
D) 使いにくい操作を設計する

**答え**: A


**解説**: ディープラーニングは、3層以上の隠れ層を持つニューラルネットワークです。

C) 低レベルの特徴から段階的に高レベルの特徴を学ぶ
D) 使いにくい操作を設計する

**答え**: C


**解説**: 層が深いほど、より抽象的で高レベルの特徴を学べます。
