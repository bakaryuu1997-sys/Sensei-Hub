## 3. 本日の内容

### AI エージェントとは

**定義**：複数のツール（検索、計算、API など）を自律的に選択・実行して、複雑なタスクを達成する AI システム。

（Tác nhân AI: hệ thống có khả năng chọn và sử dụng các công cụ để hoàn thành nhiệm vụ）

```
従来の LLM：
ユーザー質問
    ↓
LLM（テキスト生成）
    ↓
答えを返す
    ↓
終了

AIエージェント：
ユーザー指示
    ↓
ゴール設定
    ↓
推論ループ開始
  ├─ 現在の状態を分析
  ├─ 使用するツールを決定
  ├─ ツールを実行
  ├─ 結果を評価
  └─ ゴール達成？→ No なら繰り返す
    ↓
ゴール達成
    ↓
終了
```

### エージェントの構成要素

```
【1. LLM コア】
思考・判断・意思決定

【2. メモリ】
・短期記憶：現在のタスク情報
・長期記憶：過去の経験・学習

【3. ツール】
利用可能な機能
・Web 検索
・計算機
・API 呼び出し
・ファイル操作
・データベースアクセス

【4. 推論エンジン】
最適なツールとアクションを選択

【5. 実行エンジン】
決定に基づいて実行

【6. 監視・制御】
進捗確認、制約条件チェック
```

---

### エージェントの意思決定プロセス

```
【ステップ 1】ユーザーからタスク受け取り
「来週の東京と大阪の天気を調べて、
旅行の服装を提案してください」

【ステップ 2】ゴール設定
・達成目標：旅行服装提案
・必要情報：東京と大阪の天気、来週の日程

【ステップ 3】推論ループ開始

反復 1：
思考：「来週の天気を知る必要がある」
ツール選択：「天気 API」
実行：天気データ取得
結果：「東京：晴れ、気温 25℃」「大阪：曇り、気温 23℃」
進捗：50%

反復 2：
思考：「天気に応じた服装を決定する必要がある」
ツール選択：「知識ベース」
実行：推奨服装を検索
結果：「晴れ、25℃ なら半袖+薄いジャケット」
進捗：75%

反復 3：
思考：「服装提案を生成」
ツール選択：「テキスト生成」
実行：提案文を作成
結果：「東京では...、大阪では...」
進捗：100%

【ステップ 4】完了・ユーザーに返す
提案：「東京は晴れなので、半袖で大丈夫です...」
```

## 4. エージェントのパターン

### パターン1：ReAct（Reasoning + Acting）

```
思考 → 行動 → 観察 → 思考 → 行動 → ...

例：旅行計画
思考：「飛行機の時間を知る必要がある」
行動：「フライト検索 API」
観察：「東京→大阪は 10:00 発」
思考：「ホテルも予約する必要がある」
行動：「ホテル検索 API」
...
```

### パターン2：ツリーサーチ

```
複数の選択肢を並行探索

ユーザー：「投資戦略を提案」

エージェント：
├─ 経路 1：高リスク・高リターン
│   ├─ 株式投資
│   ├─ 仮想通貨
│   └─ 評価
├─ 経路 2：中程度リスク
│   ├─ 投信
│   ├─ 債券
│   └─ 評価
└─ 経路 3：低リスク
    ├─ 銀行預金
    ├─ 国債
    └─ 評価

最適な経路を選択
```

### パターン3：ハイエラルキー（階層型）

```
複雑なタスク → サブタスク分割

ユーザー：「新規事業プランを作成」

メインエージェント：
├─ 市場調査エージェント
│   ├─ 競争分析
│   ├─ 需要分析
│   └─ レポート作成
├─ 財務計画エージェント
│   ├─ コスト推定
│   ├─ 収益予測
│   └─ ROI 計算
└─ リスク評価エージェント
    ├─ リスク特定
    ├─ 対策案立案
    └─ レポート作成

最終結果を統合
```

## 5. 具体例

### 例1：旅行計画エージェント

```
ユーザー：「来月、予算 30 万円で、
家族 4 人で 3 泊 4 日の沖縄旅行を計画してください」

エージェントの実行：

1. フライト検索：
   「東京→那覇の往復」
   結果：ANA 往復 80,000 円

2. ホテル検索：
   「那覇の 4 つ星ホテル、3 泊」
   結果：1 泊 15,000 円 × 3 = 45,000 円

3. 食事・観光予算計算：
   「1 日 1 人 3,000 円、4 人 4 日」
   結果：48,000 円

4. 合計計算：
   80,000 + 45,000 + 48,000 = 173,000 円

5. 予算内か判定：
   「173,000 < 300,000 ✓」

6. 観光スポット検索：
   「沖縄の子ども向け観光地」
   結果：ひめゆりの塔、美しい海など

7. 旅程を作成：
   「Day 1: 到着 → ホテル
   Day 2: 海 → 買い物
   ..."

出力：
「推奨プラン：
飛行機：ANA 往復
ホテル：XXX ホテル
予算：173,000 円
旅程：...」
```

### 例2：データ分析エージェント

```
ユーザー：「2023 年の売上データを分析し、
トレンドを抽出して、2024 年の予測を立てて」

エージェントの実行：

1. データ取得：
   「売上データベースから 2023 年データ」
   結果：月別売上 CSV を取得

2. 統計分析：
   「月別売上の平均、標準偏差、成長率計算」
   結果：「平均売上 1000 万円、成長率 15%」

3. トレンド抽出：
   「時系列データから傾向検出」
   結果：「Q2 が最高、Q4 に低下」

4. 外部要因分析：
   「競合企業の動向、市場調査」
   結果：「ライバル企業 X が 20% 成長」

5. 予測モデル構築：
   「2024 年売上予測」
   結果：「1200 万円 ± 5%」

6. レポート作成：
   グラフ + 分析結果

出力：
「2023 年売上分析：
- 平均：1000 万円
- トレンド：右肩上がり
- 2024 年予測：1200 万円」
```

### 例3：カスタマーサポートエージェント

```
顧客：「商品が届かないのですが」

エージェントの実行：

1. 顧客情報取得：
   「注文番号から注文履歴を検索」
   結果：「Order #12345、配送中」

2. 配送状況確認：
   「配送トラッキング」
   結果：「昨日配送センター出発」

3. 配送予測：
   「現在位置から配送予定日計算」
   結果：「明日までに到着予定」

4. 顧客対応：
   「対応オプション決定」
   ├─ そのまま待つ（明日到着予定）
   ├─ 配送業者に連絡
   └─ 返金手続き

5. 提案：
   「顧客状況に応じた最適な対応」
   結果：「通常配送なら明日到着。
   急ぎなら配送業者に連絡します」

出力：
「お待たせしました。
貴注文は明日までに到着予定です。
急ぎの場合は以下にご連絡ください...」
```

## 6. AI エージェントの利点と課題

### 利点

✓ 複雑なタスク自動実行  
✓ ユーザーの時間削減  
✓ 一貫した判断  
✓ 複数ツール統合  
✓ 学習・改善可能  

### 課題

✗ 予測不能な動作  
✗ 制御が難しい  
✗ コストが高い  
✗ セキュリティリスク  
✗ 説明可能性（AI が何を考えているか不明確）

## 9. 確認問題

### 問題1
次のうち正しいものはどれですか？

A) 結論がない
B) 説明責任を無視する
C) 複数ツールで自律的にタスク実行
D) 表示だけを変える

**答え**: C

**解説**: AI エージェントは、目標達成のため、複数の利用可能なツールを自律的に選択・使用します。

---

### 問題2

A) エージェントは複数ツール統合、複雑タスク対応

C) 手段を優先する
D) 専門用語をそのまま使う

**答え**: A

**解説**: ツール統合により、エージェントはより複雑なタスクを処理できます。

### 問題3

A) 変化を予測しない
