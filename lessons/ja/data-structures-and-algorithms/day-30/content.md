## 🗺️ 知識のマップ：Phase 5 の 4 つの柱

過去10日間で、高度なアルゴリズムの「ビッグフォー（4大要素）」を網羅しました。

1. **最短経路とサイクル (Day 21-22)**:
   - **Dijkstra**: 非負の重みに対する「貪欲（Greedy）」な選択。
   - **Bellman-Ford**: 負の辺やサイクル検出に対応する堅牢な選択。
2. **連結性と MST (Day 23-24)**:
   - **Prim & Kruskal**: 最も効率的なネットワークの構築。
   - **DSU (Disjoint Set Union)**: ほぼ定数時間での連結性チェックの魔法。
3. **高度な動的計画法 (Day 25-28)**:
   - 1次元 DP から **Tree DP** や **Bitmask DP** への進化。
   - 指数関数的な問題を多項式時間で解くために、「状態」を整数として表現する方法。
4. **文字列インテリジェンス (Day 29)**:
   - **KMP & Z-Algorithm**: 「二度と後戻りしない」ことがパフォーマンスの秘訣であることを理解。

## 🧩 決定マトリクス：いつ何を使うか？

| 状況... | 使用するアルゴリズム... | ロジック |
| :--- | :--- | :--- |
| 「最短経路、重みは正」 | **Dijkstra** | $O(E \log V)$ の効率性。 |
| 「最短経路、負の辺あり」 | **Bellman-Ford** | $O(V \cdot E)$ の安全性。 |
| 「全ノードを最小コストで連結」 | **Kruskal + DSU** | 疎なグラフ（辺が少ない）に最適。 |
| 「最適な部分木 / 階層構造」 | **Tree DP** | ノードに対するボトムアップな決定。 |
| 「N が小さい (N <= 20)、部分集合」 | **Bitmask DP** | ビットを用いた網羅的な探索。 |
| 「テキスト内のパターンマッチング」 | **KMP** | $O(N+M)$ の線形検索。 |

## 🏹 グランドチャレンジ：分散型メッセンジャー

あなたは、世界規模の災害救助チームのための分散型メッセージングアプリを構築していると想像してください。
- **グラフ**: 都市がノード、通信リンクが辺（重みは遅延時間）です。
- **課題**: 
  1. 2つの都市間のメッセージの最速ルートを見つける（最短経路）。
  2. リンクに負の遅延（仮定：信号ブースト）がある場合、無限ループが発生しないか確認する（サイクル検出）。
  3. すべての都市を接続し続けるために必要な最小限のインフラを見つける（MST）。
  4. 最大15個のハブを使用して、重複しないハブの最長チェーンを見つける（Bitmask DP）。
  5. すべての受信メッセージに「DANGER」というキーワードが含まれていないかスキャンする（KMP）。

**問い**: 各課題に対して、どのアルゴリズムを使用しますか？
