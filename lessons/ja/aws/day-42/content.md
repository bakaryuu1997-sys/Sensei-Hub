# 🪝 THE HOOK: 「ブラックフライデーに DDoS 攻撃を受けたら」

あなたが **ブラックフライデー** に向けて EC サイトを運営していると想像してください。
- トラフィックが急増し、秒単位で売上が積み上がっています。しかし突然、システムがダウンしました。
- ログを確認すると、世界中の見知らぬ IP から同時に数百万件のアクセスが。
- AWS Shield のダッシュボードが真っ赤に点灯しています。巨大な **DDoS 攻撃** を受けているのです。

さらに悪いことに、ハッカーはその混乱に乗じて **SQL インジェクション** を仕掛け、密かに顧客データを盗み出そうとしています。IP やポート番号だけをチェックする従来のセキュリティグループだけでは、太刀打ちできません。セキュリティグループは、本物の顧客と「演技」をしているボットを区別できないからです。

**Day 42: Infrastructure & Application Security** へようこそ。今日は、ビジネスの「魂」を守る、最もスマートな多層防御の盾を構築します。

# 🎭 ANALOGY: インフラ保護は「大使館の入館手続き」と同じ

### 🧱 1. セキュリティグループ - 鉄の門
- IP やポートに基づいて「誰が入れるか」をチェックします。持ち物（中身）には関心がありません。「顔見知り（許可された IP）」であれば、爆弾を持っていても通してしまいます。

### 👮 2. AWS WAF - 入口の警備員（レイヤー 7）
- 「カバンの中身（HTTP リクエスト）」を検査します。悪意のあるコードや SQL インジェクションがあれば、「顔見知り」であっても即座に追い出します。

### 🛡️ 3. AWS Shield - 対テロ特殊部隊（DDoS 対策）
- 何百万人もの暴徒（偽トラフィック）が押し寄せて門を塞ごうとしたとき、AWS Shield が登場して暴徒を排除し、本物の顧客のための通路を確保します。

# ⚙️ UNDER THE HOOD: 技術ディープダイブ

### 1. AWS WAF (Web Application Firewall)
- OWASP Top 10 の脆弱性から保護。ボットによるスクレイピング（データ収集）や、アカウント乗っ取り攻撃を防ぎます。

### 2. AWS Shield Standard & Advanced
- **Standard**: 全ユーザーに無料で提供される、基本的な DDoS 保護（レイヤー 3、4）。
- **Advanced**: 24 時間 365 日体制の専門家チーム（DRT）によるサポート。DDoS 攻撃による予期せぬスケールアップ費用の補償も含まれます。

### 3. 2026 年最新アップデート: AI 駆動型ディフェンス 🚀
- **Amazon Q for WAF (2026)**: 複雑なルールを書く必要はありません。「今ロシアから来ているスクレイピング攻撃を止めるルールを作って」と言うだけで、AI がトラフィックパターンを分析し、数秒でルールを適用します。
- **Zero-Day AI Protection (2026)**: WAF は AI モデルを使用して、脆弱性が正式に発表される前であっても、行動パターンから新しい攻撃（ゼロデイ）を予測し、防御します。
- **GuardDuty AI Malware Protection (2026)**: S3、EBS、さらには Lambda 実行環境内のマルウェアを、エージェントなしで AI が自動検知。ランサムウェアが侵入した瞬間に発見します。
- **Automated Shield Mitigation 2.0 (2026)**: リアルタイム AI 分析により、誤検知（False Positive）をほぼゼロに抑えつつ、1 秒以内にエッジで DDoS を緩和します。

# ☁️ AWS IN PRACTICE / INTERVIEW

**実務シチュエーション：** 「本物の顧客に影響を与えず、商品の価格情報を盗むボット（スクレイピング）だけをブロックするには？」

**マスターアーキテクトの回答例：**
「**AWS WAF Bot Control** を使用します。
1. ボットを識別するマネージドルールセットを有効化します。
2. 不審な IP に対して **CAPTCHA** や **Challenge**（パズル解き）を要求します。
3. **Rate-based rule**（頻度制限）を設定します。
2026 年なら、**Amazon Q** を使用して実際のログからこれらのルールを継続的に最適化し、高いボット検知率とスムーズなユーザー体験を両立させます。」

# 🔦 CASE STUDY: Epic Games と Fortnite の DDoS 防衛戦

**背景:** Epic Games は、世界中で数億人がプレイする **Fortnite（フォートナイト）** の開発元です。ゲーム業界では、チート行為や競合他社による DDoS 攻撃が日常茶飯事であり、プレイヤーの体験を著しく損ないます。

**課題:** 対戦中、毎秒数百万もの UDP パケットが飛び交います。DDoS 攻撃によってインフラが圧迫されると、ラグやサーバーダウンが発生し、数百万人のプレイヤーの怒りを買うことになります。

**アプリケーション・セキュリティ・ソリューション（2026 年基準）:**
1.  **「鉄の盾」 AWS Shield Advanced**: Epic Games は全世界で **AWS Shield Advanced** を展開。レイヤー 3 や 4 での攻撃を検知すると、エッジロケーションで数ミリ秒以内に悪意のあるトラフィックを自動排除します。
2.  **API を守る AWS WAF**: ログインやアイテム購入システムは **AWS WAF** で保護。**Bot Control** を使用して、他人のアカウントを盗もうとする自動ログイン（資格情報の詰め込み攻撃）をブロックしています。
3.  **Amazon Q によるインテリジェント監視 (2026)**: セキュリティチームは **Amazon Q** を使用して新しい攻撃パターンを分析。AI がハッカーの行動に基づいて新しい WAF ルールを自動提案し、ゼロデイ攻撃を未然に防ぎます。

**結果:**
- 大規模な DDoS 攻撃下でも、プレイヤーに超低遅延な環境を維持。
- 数百万のユーザーアカウントを乗っ取り攻撃から保護。
- 無駄なトラフィックをエッジで遮断することで、インフラコストを数百万ドル節約。

**BrSE への教訓:** 日本の顧客はレピュテーションリスク（評判リスク）を極めて恐れます。DDoS によるサイト停止は数十億円の損失に繋がることもあります。重要なシステムには、**Shield Advanced** を「最高級の保険」として提案しましょう。

### 🚀 Master Architect Pro-Tips

> **Tip 1 — マネージドルールを最優先に**: 最初からすべてのルールを自作しようとせず、AWS が更新し続ける **マネージドルール** を使いましょう。これだけで最新の脆弱性の多くに対応できます。

> **Tip 2 — 費用対効果を考える**: Shield Advanced は月額 3,000 ドルと高価ですが、サーバーが攻撃を防ごうと自動スケールして発生する「高額請求（ビルショック）」からあなたを守る保険でもあります。

> **Tip 3 — WAF ログを忘れずに**: ログがなければ、なぜ本物の顧客が拒否されたのか、どこから攻撃が来たのか分析できません。2026 年は **Amazon Q** にログを「代読」させましょう。

> **Tip 4 — CloudFront との併用**: WAF はロードバランサーではなく、なるべく **CloudFront（エッジ）** に配置しましょう。攻撃者の近くで門前払いすることで、背後のインフラ負荷を最小限に抑えられます。
